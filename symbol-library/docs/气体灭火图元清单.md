# 气体灭火图元清单

气体灭火系统组态图的图元、测点与规范增量清单，供 `src/symbols.source.js` 增补与画面绘制使用。

## 1. 总量

| 项 | 数量 |
|---|---|
| 新增图元 | 18 |
| 复用图元 | 11 |
| 新增测点 | 31（AI 5 / DI 26） |
| 点表规模 | 69 → 100 |
| 新增分类 | 6（储存装置、驱动装置、灭火剂管网、探测报警、控制、辅助设施） |

图元 ID 全部符合构建校验正则 `^[A-Z]{2,4}-[A-Z]{2,5}-\d{2}$`。

## 5. 规范改动（4 项）

| # | 位置 | 改动 |
|---|---|---|
| 1 | `src/build.mjs` `SCREENS` | 新增 6 类映射：储存装置 / 驱动装置 / 灭火剂管网 / 探测报警 / 控制 / 辅助设施 → `G07 气体灭火总貌` |

`is-delay` 不新增，延时中复用现有 `is-manual`（黄）。

| 项 | 数量 | 说明 |

图片版已知偏差需在提示词中规避：

- 钢瓶组易被画成灭火器或氧气瓶 → 强调「灭火剂钢瓶组，无灭火器手柄」
