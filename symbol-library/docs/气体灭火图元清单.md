# 气体灭火图元清单

气体灭火系统的图元、测点与画面落地清单，与 `src/symbols.source.js` 的实现一致。

## 1. 分类体系

图元库采用两级分类，分类表在 `src/symbols.source.js` 的 `SYSTEMS` / `CATEGORIES` 中集中声明，是分类的唯一真源。

| 一级（系统） | key | 二级（部件类别） | 图元数 |
|---|---|---|---|
| 消防给水 | `pipeline` | 水源、泵组、末端设施、接合器 | 16 |
| 气体灭火 | `gas` | 储存装置、驱动装置、灭火剂管网、探测报警、控制、辅助设施 | 18 |
| 消防防排烟 | `smoke` | 预留 | 0 |
| 通用件 | `common` | 管道管件、阀门、仪表、电气 | 13 |

规则：

- 一级分类与平台 `systemKey`（`pipeline` / `gas` / `smoke` / `custom`）同源，图元库分组与组态画面的「归属系统」用同一套词
- 图元只引用二级分类键；系统归属默认取分类的 `system`，图元可用自身 `system` 字段覆盖（`PAI-CYL-01` 分类属通用「仪表」，系统归属为气体灭火；`ALV-GRP-01` 分类属通用「阀门」，系统归属为消防给水）
- 通用件在所有系统视图下都可见，界面带「通用」标记
- 构建时校验：图元引用的分类与系统必须已声明；分类的 `screen`（建议画面）不得为空

分类声明表：

```js
export const SYSTEMS = [
  { key: 'pipeline', name: '消防给水', desc: '水源、泵组、末端设施与接合器' },
  { key: 'gas', name: '气体灭火', desc: '储存装置、驱动装置、灭火剂管网、探测报警、控制与辅助设施' },
  { key: 'smoke', name: '消防防排烟', desc: '风机与风阀（预留）' },
  { key: 'common', name: '通用件', desc: '跨系统共用的管道管件、阀门、仪表与电气件' },
];
```

## 7. 画面落地

`src/layouts/demo-gasfire.json` — 气体灭火系统总貌，1400×920，69 节点 / 37 连线。

结构（每个保护区一套独立回路，4 个保护区）：

```
启动气瓶 → 启动电磁阀 → 灭火剂钢瓶组 → 集流管 → 灭火剂主管 → 支管阀 → 喷嘴
```

- 左侧控制列：气体灭火控制器、输入输出模块 ×2、延时继电器、压力信号器、手动启动拉环、气体灭火盘控制柜
- 保护区行 ×4（数据机房 / 通信机房 / 变配电室 / 档案室），每行 14 个图元
- 每个保护区上方挂感烟探测器、感温探测器、声光警报器、手动报警按钮；下方挂泄压口与排风机
- 底部联动流程条：探测报警 → 声光启动 → 延时 0~10s → 启动电磁阀 → 喷放反馈 → 喷嘴喷放

连线规则：`kind=pipe` 走端口，`kind=control` 为电气虚线直连、两端不写端口。

点位按实例编号：`图元前缀_保护区号_参数`（Z1~Z4），点表需按现场实例数展开（钢瓶压力探测器 98 只 → 98 组测点）。
