# 技能：告警日报（alarm-report）

## 触发意图
用户要求"出个今日告警日报""告警汇总""今日告警情况"等，期望得到一份**可交付的告警日报**。

## 数据源
工具 `query_alarms`（按 scope 过滤，返回告警点位/类型/等级/处置状态/时间/企业）。

## 产物形态（HTML）
自包含 HTML，浅色商务风，包含：
- **头部**：标题「今日告警日报」+ 统计时间 + 覆盖范围
- **统计卡**：告警总数 / 未处理（红）/ 已处置（绿）
- **明细表**：时间 | 点位 | 类型 | 等级 | 状态 | 企业
- **页脚**：平台名 + 「由韧性AI助手生成」

## 图表规范（可选扩展）
- 按等级分布可用环形图（紧急红/重要黄/一般蓝）
- 按时间段趋势可用折线图
- 当前 Demo 版本为纯表格 + 统计卡，未引入图表库（保持单文件零依赖，双击可看）

## 说明
产物在右栏「产物」Tab 用 iframe 预览，支持下载 `.html` 交付给领导/客户。
