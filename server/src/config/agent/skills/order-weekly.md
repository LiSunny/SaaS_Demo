# 技能：工单汇总（order-weekly）

## 触发意图
用户要求"工单周报""工单汇总""我的工单情况"等，期望得到一份**可交付的工单汇总**。

## 数据源
工具 `query_orders`（按 scope 过滤，返回工单号/标题/类型/状态/优先级/处理人/创建时间/企业）。

## 产物形态（HTML）
自包含 HTML，浅色商务风，包含：
- **头部**：标题「工单汇总」+ 截至时间 + 处理人范围
- **统计卡**：工单总数 / 进行中（蓝）/ 已关闭（绿）
- **明细表**：工单号 | 标题 | 类型 | 状态 | 优先级 | 处理人 | 创建时间
- **页脚**：平台名 + 「由韧性AI助手生成」

## 图表规范（可选扩展）
- 按状态占比可用环形图
- 按类型分布可用柱状图

## 说明
产物在右栏「产物」Tab 用 iframe 预览，支持下载 `.html` 交付。
