# 技能：隐患清单（hazard-list）

## 触发意图
用户要求"列出未整改隐患""隐患清单""隐患汇总"等，期望得到一份**可交付的隐患清单**。

## 数据源
工具 `query_hazards`（按 scope 过滤，返回隐患位置/类别/等级/整改状态/发现时间/企业）。

## 产物形态（HTML）
自包含 HTML，浅色商务风，包含：
- **头部**：标题「隐患清单」+ 截至时间 + 覆盖范围
- **统计卡**：隐患总数 / 重大隐患（红）/ 未整改（黄）
- **明细表**：位置 | 类别 | 等级 | 状态 | 发现时间 | 企业
- **页脚**：平台名 + 「由韧性AI助手生成」

## 图表规范（可选扩展）
- 按类别分布可用柱状图
- 按等级分组可用表格分组排序（重大在前）

## 说明
产物在右栏「产物」Tab 用 iframe 预览，支持下载 `.html` 交付。
