# 通用消防水泵房三维示例模型

> PUMP_ROOM_GENERIC_001 v1.0.0 ｜ 单位：米 ｜ +Y 轴向上 ｜ 原点在房间地平面几何中心

不绑定具体工程、按标准消防泵房配置试算的离线三维示例模型，用于业务平台的三维展示与功能验证。

---

## 二、运行

模型为独立静态应用，three.js r160 走本地 `vendor/`，**零 CDN、零外部素材**（贴图全部 Canvas 程序化生成）。

```bash
cd public && python3 -m http.server 8123
# 打开 http://127.0.0.1:8123/pump-room-model/
```

嵌入模式：`?embed=1` 隐藏自身 UI，向父窗口回报 `postMessage({type:'pump-room-model:ready'})`。

在 Vite 工程内则直接访问 `/pump-room-model/`（位于 `public/`，随构建产出）。

操作：左键旋转 / 滚轮缩放 / 右键平移；点设备出属性面板；`F` 聚焦选中；`Esc` 取消选中；`W` 线框。

视图预设：**外观**（室外 3/4 斜视，默认）｜**室内**（人视点）｜**剖切俯视**（高处俯视整体布置）。

## 三、剖视模式（默认开启）

让用户**不进入建筑**也能看清内部结构，由两件事组成：

| 动作 | 范围 | 判定 |
|---|---|---|
| 去屋顶 | 屋面板、4 道屋面梁、25 件吊装件（灯具吊杆/安装座/套管、桥架吊杆） | 剖视开启即隐藏 |
| 隐墙 | 位于相机与房间之间的墙，以及其附属构件（墙裙、门、窗、防撞标识、房号牌、应急灯支架、桥架壁挂托架、排污立管穿墙段、出水母管穿墙套管） | 随相机实时判定 |

墙面判定用平面外法线：相机在某面墙的外侧即隐去该墙。相机在房间内时四面墙全部保留；在室外某角时恰好隐去朝向用户的两面墙。

| 机位 | 相机位置 (m) | 屋顶 | 南墙 | 北墙 | 西墙 | 东墙 |
|---|---|---|---|---|---|---|
| 外观（默认） | (-19.2, 10.1, -12.6) | 隐 | 隐 | 显 | 隐 | 显 |
| 室内 | (-10.2, 2.9, -5.0) | 隐 | 显 | 显 | 显 | 显 |
| 剖切俯视 | (3.8, 18.7, -13.0) | 隐 | 隐 | 显 | 显 | 显 |

关闭右侧「剖视」复选框即恢复完整建筑（屋顶与四面墙全部显示）。

## 六、约定

- **唯一几何来源**：`src/layout.js`。各模块不得硬编码世界坐标。
- **坐标顺序**：对象级 `position` 为 `[x, z, y]`；POI 级 `position` 为 `[x, y, z]`。易错对象另提供具名字段 `x`/`y`/`z`，或用 `objPos()` 转换。
- **材质**：一律 `ctx.mat(name)` 取用，模块不新建材质。贴图全部 Canvas 程序化生成，尺寸 ≤ 256×256。
- **随机**：一律 `ctx.rng()`（mulberry32 可复现），禁止 `Math.random()`。
- **健壮性**：伙伴模块用动态 import 装载，单个模块缺失或抛错只跳过该模块并报错，不整页白屏。
- **剖视归组**：按网格名前缀/后缀归类（见 `src/app.js` 的 `CUTAWAY_RULES`），不改各建模模块；新增墙装构件时同步补规则，避免隐墙后悬空。
