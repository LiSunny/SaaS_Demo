## 一、模块定位
工单管理是消防安全管理平台的**流程中枢**，承载"任务流转与处置闭环"核心能力。其本质是一个可泛化的流程编排框架 + 工单全生命周期管理系统。

**四方协同模型**（详见 [平台岗位设计.md](../平台岗位设计.md) §一）：

| 租户方 | 典型角色 | 工单职责 |
| --- | --- | --- |
| 阳光物业管理有限公司（物业方） | 消防安全管理人、消控值班员、消防安全责任人 | 发起工单、核查验收、SLA 监督 |
| 蓝盾消防技术服务公司（服务方） | 维保工程师、项目负责人、技术负责人 | 接单处置、团队管理、技术审核 |
| 应急管理局安全管理中心（监管方） | 安全监管员 | 督办发起、核查验收、监管报告 |
| 平台运营方 | 平台管理员 | 流程模板配置、全局参数、全平台干预 |


**两种产品视角**（详见 [§八 岗位分离原则](#八岗位分离原则)）：

**我的工单** （个人视角）

> 信息密度低，无统计卡片。面向消防安全管理人、消控值班员、维保工程师。
>

+ 入口：工作台。
+ 数据范围：与我相关（我发起的 + 指派给我的）。

**工单监控** （管理视角）

> 信息密度高，必须有统计卡片 + SLA 预警。面向消防安全责任人、项目负责人、技术负责人、安全监管员。
>

+ 入口：工单监控。
+ 数据范围：按岗位全量过滤。

**工单管理不是**：

+ 不是告警系统（告警核实后由消控值班员发起工单，但告警本身属于远程值守模块）
+ 不是隐患管理系统（隐患发现与评估属于隐患管理模块，但隐患可通过业务组件自动带入工单）
+ 不是独立的统计分析工具（统计分析数据来源于工单流转）

## 五、关键业务规则
1. **双计时（端到端）**：
    - **响应时限**：发起流程 → 首个处理人确认收到并开始处理。若无接单环节则终点为首次打开任务
    - **解决时限**：发起流程 → 执行 → 确认 → 关闭的完整时长。驳回/转单不重置
    - 模板配置时按四档优先级（紧急/高/普通/低）独立设置两种时限
2. **接单仅在必要时出现**：接单不是流程的必经步骤。仅当指派节点为静态指派 + 目标为岗位/部门/多人 + 接单模式为"任一人接单"时，被指派人看到任务后需点击"接单"确认。其他场景（指定到具体人、每人独立任务、指派给发起人、动态指派）系统直接生成任务，用户打开即处置，无需额外接单动作
3. **确认节点极简化**：确认节点的目标是"用户无感"。模板配置确认节点时，默认为一键确认（点击即通过），不要求填写意见。仅当模板明确配置"需填写验收意见"时才展示文本框。驳回操作需填写原因（必填）
4. **转单仅管理员**：转单（强制改派）仅管理员角色可操作，普通执行人不可自行转单。管理员转单需填写原因留痕
5. **状态三态标准化**：草稿 → 进行中 → 已关闭。具体进度（待指派、处置中、验收中等）由当前节点名称体现，不再单独枚举中间状态。进度数字由已完成步骤数 / 总步骤数计算。工单监控列表展示统计卡片：全部/草稿/进行中/已关闭
6. **已关闭只读**：归档后不可修改，展示响应时长/解决时长/总耗时
7. **三方权限隔离**：物业看本企业、服务商看分配、监管看全量
8. **模板独立版本**：已发布模板产生工单后锁定，修改需新建版本
9. **按钮权限按作用域分离**：

   **工单级操作**（详情页顶部右侧，仅管理员可见）：

   | 按钮 | 显示条件 | 样式 |
   |------|---------|------|
   | 强制转派 | 进行中 | 蓝色线框 |
   | 取消工单 | 未关闭 | 蓝色线框 |
   | 手动关闭 | 未关闭 | 红色线框 |

   **节点级操作**（左栏底部当前节点卡片内，按节点类型切换）：

   | 节点类型 | 操作内容 | 按钮 |
   |---------|---------|------|
   | 指派 | 选择人员 | 保存 |
   | 执行 | 填写表单字段 | 保存 |
   | 确认 | 默认一键通过，模板可配"需验收意见" | 通过 / 驳回(需原因) |

   **接单说明**：
   - 接单不是独立的节点级按钮，而是执行节点的前置拦截状态
   - 当上一节点为指派（任一人接单模式 + 岗位/部门/多人）时，执行节点的负责人打开详情页先看到"接单"按钮，点击后露出表单
   - 其余场景（指定具体人、每人独立任务、指派给发起人、动态指派）无接单，直接展示表单

## 八、岗位分离原则
### 8.1 两种工单视角
| 维度 | 我的工单（个人视角） | 工单监控（管理视角） |
| --- | --- | --- |
| **用户** | 普通岗位（消防安全管理人、消控值班员、维保工程师） | 管理岗位（消防安全责任人、项目负责人、技术负责人、安全监管员） |
| **入口** | 工作台 | 独立页面 |
| **数据范围** | 与我相关（我发起的 + 指派给我的） | 全量（按岗位数据范围过滤） |
| **信息密度** | 低 — 工单编号、标题、状态、时间 | 高 — 超时进度、三色预警、节点详情 |
| **操作** | 发起、处置、验收 | 查看、督办、改派、取消 |
| **统计卡片** | 不需要 | 必须 — 按状态分布、达标率 |


### 8.2 发起工单的入口
+ **工作台**：快捷发起入口，面向消防安全管理人、消控值班员
+ **工单监控页**：不提供发起入口，纯监控用途
