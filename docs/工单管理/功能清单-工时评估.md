# 工单管理 — 功能清单与工时评估

> 日期：2026-06-16 | 从零开发 | 覆盖：流程模板 + 工单监控 + 发起工单 + 移动端

| 功能模块 | 功能点 | 功能描述 | 预估工时 |
|---------|--------|---------|:---:|
| **流程模板** | 模板列表页 | 模板的增删改查与状态管理，支持按名称、状态、周期筛选查询，支持分页；操作列提供预览、编辑、删除、启停、复制功能 | 3d |
| | 三步配置向导 | 引导式三步创建模板（基础设置→表单设计→流程设计），支持步骤间前后切换、草稿保存、发布校验，支持查看与编辑两种模式 | 1.5d |
| | 基础设置 | 配置模板名称、工单说明、可发起工单的人员范围；配置四档优先级（紧急/高/普通/低）各自独立的响应时限与解决时限 | 1.5d |
| | 表单设计器 | 可视化设计工单表单：提供基础组件（输入框、多行输入、单选框、选择器、日期、上传）和业务组件（事件信息、异常信息、隐患信息），支持拖拽编排、属性配置、字段来源设置（手动/自动/继承/回调） | 5d |
| | 流程设计器 | 可视化编排流程节点链：预置开始与结束节点，支持在节点间插入指派/执行/审批/条件判断/跨企业协同五种节点，支持删除节点、配置流转连线 | 3d |
| | 节点属性面板 | 配置节点的详细属性：节点名称、指派策略（静态指派/动态表单字段指派/指派给发起人，不同节点类型可选策略不同）、表单字段在该节点的可见与可编辑权限、超时规则与通知方式 | 3d |
| | 模板版本管理 | 已发布模板锁定不可直接修改，变更需生成新版本；支持历史版本查看；进行中的旧版实例不受版本更新影响 | 2d |
| **工单监控** | 监控列表页 | 按状态（全部/草稿/进行中/已关闭）统计工单数量并支持点击快速筛选；支持按关键词、服务时效状态、优先级、日期范围组合筛选；列表展示工单关键信息含服务时效三色预警；支持岗位数据范围隔离（物业看本企业/服务商看分配/监管看全量），超时工单自动置顶 | 3d |
| | 工单详情页 | 查看工单完整信息：流程步骤进度、已完成节点的数据汇总、当前节点的处置操作区、流转记录时间线；管理员可执行强制转派、取消工单、手动关闭 | 2d |
| | 动态表单组件 | 通用表单渲染引擎：根据模板定义的字段和当前节点的权限配置，自动渲染可交互表单——不可见字段隐藏、已填写字段只读回填、需填写字段可编辑。支持全部字段类型的渲染与校验，支持全局只读模式 | 3d |
| | 指派节点操作 | 当前节点为指派时，选择处理人并保存，完成人员分派 | 1d |
| | 执行节点操作 | 当前节点为执行时，展示需填写的表单字段并提交处置结果；多人抢单模式下需先接单再处置，接单后锁定响应时效并启动解决时效 | 1.5d |
| | 确认节点操作 | 当前节点为确认时，支持通过或驳回操作，驳回需填写原因；可配置是否强制填写验收意见 | 1d |
| | 按钮权限判定 | 根据工单状态、当前用户角色、当前节点类型三个维度自动判定每个操作按钮的可见性与可操作性 | 1.5d |
| | 工单归档 | 已关闭工单的独立检索页面，支持按时间范围、模板、优先级、服务时效结果筛选，支持导出 | 2.5d |
| | 统计看板 | 工单数据可视化分析：本月总量/达标率/平均处理时长/超时数等核心指标、近三十天趋势图、模板分布占比、处理人效率排行 | 4d |
| **发起工单** | 发起工单弹窗 | 从可用模板列表中选择模板，填写优先级、标题、备注及模板定义的发起字段，支持保存草稿或立即发起 | 2d |
| **跨企业协同** | 跨企业节点配置 | 定义跨企业协同节点：指定协作方需执行的子流程节点链，协作目标企业由运行时上下文动态确定，人员指派限制为平台级岗位 | 3d |
| | 父子工单关联 | 跨企业场景下父工单与子工单的关联：父工单可查看子工单进展，父→子数据自动带入，子→父处置结果自动回流 | 1.5d |
| **消息通知** | 站内消息中心 | 工单指派、服务时效预警、服务时效超时升级、审核结果等事件的站内通知，支持已读未读状态 | 2d |
| | 通知配置 | 各类型通知的开关控制与接收人设置 | 1d |
| | 语音/短信通知 | 服务时效红灯时自动电话通知责任人，紧急工单指派时自动发送短信 | 2d |
| **移动端（小程序）** | 框架搭建 | 项目初始化、路由、全局样式、网络请求封装、异常处理 | 2d |
| | 登录鉴权 | 微信授权登录、身份令牌管理、与服务商账号绑定 | 2d |
| | 待办列表 | 展示待接单与处置中的工单列表，支持下拉刷新与分页加载，显示待办数量角标 | 3d |
| | 工单详情 | 查看工单流程进度、已完成节点数据汇总、当前节点处置操作 | 2.5d |
| | 一键接单 | 确认接单后锁定响应时效、启动解决时效计时，工单状态变更为处置中 | 1d |
| | 处置表单 | 根据模板定义渲染处置表单，支持全部字段类型、表单校验与数据提交 | 4d |
| | 拍照上传 | 调用相机拍照、图片压缩、上传，支持必填校验与上传进度展示 | 1.5d |
| | 消息推送 | 工单指派、服务时效预警、审核结果等事件的微信服务通知推送 | 2d |
| | | **合计** | **72d** |
