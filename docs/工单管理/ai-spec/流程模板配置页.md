
# 页面2：流程模板配置页 — 设计文档

> 基于 Figma 设计稿更新：基础设置(node-id=4412-11011)、表单设计(node-id=4413-11448)、流程设计(node-id=4413-11633)、节点属性面板(4598-13065系列)。

## 一、页面元信息
| 项目 | 内容 |
| --- | --- |
| 页面名称 | 流程模板配置页 |
| 所属模块 | 工单管理 |
| 页面类型 | 多步骤配置 |
| 路由路径 | `/system/template/config/:id?` |


### 功能描述
流程模板的多步骤配置页面，包含基础设置、表单设计、流程设计三个步骤，支持新增模板和编辑已有模板。

---

## 二、页面结构

页面采用"面包屑置顶 + 工具栏卡片 + 工作区卡片"三层结构。

### 整体布局
| # | 区域名称 | 位置 | 注册表组件 | 包含元素 |
| --- | --- | --- | --- | --- |
| 1 | 面包屑行 | 顶部 | 自定义 | 返回列表按钮 + 模板名称 + 工单说明（左侧垂直排列） |
| 2 | 工具栏卡片 | 顶部 | 自定义 | 圆角卡片，横向布局：左侧模板名称+工单说明，中间自定义步骤指示器（①②③ 编号圆圈+标签），右侧操作按钮。当前步骤蓝色高亮 + 底部 4px 蓝线下划线。按钮按步骤显隐：步骤1=「取消+下一步」，步骤2-3=「上一步+下一步/发布」。查看模式仅显示「返回、上一步、下一步」导航按钮 |
| 3 | 工作区卡片 | 中部 | `el-card` | 圆角卡片包裹步骤内容，`flex:1` + `overflow:auto`。查看模式下所有表单字段 disabled |


### 步骤1：基础设置
| # | 区域名称 | 位置 | 注册表组件 | 包含元素 |
| --- | --- | --- | --- | --- |
| 1 | 基础信息表单 | 中部 | `el-form` | 模板名称（必填，input）+ 工单说明（input）+ 谁可发起工单（下拉选择器，点击弹出 PersonSelector） |
| 2 | SLA 配置 | 中部 | 自定义卡片组 | **2×2 四档优先级独立卡片**（非折叠面板）。每卡片：彩色头部(紧急=红/高=橙/普通=黄/低=蓝) + 优先级标题 + 说明文字"如果发起流程时选择此优先级，则按此时限监测" + 响应时限(分钟)输入 + 解决时限(分钟)输入。每输入框含帮助图标。无黄灯阈值滑块 |


### 步骤2：表单设计
| # | 区域名称 | 位置 | 宽度 | 注册表组件 | 包含元素 |
| --- | --- | --- | --- | --- | --- |
| 1 | 组件面板 | 左侧 | 332px | 自定义面板 | 上方「基础组件」3×2 网格：输入框、多行输入框、单选框、选择器、日期、上传。下方「业务组件」3 种：事件信息、异常信息、隐患信息 |
| 2 | 表单画布 | 中央 | flex:1 | `FormDesigner`（封装 `fc-designer`） | 拖拽组件构建表单，实时预览，支持排序、删除、复制。暴露 `getFields()` / `setFields()` 方法 |
| 3 | 属性面板 | 右侧 | 332px | 自定义面板 | 选中组件后显示：字段名称、标签位置、必填、宽度、校验规则、默认值、**字段来源**下拉（手动/自动/继承/回调） |

> 基于 FormCreate（fc-designer）封装。查看模式不可交互。下一步校验至少 2 个组件。


### 步骤3：流程设计
| # | 区域名称 | 位置 | 宽度 | 注册表组件 | 包含元素 |
| --- | --- | --- | --- | --- | --- |
| 1 | 流程可视化区 | 左侧 | flex:1 | 自定义 `FlowDesigner` | 线性节点链：预置"开始"→"结束"节点，节点间向下箭头连线 + "⊕"圆形按钮。节点卡片含类型图标(56×56px) + 节点名称(粗体) + 描述文字。悬浮显示删除按钮（总节点数≤2时隐藏）。点击选中高亮→右侧属性面板联动。开始/结束节点不可删除 |
| 2 | 节点属性面板 | 右侧 | 548px | 自定义 `NodePropertyPanel` | **按节点类型区分 Tab 数量和内容**（详见下方 Tab 结构表）。点击任意节点（含开始/结束）均可打开 |
| 3 | 节点类型选择弹窗 | 浮层 | — | `el-dialog` | 点击节点间"⊕"按钮触发。网格展示 5 种可选节点类型（指派/执行/审批/条件判断/跨企业协同），每种以图标+名称+描述卡片呈现。开始和结束节点不在弹窗中 |

> 进入页面默认选中第一个节点。


### 节点属性面板 Tab 结构

**按节点类型区分：**

| 节点类型 | Tab 数量 | Tab 名称 |
|---------|---------|---------|
| 开始 (start) | 2 | 节点信息 / 节点配置 |
| 指派 (assign) | 3 | 节点信息 / 表单权限 / 超时配置 |
| 执行 (execute) | 3 | 节点信息 / 表单权限 / 超时配置 |
| 确认 (confirm) | 3 | 节点信息 / 表单权限 / 超时配置 |
| 条件判断 (condition) | 2 | 节点信息 / 节点配置 |
| 跨企业协同 (external) | 2 | 节点信息 / 节点配置 |
| 关闭 (close) | 2 | 节点信息 / 节点配置 |

**各 Tab 内容：**

##### Tab「节点信息」
| 配置项 | 控件 | 适用节点 |
|--------|------|---------|
| 节点名称* | `el-input` | 全部 |
| 指派策略 | 三选一 radio（见下方指派策略表） | assign, execute, confirm |
| 操作按钮 | 通过按钮 + 驳回按钮（各配置目标节点） | confirm |
| 消息通知 | 开启/关闭 radio（"节点完成通知下一节点"） | 全部 |

**指派策略选项（按节点类型限制）：**

| 指派来源 | assign | execute | confirm |
|----------|:---:|:---:|:---:|
| 静态指派 (`static`) | ✅ | ✅ | ✅ |
| 动态表单字段 (`dynamic`) | ✅ | ✅ | ✅ |
| 指派给发起人 (`initiator`) | ❌ | ❌ | ✅ |

> 静态指派：PersonSelector 选人/岗位/部门/角色 + 多人模式（任一人接单 / 每人独立任务）。
> 动态表单字段：下拉选择步骤 2 中类型为"人员选择器"的表单字段。
> 指派给发起人：无需额外配置，仅确认节点可用。跨企业节点下人员选择仅限平台级岗位。

##### Tab「表单权限」
所有节点均显示。列出步骤 2 的全部表单字段，每行三态 radio（🔒隐藏 / 👁只读 / ✏️可编辑）。

默认规则：
- 发起节点：属于本节点的字段→可编辑，其他→只读
- 指派节点：全部→只读
- 执行节点：属于本节点的字段→可编辑，其他→只读
- 确认节点：属于本节点的字段→可编辑，其他→只读
- 关闭节点：全部→只读
- 未显式配置→默认为只读

##### Tab「超时配置」
> 仅执行(execute)、指派(assign)、确认(confirm)节点显示。

| 配置项 | 控件 | 说明 |
|--------|------|------|
| 节点完成时限 | 下拉选择器 | 单一完成时限（如"15分钟"），非 TTR/TTS 成对 |
| 超时提醒 | 开启/关闭 radio | 默认开启 |
| 超时前 | 下拉选择器 | 超时前多久发出提醒（如"10分钟"） |
| 超时通知方式 | 多选框 | 系统消息 / 手机短信 / 手机电话（可多选） |
| 抄送通知人员 | PersonSelector | 选择抄送岗位或人员 |

## 三、数据模型
### 3.1 模板完整详情（TemplateDetail）
| 字段名 | 中文名 | 类型 | 说明 |
| --- | --- | --- | --- |
| `id` | 模板ID | `number` | — |
| `baseInfo` | 基础设置 | `TemplateBase` | 见下方 |
| `formSchema` | 表单设计 | `FormSchema` | 按节点分组的表单字段 |
| `flowDefinition` | 流程定义 | `FlowDefinition` | 节点列表、连线、流转规则 |


**TemplateBase**:

```typescript
{
  name: string;                           // 模板名称（必填）
  description?: string;                   // 工单说明
  initiatorScope: 'all' | 'specified';   // 谁可发起工单
  initiatorUserIds?: number[];            // 指定人员ID
}
```

> SLA 四档配置（紧急/高/普通/低各自独立的 TTR/TTS）不属于 TemplateBase 的单一字段，而是存储在模板级 SLA 配置中。黄灯阈值由系统统一按 80% 计算，不暴露为可配置项。

**FormSchema**:

```typescript
{
  [nodeId: string]: {
    fields: Array<{
      id: string;
      type: string;           // input, textarea, radio, checkbox, select, date, upload, number
      label: string;
      required: boolean;
      source: 'manual' | 'auto' | 'inherited' | 'callback';
      defaultValue?: any;
      options?: Array<{ value: string; label: string }>;
      span?: number;
    }>;
  };
}
```

**FlowDefinition**:

```typescript
{
  nodes: Array<{
    id: string;
    type: 'start' | 'assign' | 'execute' | 'confirm' | 'close' | 'condition' | 'external';
    name: string;
    // 指派策略 — 按节点类型限制可选项
    assignSource?: 'static' | 'dynamic' | 'initiator';
    assignConfig?: {
      targetIds: number[];
      multipleMode: 'anyone' | 'each';     // 任一人接单 / 每人独立任务
    };
    dynamicAssignFieldId?: string;          // assignSource='dynamic' 时绑定的表单字段ID
    // 超时配置（仅 execute/assign/confirm 节点）
    nodeTimeoutMinutes?: number;            // 节点完成时限（单一值）
    timeoutWarningMinutes?: number;         // 超时前提前警告时间
    timeoutNotifyChannels?: Array<'in_app' | 'sms' | 'voice'>;
    timeoutCcPositionNames?: string[];
    // 操作按钮（仅 confirm 节点）
    actions?: Array<{
      name: string;                         // 按钮文字，如"通过""驳回"
      targetNodeId: string;
    }>;
    // 条件分支（仅 condition 节点）
    slaConditionConfig?: {
      branches: Array<{
        threshold: 'normal' | 'timeout';   // 正常 / 超时（2 分支 + 回流）
        targetNodeId: string;
        label: string;
      }>;
    };
    // 跨企业协同（仅 external 节点）
    crossEnterpriseConfig?: {
      childNodes: FlowNode[];              // 子流程节点链
    };
    // 字段权限
    formFields?: Array<{
      fieldId: string;
      mode: 'hidden' | 'readonly' | 'editable';  // 默认 'readonly'
    }>;
    // 消息通知
    notifyOnComplete?: boolean;
  }>;
  edges: Array<{
    from: string;
    to: string;
    condition?: string;
  }>;
}
```

## 四、接口定义
| 操作 | 方法 | 路径 | 请求类型 | 响应类型 |
| --- | --- | --- | --- | --- |

## 五、业务逻辑
### 5.1 状态流转
配置页不直接操作模板状态，草稿保存时模板状态保持"待生效"；点击"发布"后调用发布接口，状态变为"执行中"。

### 5.2 交互行为
| 操作 | 触发条件 | 行为描述 |
| --- | --- | --- |
| **查看模式** | 路由携带 `?mode=view` | 表单全部 disabled；工具栏仅显示"返回、上一步、下一步"（纯导航，无校验无保存） |
| **编辑模式** | 路由无 mode 参数 | 表单可编辑；工具栏显示完整按钮 |
| 下一步 | 编辑模式点击 [下一步] | 校验当前步骤必填项，通过后进入下一步 |
| 上一步 | 点击 [上一步] | 返回上一步，保留已填写内容 |
| 发布 | 最后一步点击 [发布] | 整体校验→调用发布接口→跳转列表页 |
| 取消 | 编辑模式点击 [取消] | 确认框"内容未保存，是否离开？"→跳转列表页 |
| 插入节点 | 点击节点间"⊕"→弹窗选类型 | 在当前位置插入新节点，默认名称为类型中文名 |
| 删除节点 | 悬浮节点→点击× | 节点总数≤2时隐藏删除按钮 |
| 配置节点 | 点击节点卡片 | 右侧属性面板显示该节点 Tab 配置 |

### 5.3 特殊规则
+ 开始节点和结束节点预置且唯一，不可删除、不可通过弹窗添加
+ 确认节点必须配置至少两个操作按钮（"通过""驳回"），并指定目标节点
+ 条件节点基于上一节点状态分支（正常/超时 2 分支），含回流机制
+ 跨企业协同节点零配置，目标企业由运行时上下文动态确定，内部含子流程节点链
+ `assignSource='static'` 时必须配置指派人员，否则校验不通过
+ `assignSource='dynamic'` 时必须绑定有效的表单字段
+ `assignSource='initiator'` 仅确认节点可用，无需额外配置
+ 字段权限默认规则见 Tab「表单权限」
