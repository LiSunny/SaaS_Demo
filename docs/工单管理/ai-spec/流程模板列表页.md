
# 页面1：流程模板列表页 — 设计文档

> 基于 Figma 设计稿 (node-id=3381-3735) 更新。页面位于侧栏「系统管理 > 工单管理 > 工单配置 > 列表」。

## 一、页面元信息
| 项目 | 内容 |
| --- | --- |
| 页面名称 | 流程模板列表页 |
| 所属模块 | 工单管理 |
| 页面类型 | 列表管理 |
| 路由路径 | `/system/template` |


### 功能描述
流程模板的列表管理页面，支持按名称/状态查询、新建模板、编辑模板、停用/启用、删除模板。

### 列表管理页布局

## 三、数据模型
### 3.1 实体字段（TemplateItem）
| 字段名 | 中文名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| `id` | 模板ID | `number` | 是 | 主键 |
| `name` | 模板名称 | `string` | 是 | max:50，唯一 |
| `status` | 状态 | `number` | 是 | 见状态枚举 |
| `nodeCount` | 节点数 | `number` | 是 | 流程中节点个数 |
| `fieldCount` | 字段总数 | `number` | 是 | 所有节点表单字段之和 |
| `code` | 模板编号 | `string` | 是 | 自动生成，格式 `MB-YYYYMMDD-NNNN` |
| `creator` | 创建人 | `string` | 是 | 可为人员或部门/岗位名称 |
| `createdAt` | 创建时间 | `string` | 是 | ISO 8601 |
| `updatedAt` | 更新时间 | `string` | 否 | ISO 8601 |


### 3.2 状态枚举
| 枚举值 | 标签文字 | 颜色 | 说明 |
| --- | --- | --- | --- |
| `0` | 待生效 | 蓝色 `#3678e3` | 新建或编辑后未发布 |
| `1` | 执行中 | 绿色 `#059669` | 已发布，可被实例使用 |
| `2` | 已停用 | 黄色 `#ca8a04` | 手动停用，不可用于新实例 |
| `3` | 已过期 | 灰色 `#364153` | 超过有效期的模板 |

## 六、业务逻辑
### 6.1 状态流转
```
[*] → 待生效(创建) → 执行中(发布) ⇄ 已停用(停用/启用)
       ↓ 删除            ↓ 版本覆盖
      [*]             已过期(仅历史实例使用)
```

### 6.2 交互行为
| 操作 | 触发条件 | 行为描述 |
| --- | --- | --- |
| 新建模板 | 点击 [新建工作流] | 跳转至 `/system/template/config`（无 id 参数），进入三步配置 |
| 编辑模板 | 点击行 [编辑图标] | 跳转至 `/system/template/config/{id}`，回填已有配置 |
| 删除模板 | 点击行 [删除图标] | 弹出确认框，若模板有关联进行中实例则禁止删除并提示 |
| 发布模板 | 仅在"待生效"状态下操作 | 调用发布接口，状态变为"执行中" |
| 停用/启用 | 点击行 [开关 toggle] | 即时变更状态 |
| 复制模板 | 点击行 [复制图标] | 基于现有模板创建副本 |


### 6.3 特殊规则
+ 执行中或已过期的模板不可删除（后端校验）
+ 已过期的模板不可重新启用
+ 删除模板时需检查是否有未完成的实例（草稿/进行中），如有则禁止删除并提示
+ 停用模板后，新实例不允许使用该模板；进行中的实例不受影响
+ 无多选框列、无批量删除功能
