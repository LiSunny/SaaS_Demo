## 一、项目概览

| 维度 | 港南项目 | neat-ui |
|------|---------|---------|
| 项目名 | wlw_six | 公共安全管理平台 v6.0 |

## 三、两端功能互补关系

```
移动端（现场操作）         Web 端（管理配置）
─────────────────         ─────────────────
巡查执行 + 拍照签字   ←→   巡查计划 + 表单模板配置
隐患上报 + 现场处理   ←→   隐患台账 + 分派 + 统计分析
动火 15 步操作流程   ←→   合规报告 + PDF 导出
设备扫码添加 + 绑定   ←→   设备批量导入 + 分类体系配置
离线数据采集         ←→   数据汇总 + 大屏可视化
告警核实 + 一键确认   ←→   事件规则 + 联动策略配置
```
