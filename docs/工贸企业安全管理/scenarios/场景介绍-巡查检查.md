## 背景

2023 年，应急管理部在对全国安全生产检查进行深度调研后，指出了一个普遍问题："查不出来、改不到位。"——检查人员在，但问题没发现。整改报告交了，但隐患没消除。

同年，国务院考核巡查组在吉林发现：一家企业的整改报告上写着"已整改完毕、符合规范"，但巡查组到现场一看，隐患原封不动。企业负责人把整改报告当"作业"交了——不是真的解决了问题，而是交了"答案"。

更触目惊心的案例是宁夏银川烧烤店爆炸（2023 年 6 月，31 人死亡）和齐齐哈尔体育馆坍塌（2023 年 7 月，11 人死亡）——两起重大事故都有一个共同点：**事故前一个月内，都有人做过安全检查，都没有发现问题。**

这不是说检查人员偷懒。而是说：**巡查的有效性取决于执行质量，而执行质量在缺乏系统约束的情况下，会不可阻挡地被人的惰性、惯性思维和"差不多就行"的心态侵蚀。**

| 痛点 | 传统做法 | 问题 |
|------|---------|------|
| 人到不到现场无法验证 | 纸质巡检表打钩签字，拍几张照发给管理者 | 人没到也能打钩，照片可以事后补。管理者看不到真实巡查轨迹 |
| 检查项靠记忆 | 巡检员凭经验"看一圈"，没有结构化的检查清单 | 今天记得查了这个忘了那个。重大隐患可能在"忘了"的那一项里 |
| 异常上报靠口头 | 发现了问题跟班组长说一声，口头上报 | 有没有处理、谁处理的、处理得怎么样——全在口头上，没有证据链 |
| 数据碎片化 | 每天的巡检表塞进文件夹，月底做 Excel | 每周完成率、每个点位的异常率、每个巡检员的质量——这些信息需要花大量时间手工统计 |
| 离线场景无法工作 | 地下水泵房、顶层设备间无网络 | 传统 App 在这些区域无法操作，只能事后靠记忆补录 |

平台的做法是把巡查从以纸质表为中心，变成以数字点为中心。**巡查计划**定义查什么、查几次、谁来查。**任务自动生成**，到时间推送。**扫码打卡**到点位验证位置，弹出的检查清单引导巡检员逐项核对，拍照上传作为证据。**异常点自动生成隐患流**，推送整改责任人，处理完拍照回传。整个流程不需要一张纸。对于地下水泵房、顶层设备间等无网络区域，离线模式支持断网执行，回到有网络的地方自动同步。

## 典型一天

### 08:00 ｜ 安全管理员看今天的巡查任务

安全管理员张工打开电脑上的巡查模块。系统今天自动生成了 3 条任务——A 区消防设施巡查（王师傅负责，12 个点位）、B 车间设备巡检（李师傅负责，8 个点位）、C 库房安全检查（赵师傅负责，5 个点位）。三个人的任务状态全部显示"待执行"。

张工不需要打电话分配任务——系统按计划自动分发到责任人的手机上了。他要做的是看"待执行"什么时候变成"执行中"，再变成"已完成"。

📷 截图：Web 端巡查任务管理页 — 今日任务列表 + 责任人 + 点位数量 + 完成进度 + 状态标签

---

### 09:00 ｜ 巡检员出发，到点位扫码打卡

巡检员王师傅拿着手机走到 A 区一楼走廊尽头——第一个巡查点位"消防栓-01"。他扫描点位上的二维码，系统弹出该点位的检查表单：消防栓外观是否完好、水带是否在位、水枪是否在位、阀门是否可正常开启。

📷 截图：移动端扫码巡查页 — 点位名称 + 检查项逐条 + 拍照区 + 手写签名

他逐一检查，拍到消防栓整体外观和水带的状态——提交，第一个点位完成打卡。系统自动记录扫码时间、位置、检查结果。12 个点位，王师傅按路线逐个完成。其中两个点位有问题：一个灭火器压力偏低，一个应急照明灯不亮——他标记为"异常"，拍照描述异常情况，提交。

---

### 10:30 ｜ 异常点自动流转到整改人

王师傅在 B 区标注的那两个异常点位不再是"王师傅跟班组长说了一声"。系统自动把这两条异常点推送到整改责任人——维保工程师小陈的手机上。

小陈打开手机，看到两条待处理的异常任务，里面附有王师傅拍的照片和异常描述。他带着新灭火器和应急灯备件，逐个到场更换。换好后拍照上传——处理前的异常照片和更换后的对比照片同时存在系统里。

📷 截图：移动端异常处理页 — 异常描述 + 异常照片 + 处理方案 + 处理后照片 + 签名区

---

### 17:00 ｜ 张工看一眼巡查报表

下班前张工打开巡查报表——今天 25 个巡查点位全部完成打卡，其中 23 个正常、2 个异常已处理。本月巡查覆盖率 96%——上周是 92%，有改善。他注意到赵师傅负责的点位本周完成时间比平均值慢了 40 分钟——下周需要提醒一下。

📷 截图：Web 端巡查报表 — 巡查覆盖率折线图 + 各巡检员完成效率对比 + 异常点位分布

以前张工不知道谁在认真查、谁在走过场。现在每个人都有一条轨迹。好与不好——数据说了算。

## 核心价值

| 角色 | 价值 |
|------|------|
| **安全管理员** | 巡查任务自动生成、自动分发，不再挨个打电话安排。完成率实时可见——谁做完了、谁还没开始 |
| **巡检员** | 扫码定位验证你到了现场，结构化的检查清单引导你逐项检查——不再凭记忆"看一圈"。拍照就是证据 |
| **整改责任人** | 异常点直接推送到你手机上——不需要等口头传达。处理前处理后的对比，就是你最好的"已处理"证明 |
| **企业负责人** | 本月巡检覆盖率、异常率、完成效率——三个数字就知道安全巡查有没有落到实处。不是看签到本，是看轨迹 |
| **全链条** | 从巡查计划到扫码打卡到异常上报到整改确认——全程数字记录。上级来查，翻的不是文件夹，是一条完整的时间线 |
