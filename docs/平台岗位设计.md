# 平台岗位设计

> 消防安全管理多租户 SaaS 平台岗位体系。本文档定义 9 个岗位及其权限、工作台布局，是后续所有功能设计的依据。
> 最后更新：2026-06-29（v1.2 精简企业管理员变体，去掉岗位级数据范围）。

---

## 一、组织架构

四方多租户模型：

| 租户 | 类型 | 简称 | 说明 |
|------|------|------|------|
| 阳光物业管理有限公司 | 物业方 | 阳光物业 | 消防安全责任主体，发起工单 + 组织验收 |
| 蓝盾消防技术服务公司 | 服务方 | 蓝盾消防 | 维保 / 检测 / 评估，承接工单 + 现场处置 |
| 应急管理局安全管理中心 | 监管方 | 应急管理局 | 政府监管执法，督办超时 + 核查验收 |
| 平台运营方 | 平台方 | — | SaaS 平台运营，租户管理 + 模板配置 |

每个租户有独立的组织树、用户体系和权限空间。平台管理员跨租户操作。

## 二、岗位清单

### 2.0 通用岗位 — 企业管理员

> 平台统一的企业管理员岗位，不区分企业类型。新增租户时自动分配此岗位。

| 属性 | 内容 |
|------|------|
| key | `org-admin` |
| 名称 | 企业管理员 |
| 适用企业 | 所有企业 |
| 使用频率 | 日常 |
| 渠道偏好 | Web |
| 核心职责 | 管理本企业用户账号与权限；企业信息配置；操作日志审计 |
| 工作台 | 用户管理 + 工单概览 + 维保概览 |
| 工单操作 | 仅查看 |

## 五、岗位 × 导航可见性（渐进式路线图）

当前所有岗位看到全量导航菜单。后续分三步实施：

| 阶段 | 策略 | 说明 |
|------|------|------|
| **当前** | 全量导航 | 所有岗位看到 6 个分组，不做过滤 |
| **阶段 1** | 默认展开/折叠 | 按岗位偏好设置各分组默认状态（已在 navigation.ts 实现 `defaultOpen`） |
| **阶段 2** | 可见性过滤 | 不在本岗位权限内的菜单节点自动隐藏 |
| **阶段 3** | 个性化推荐 | AI 驱动的工作台 + 导航推荐 |
