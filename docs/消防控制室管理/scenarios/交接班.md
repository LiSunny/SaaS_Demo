# 交接班

> 适用角色：消控值班员（交班人与接班人）  |  前置条件：双方均在岗，在同一消控室

## 操作步骤

1. **发起交接班**
   - 交班人在系统中点击「发起交接」
   - 系统自动汇总本班次关键信息：未处置的主机台账条目、设备异常状态、待跟进事项
   📷 截图：Web 端交接班发起页面，含数据继承清单

2. **接班人确认**
   - 接班人逐项查看继承清单
   - 确认无误后点击「确认接班」
   - 系统生成交接班档案
   📷 截图：Web 端接班人确认页面

3. **查看交接班记录**
   - 在「交接班」Tab 中可查看历史交接班记录
   - 筛选条件：全部 / 正常 / 异常
   - 点击异常记录可展开详情，查看具体违规项
   📷 截图：Web 端交接班档案列表

## 完成后的结果

交接班档案包含：班次日期、消控室、交接时间、交班人、接班人、违规数、状态。系统自动识别 8 类违规：单人交接、无证交接、未打卡、提前离岗、故障未交接、隐患隐瞒、超时、联签未存证。违规记录标红，事后可追溯。

## 常见问题

**Q: 如果只有一个人怎么交接？**
A: 法规要求消控室 24 小时双人值守。如果确实只有一人，系统会标记"单人交接"违规，建议联系安全管理员安排补岗。
