# 远程视频点名

> 适用角色：远程值守服务商 / 应急局监管员  |  前置条件：已登录，目标消控室有在岗值班人员

## 操作步骤

1. **选择点名对象**
   - 在 Web 端「远程点名」Tab 中，左侧显示在岗人员列表（按消控室分组）
   - 勾选需要点名的人员（可多选）
   - 已选人员显示在右侧操作区的标签中
   📷 截图：Web 端远程点名页面，左侧人员列表 + 右侧操作区

2. **发起点名**
   - 选择点名模式：有感点名（手动发起）/ 无感点名（AI 自动）
   - 点击「发起点名」，系统向被选人员推送点名请求
   - 值班员在手机上确认应答
   📷 截图：移动端点名应答页面

3. **填写核验表单**
   - 值班员应答后，发起人填写现场核验 5 项：
     - 消防主机状态
     - 联动设备状态
     - 应急物资状态
     - 门窗监控状态
     - 证件核验
   - 全部确认后提交，点名完成
   📷 截图：Web 端核验表单

## 完成后的结果

点名记录自动归档，包含应答人员、核验结果、时间戳。无人应答或核验不通过自动标记为异常。可在点名记录列表中按有感/无感模式筛选查看。

## 常见问题

**Q: 值班员不回应怎么办？**
A: 超时未应答自动标记为异常，系统通知企业管理方。可根据异常记录发起有针对性的后续检查。
