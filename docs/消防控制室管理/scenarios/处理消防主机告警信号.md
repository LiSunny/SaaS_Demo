# 处理消防主机告警信号

> 适用角色：消控值班员  |  前置条件：已登录，消防主机已接入系统

## 操作步骤

1. **查看告警信号**
   - 进入 Web 端「主机台账」Tab
   - 顶部统计卡片显示各类信号数量：火警（红）、故障（黄）、屏蔽（蓝）、监管（灰）、通讯异常（红）
   - 点击任意统计卡片可按该类型筛选
   📷 截图：Web 端主机台账页面，顶部统计卡片

2. **确认告警详情**
   - 在台账列表中点击一条信号，查看详细信息：信号时间、类型、点位编号、位置
   - 如需确认现场情况，切换到「实时监控」Tab 调取对应摄像头画面
   📷 截图：Web 端告警详情 + 实时监控画面

3. **处置并记录**
   - 确认为真实火情 → 标记为"已处置"，按预案处理
   - 确认为误报 → 标记为"误报"，填写误报原因
   - 处置完成后，记录自动归档
   📷 截图：Web 端处置操作对话框

## 完成后的结果

处置状态同步更新（待处置 → 处置中 → 已处置）。若超过 5 分钟未处置，信号自动升级提醒值班员和管理方。所有处置记录可追溯。

## 常见问题

**Q: 处置错了怎么办？**
A: 可在台账中找到该记录，点击「修改处置」更正。更正会留下修改记录。
