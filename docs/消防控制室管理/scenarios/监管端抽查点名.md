# 监管端抽查点名

> 适用角色：应急局监管员  |  前置条件：已登录，有监管权限

## 操作步骤

1. **选择被监管企业**
   - 在 Web 端左侧企业列表中选择一家企业
   - 右侧展示该企业所有消控室及当前值班人员
   - 可查看该企业近期的值班记录、预警记录作为背景参考
   📷 截图：监管端企业选择页面

2. **发起抽查点名**
   - 在「远程点名」Tab 中勾选目标值班人员
   - 点击「发起点名」，流程与值守服务商点名一致
   - 值班员应答后，填写核验表单提交
   📷 截图：监管端发起点名页面

3. **调取历史记录**
   - 需要调查历史情况时，在「值班记录」Tab 中筛选日期范围和打卡类型
   - 在「交接班」Tab 中查看历史交接班档案和违规记录
   - 所有记录含时间戳和操作人，可作为非现场执法依据
   📷 截图：监管端历史记录调取页面

## 完成后的结果

抽查点名记录自动归档至被监管企业的安全档案。监管员可定期导出报告，作为企业消防安全评级的参考依据。

## 常见问题

**Q: 抽查记录能作为执法依据吗？**
A: 系统记录含完整的时间戳、操作人、应答结果，可作为辅助证据。正式执法仍需按照法定程序进行。
