# 到岗打卡与巡检打卡

> 适用角色：消控值班员  |  前置条件：已登录，已绑定所属消控室

## 操作步骤

1. **到岗打卡**
   - 打开手机上的移动端应用
   - 在「值班记录」中点击「到岗打卡」
   - 系统自动记录打卡时间和位置
   📷 截图：移动端到岗打卡页面

2. **巡检打卡**
   - 按排班计划完成巡检后，在「值班记录」中选择「巡检打卡」
   - 确认巡检项目已完成
   - 提交后打卡记录自动计入值班档案
   📷 截图：移动端巡检打卡页面

3. **查看打卡记录**
   - 在 Web 端「值班记录」Tab 中可按日期筛选（今日 / 本周 / 本月）
   - 可按打卡类型筛选（到岗 / 交接班 / 巡检）
   📷 截图：Web 端值班记录列表，含筛选条件

## 完成后的结果

打卡记录实时同步到管理端，安全管理员和远程值守服务商可查看。连续 3 日缺勤自动标记为"重点关注"，值班员卡片上红色闪烁提醒。

## 常见问题

**Q: 忘记打卡怎么办？**
A: 系统会自动记录缺勤。如有特殊情况，联系安全管理员在后台补录并备注原因。
