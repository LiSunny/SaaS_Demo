# 维保计划模块 — 详细设计

## 1. 概述

维保计划是维保三层架构（台账→计划→任务）的中间层，定义"何时做、谁来做"——即服务商每月为各业主单位编排的维保工作安排。计划创建时选择维保覆盖的消防系统，该系统下全部设备自动纳入计划，指定执行人员后启用计划，系统自动生成任务并分发给指定人员。

**涉及角色：** 服务商端（编排和管理），业主端（不可见）

**模块定位：**

```
维保台账（What）              维保计划（When & Who）           维保任务（Do）
┌──────────────────┐         ┌────────────────────┐         ┌────────────────┐
│ 维护设备清单      │──→      │ 制定维保工作安排    │──→      │ 执行维保检查   │
│ · 设备编码/名称   │         │                     │         │ · 按区域/系统  │
│ · 系统类别        │         │ · 选择维保系统       │         │ · 记录结果    │
│ · 建筑/位置       │         │ · 设定执行期限      │         │ · 上报故障    │
│ · 维保周期(月/季/年)│        │ · 指定维保人员      │         │ · 完成闭环    │
│ · 分值            │         │ · 启用后自动生成任务 │         └────────────────┘
└──────────────────┘         │ · 任务自动分发至执行人│
                              └────────────────────┘

约束：台账→计划→任务逐层依赖，不可跳级
```

---

## 2. 核心概念

### 2.1 什么是维保计划

维保计划是服务商为业主单位编排的**周期性维保工作安排**，决定"哪些设备在什么时间由谁去做"：

- **服务商端**：创建计划、按条件检索设备、分配人员、启用/停用
- **业主端**：无维保计划页面，通过维保任务查看执行进度

### 2.2 计划与台账、任务的关系

| 维度 | 与台账的关系 | 与任务的关系 |
|------|------------|------------|
| 数据来源 | 选择维保系统（计划启用时解析为该系统下全部设备） | 计划启用后自动生成维保任务 |
| 分值 | 汇总所选设备的分值总和 | 任务继承该总分，不可修改 |
| 变更影响 | 计划创建后台账修改不影响已有计划 | 任务生成后计划变更不影响已有任务 |

### 2.3 分值汇总规则

- 创建计划时选择维保系统，系统自动计算所选系统下全部设备的分值总和
- 分值总和在计划层面固定展示，作为该计划的总分值
- 任务生成时直接继承该总分，用于后续完成率计算

## 3. 计划状态机

### 3.1 状态定义

| 状态 | 含义 | 是否终态 |
|------|------|---------|
| 未启用 | 计划已创建，待启用 | 否 |
| 已启用 | 计划已激活，系统已自动生成任务并分发 | 否 |
| 已停用 | 计划已停用，无法生成新任务 | 否 |

### 3.2 状态流转图

```
  创建计划
      │
      ▼
  ┌────────┐
  │ 未启用  │
  └───┬────┘
      │
  启用计划（自动生成任务）
      │
      ▼
  ┌────────┐        ┌────────┐
  │ 已启用  │──停用──→│ 已停用  │
  └───┬────┘        └───┬────┘
      │                  │
      │              重新启用
      └──────────────────┘
```

### 3.3 状态机说明

| 状态 | 数据可编辑 | 允许的操作 | 说明 |
|------|-----------|-----------|------|
| **未启用** | 是（编辑/删除） | 编辑、删除、上传确认函（可选） | 草稿状态，计划信息可任意修改 |
| **已启用** | 否 | 停用 | 计划生效中。启用时**自动生成维保任务并分发给指定人员** |
| **已停用** | 否 | 重新启用 | 计划暂停，无法生成新任务，历史任务保留。可重新激活回已启用 |

**状态机约束规则：**
1. **单向递进** — 未启用 → 已启用，不可回退（已停用除外）
2. **停用/启用可逆** — 已启用 ↔ 已停用 可双向切换
3. **编辑权限封闭** — 仅"未启用"状态下允许编辑和删除，启用后所有字段锁定
4. **任务生成依赖** — 启用时自动生成任务，无需手动触发
5. **确认函可选** — 业主确认函不是状态转移的前置条件，可录可不录

### 3.4 各状态下可执行的操作

| 当前状态 | 可操作 | 说明 |
|---------|-------|------|
| 未启用 | 编辑、删除、上传确认函（可选） | 确认函不影响状态流转 |
| 已启用 | 停用 | 停用后已有任务仍可执行 |
| 已停用 | 重新启用 | 重新启用后生成新一轮任务 |

### 3.5 状态转移确认提示

| 前往状态 | 确认提示 |
|---------|---------|
| 已启用 | "确认启用此计划？启用后系统将自动生成维保任务并分发至指定人员" |
| 已停用 | "确认停用此计划？停用后无法生成新任务，但已有任务不受影响" |

## 4. 计划包含的信息

| 信息类别 | 字段 | 必填 | 说明 |
|---------|------|------|------|
| **基本信息** | 计划名称 | 是 | 系统按规则自动生成（可手动修改） |
| | 所属企业 | 是 | 该计划针对的业主单位，从已关联的企业中选择 |
| | 负责人 | 是 | 从人员名单中选择 |
| **周期与时间** | 维保周期类型 | 是 | 月检 / 季检 / 年检，用于计划名称自动生成 |
| | 开始日期 | 是 | 计划执行起始日 |
| | 结束日期 | 是 | 计划执行截止日 |
| | 计划完成天数 | 系统自动计算 | 结束日期 − 开始日期 |
| **系统选择** | 维保系统 | 是（多选） | 选择维保覆盖的消防系统，计划自动覆盖该系统下该企业的全部设备 |
| | 覆盖设备数 | 系统自动计算 | 所选系统下该企业的设备总数 |
| | 总分值 | 系统自动汇总 | 所选系统下全部设备的分值总和 |
| **人员** | 分配维保人员 | 是 | 可多选，任务自动分发至所选人员 |
| **签到配置** | 需要位置 | 否 | 勾选后，签到时需记录位置信息 |
| | 需要拍照 | 否 | 勾选后，签到时需拍摄现场照片 |
| **确认函（可选）** | 业主确认函 | 否 | PDF 格式，不上传不影响计划使用 |
| | 确认时间 | 系统自动记录 | 上传确认函的日期 |
| | 确认上传人 | 系统自动记录 | 上传确认函的操作人 |
| **启用** | 启用时间 | 系统自动记录 | 计划启用的日期 |

## 5. 计划名称生成规则

计划名称按规则自动生成，格式为 **{年月}+{维保类型}+维保计划**：

| 周期类型 | 格式 | 示例 |
|---------|------|------|
| 月检 | `{YYYY}年{MM}月月检维保计划` | 2026年5月月检维保计划 |
| 季检 | `{YYYY}年第{Q}季度季检维保计划` | 2026年第2季度季检维保计划 |
| 年检 | `{YYYY}年年检维保计划` | 2026年年检维保计划 |

> 名称自动生成后可手动修改，不强制限制唯一性。

## 6. 创建计划业务流程

### 6.1 创建流程

```
选择合同 → 选择周期类型 → 设定日期范围 → 选择维保系统 → 指定人员 → 保存计划
  ①          ②              ③             ④           ⑤          ⑥
```

#### ① 选择合同
从已签约合同列表中选择。选择框中要显示合同名称及签约企业；选中的企业决定了后续计划涉及系统设备检索的范围。

#### ② 选择周期类型
选择本次计划的维保类型，用于计划名称自动生成：

| 周期类型 | 说明 |
|---------|------|
| 月检 | 计划名称生成"X月月检维保计划" |
| 季检 | 计划名称生成"X季度季检维保计划" |
| 年检 | 计划名称生成"X年年检维保计划" |

> 周期类型仅用于计划名称生成，不影响设备选择范围。所有设备均可选择加入任何类型的计划。

#### ③ 设定日期范围
- 开始日期：计划开始执行的日期
- 结束日期：计划完成的截止日期
- 系统自动计算"计划完成天数"

#### ④ 选择维保系统
从该企业维保台账覆盖的消防系统中，勾选本次计划需要维保的系统。选定系统后，该系统下的**全部设备**自动纳入计划，无需逐台选择。

从人员列表中选择本次计划的维保执行人（可多选）：
- 展示人员姓名、岗位、所属部门
- 支持搜索过滤

#### ⑥ 保存计划
- 计划以"未启用"状态保存
- 出现在维保计划列表中

### 6.3 校验规则

- 所属企业必选，无已关联企业时无法创建计划
- 开始日期不能早于当日
- 结束日期不能早于开始日期
- 至少选择一个系统
- 至少分配一名维保人员
- 计划名称不能为空

## 7. 启用与自动生成任务

### 7.1 启用流程

```
计划列表 → 点击「启用」→ 二次确认 → 系统自动处理 → 完成
  ①            ②             ③         ④            ⑤
```

**① 前提条件：** 计划状态为"未启用"

**② 操作入口：** 计划列表操作列 / 计划详情顶部操作栏

**③ 二次确认弹窗：**
```
┌──────────────────────────────────────────────┐
│  确认启用计划                                  │
│                                              │
│  计划名称：2026年5月月检维保计划             │
│  周期类型：月检                               │
│  覆盖系统：2 个    设备数量：7 台    总分：120 分 │
│  执行人员：张三、李四                          │
│  开始日期：2026-05-01    结束日期：2026-05-31  │
│                                              │
│  启用后将自动生成维保任务并分发至执行人员        │
│                                              │
│  [  取消  ]        [  确认启用  ]              │
└──────────────────────────────────────────────┘
```

**④ 系统自动处理（启用时自动完成，无需人工干预）：**

| 步骤 | 说明 |
|------|------|
| 1. 生成任务 | 按计划所选系统，解析该企业下对应系统的全部设备，生成维保任务 |
| 2. 分配任务 | 任务关联到指定的维保人员（张三、李四），出现在各自的待办列表中 |
| 3. 继承数据 | 任务继承计划中的设备列表、分值总和、签到配置 |
| 4. 更新状态 | 计划状态 → 已启用 |

**⑤ 完成后：** 计划状态变为"已启用"，任务列表中新增对应任务，维保人员可在待办中看到。

### 7.2 任务分配规则

| 规则 | 说明 |
|------|------|
| 任务数量 | 计划启用时自动生成**一个任务**，涵盖计划中所有设备 |
| 重新启用 | 计划停用后重新启用，**再次生成一个新任务**（历史任务保留） |
| 执行人 | 计划中指定的所有维保人员均可执行该任务 |
| 状态初始 | 任务生成时状态为"待执行" |
| 待办通知 | 任务自动出现在指定人员的待办工作台中 |
| 业主可见 | 任务生成后业主端可查看执行进度 |

## 8. 业主确认函（可选）

### 8.1 定位

业主确认函不再是计划流转的必要条件。它是一个**可选的附件记录**——如果已和业主线下确认，可上传确认函作为凭证，不上传也不影响计划正常使用。

### 8.2 规则

| 规则 | 说明 |
|------|------|
| 文件格式 | PDF |
| 上传时机 | 任何状态下均可上传（未启用/已启用/已停用） |
| 上传方式 | 计划详情页 → 上传确认函 |
| 上传后 | 记录文件名、上传时间、上传人 |
| 覆盖 | 允许重新上传覆盖旧文件 |
| 对状态的影响 | **无影响**——不上传确认函的计划同样可以启用 |

## 10. 数据联动关系

### 10.1 与其它模块联动

```
维保台账 ──展示全部设备──→ 按系统选择，计划启用时解析为具体设备列表
         新增/删除设备──→ 计划启用时动态解析最新设备列表
                        （已有任务不受影响）

维保任务 ──计划启用──→ 系统自动生成任务并分发给指定人员
         任务执行──→ 执行结果写入设备保养记录

服务企业 ──关联新企业──→ 计划"所属企业"下拉增加
         解除关联──────→ 已有计划保留，不可为该企业创建新计划
```

### 10.2 联动规则矩阵

| 触发动作 | 影响范围 | 效果 |
|---------|---------|------|
| 新增设备 | 计划启用时 | 动态解析为最新设备列表 |
| | 已有任务 | 不受影响（任务快照已固定） |
| 修改设备信息 | 计划启用时 | 反映最新数据 |
| | 已有任务 | 不受影响（快照） |
| 删除设备 | 计划启用时 | 动态解析时自动排除 |
| | 已有维保任务 | 不受影响 |
| 计划启用 | 维保任务 | 自动生成任务并分发 |
| 计划停用 | 维保任务 | 可继续执行已有任务，无法生成新任务 |
| 解除企业关联 | 维保计划 | 已有计划保留 |

## 11. 业务边界场景

| 场景 | 处理方式 |
|------|---------|
| **无已关联企业时创建计划** | 企业下拉为空，提示"请先关联业主单位" |
| **所选企业下无设备** | 提示"该企业暂无维保设备，请先在维保台账中添加" |
| **所选企业下无系统** | 系统列表为空，提示"该企业暂无维保系统数据" |
| **开始日期早于当日** | 校验不通过，提示"开始日期不能早于当前日期" |
| **结束日期早于开始日期** | 校验不通过，提示"结束日期不能早于开始日期" |
| **计划已启用后尝试修改** | 已启用计划不可编辑。如需修改应停用后重新创建 |
| **计划列表为空** | 引导用户创建第一个计划 |
| **上传确认函后再次上传** | 允许覆盖，更新时间/上传人 |
| **停用后重新启用** | 重新生成新一轮任务，历史任务保留 |
| **删除计划** | 仅在"未启用"状态下允许删除，删除后不可恢复 |
| **同一周期类型多次创建** | 允许同一企业同一周期类型创建多个计划 |
| **跨月度/季度创建** | 计划名称按所选日期所属月份生成 |

## 12. 历史计划管理

### 12.1 问题背景

维保计划随业务持续累积，已停用的历史计划不可删除（下游任务记录依赖计划作为追溯来源，见 3.3 状态机约束规则）。若不加管理，列表会随时间膨胀，淹没有效信息。

**典型数据量估算：** 一个服务商管理 10 个业主，每月 1 次月检 + 每季度 1 次季检 + 每年 1 次年检，每年约 170 个计划。5 年累积约 850 条。

### 12.2 默认时间范围筛选

计划列表**默认仅展示近 6 个月**的计划（以 `createdAt` 判断）。超过 6 个月的计划通过时间范围选择器手动切换查看。

| 时间范围选项 | 说明 |
|-------------|------|
| 近 1 个月 | 默认不选，需手动选择 |
| 近 3 个月 | 默认不选，需手动选择 |
| 近 6 个月 | **默认选中** |
| 近 1 年 | 手动切换 |
| 全部 | 不推荐频繁使用，数据量大时加载较慢 |

### 12.3 归档机制

已停用且 `createdAt` 超过 **12 个月** 的计划自动进入"历史归档"状态：

| 规则 | 说明 |
|------|------|
| 归档条件 | 状态 = 已停用 AND `createdAt` > 12 个月前 |
| 列表展示 | 主列表默认隐藏已归档计划 |
| 查看入口 | 列表顶部"含历史归档"开关，默认关闭 |
| 归档数据 | 仍可查看详情、查看关联任务，不可编辑、不可删除、不可重新启用 |
| 重新启用 | 已归档计划如需复用，应基于原合同和台账创建新计划 |

### 12.4 各状态下可执行操作（含归档）

| 状态 | 编辑 | 删除 | 启用/停用 | 上传确认函 |
|------|------|------|----------|-----------|
| 未启用 | ✅ | ✅ | ✅ 启用 | ✅ |
| 已启用 | — | — | ✅ 停用 | ✅ |
| 已停用 | — | — | ✅ 重新启用 | ✅ |
| 已归档 | — | — | — | ✅（仅查看） |
