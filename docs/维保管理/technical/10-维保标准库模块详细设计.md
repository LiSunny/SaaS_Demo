# 维保标准库模块 — 详细设计

## 1. 概述

维保标准库是维保台账的**上游配置中心**，定义"按什么标准维保"——即消防系统分类、设备类型、维保项目与标准、维保周期的完整知识库。维保台账在新增设备时，系统类别和设备类型来源于此；维保任务执行时，维保项目与标准作为检查依据。

**本模块将系统类别管理、设备类型管理、维保项目与标准管理整合在一个功能页面中，支持批量导入。**

**涉及角色：** 仅服务商端（管理端）

**模块定位：**

```
维保标准库（Config）        维保台账（What）           维保计划（When & Who）
┌────────────────┐         ┌────────────────┐        ┌────────────────┐
│ 维护维保标准    │──→      │ 引用系统/设备   │──→     │ 引用设备        │
│ · 系统类别     │         │                │        │                │
│ · 设备类型     │         │ 创建设备记录    │        │ 编排维保计划    │
│ · 维保项目标准  │         │                │        │                │
│ · 维保周期     │         └────────────────┘        └────────────────┘
└────────────────┘
```

**参考标准：** DB 13/T 3035—2023《建筑消防设施维护保养技术规范》（京津冀区域协同标准）

## 2. 数据模型

### 2.1 四级层级结构

```
系统类别（如"火灾自动报警系统"）
  └── 设备类型（如"点型感烟探测器"）
        └── 维保项目（如"探测器安装牢固情况及报警功能检查"）
              └── 维保标准（技术要求说明文字）
                    维保周期（月/季/半年/年）
```

**与河北地标的映射关系：**

| 河北地标章节 | 对应 M10 字段 | 说明 |
|-------------|-------------|------|
| 技术要求 | 维保标准 | 合格判定的技术基线，维保员据此判断正常/异常 |
| 检查内容 | 项目内容 | 维保员逐条执行的检查操作清单 |
| 维护要求 | 项目内容 | 清洁/润滑等操作，同样作为检查项执行 |

> **业务现实**：维保员执行维保时，统一按检查内容检查，按技术要求评估正常/异常并上传平台。"清洁""润滑"等维护要求对维保员来说就是一项检查工作，不需要单独分类。

### 2.2 字段定义

#### 系统类别

| 字段 | 必填 | 说明 |
|------|------|------|
| 系统名称 | 是 | 如"火灾自动报警系统" |
| 编码缩写 | 是 | 2-6 位大写字母，用于设备编码自动生成（如 MHQ） |
| 排序号 | 否 | 控制展示顺序 |
| 状态 | 是 | 启用 / 停用 |

#### 设备类型

| 字段 | 必填 | 说明 |
|------|------|------|
| 设备类型名称 | 是 | 如"点型感烟探测器""消防水泵" |
| 所属系统类别 | 是 | 关联到系统分类体系 |

#### 维保项目

| 字段 | 必填 | 说明 |
|------|------|------|
| 项目内容 | 是 | 维保操作描述，如"检查火灾探测器安装牢固情况及报警功能" |
| 所属设备类型 | 否 | 关联到设备类型（可空，表示该系统类别下的通用项目） |
| 所属系统类别 | 是 | 关联到系统分类体系 |
| 维保标准 | 是 | 技术要求说明文字，作为检查合格与否的判定基线 |
| 维保周期 | 是 | 月 / 季 / 半年 / 年 |
| 排序号 | 否 | 控制检查项在任务执行页的展示顺序 |
| 需要上传照片 | 否 | 默认不勾选。勾选后维保任务执行时，该检查项必须上传至少 1 张照片才能提交结果 |

### 3.2 左侧树：系统分类导航

- 第一项"全部"：展示所有系统的维保项目，按系统类别分组
- 点击具体系统：过滤展示该系统的设备类型和维保项目
- 系统名称后显示该系统的维保项目总数
- 支持在树节点上右键/悬停操作：编辑系统名称、停用

### 3.3 右侧主区域

**操作栏：**
| 按钮 | 说明 |
|------|------|
| + 新增设备类型 | 在当前系统类别下新增设备类型 |
| + 新增维保项目 | 在当前系统类别下新增维保项目 |
| 导入 CSV | 批量导入维保项目数据 |

**筛选：**
- 设备类型下拉：筛选该类别下的特定设备类型
- 周期筛选：月/季/半年/年，多选

**表格列：**

| 列 | 说明 |
|----|------|
| # | 序号 |
| 设备类型 | 关联的设备类型名称（可空，表示通用项目） |
| 项目内容 | 维保操作描述 |
| 维保标准 | 技术标准说明（鼠标悬停可查看完整内容） |
| 周期 | 月/季/半年/年，带颜色标签 |
| 拍照 | 勾选时显示 📷，表示执行时需上传照片 |

## 6. 与维保台账的联动

```
维保标准库                    维保台账                  维保任务
┌─────────────┐             ┌──────────────┐        ┌──────────────┐
│ 系统类别     │── 下拉来源 → │ 新增设备时    │        │              │
│ 设备类型     │── 模板参考 → │ 选择系统类别  │        │ 引用维保标准  │
│ 维保项目标准  │             │ 选择设备类型  │──→     │ 作为检查依据  │
│ 需要上传照片  │             │ 自动填入周期  │        │ 执行逐项检查  │
└─────────────┘             └──────────────┘        └──────────────┘
```

**联动规则：**
1. 维保台账新增设备时，系统类别下拉来源于维保标准库中已启用的系统类别
2. 选择系统类别后，设备类型下拉展示该类别下的设备类型列表
3. 维保任务执行时，任务从计划继承设备列表，同时关联维保标准库中的维保项目和标准作为检查依据
4. 维保标准库中维保项目的排序号决定任务执行页检查项的展示顺序

## 8. 业务边界场景

| 场景 | 处理方式 |
|------|---------|
| **停用系统类别** | 已有设备不受影响，台账新增设备时不可选该类别。标准库中该类别灰显 |
| **删除设备类型** | 检查是否被维保项目引用，被引用时提示确认 |
| **删除维保项目** | 不影响已有任务（任务继承快照），仅影响后续任务生成时的检查依据 |
| **维保标准超长文本** | 表格中以省略号截断，悬停或点击展开查看完整标准 |
| **CSV 导入部分失败** | 有效数据正常导入，失败记录提供错误原因下载 |
| **设备类型为空的项目** | 表示该维保项目为通用项目，适用于该系统类别下的所有设备 |
| **修改拍照要求** | 已有任务不受影响（任务继承快照），仅影响后续任务生成时的检查项配置 |
