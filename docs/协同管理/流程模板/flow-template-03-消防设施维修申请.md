## 一、基础信息

### 1.1 流程元信息

| 字段 | 值 |
|------|-----|
| 模版名称 | **消防设施维修申请** |

| 创建人 | 超级管理员 |

### 1.2 工单说明(粘贴到"工单说明"字段)

```
本流程用于消防设施(消火栓、灭火器、火灾报警器、应急照明、喷淋头、防火门等)故障或损坏的维修申请。

【适用场景】1)日常巡查发现设施损坏;2)维保检查判定需维修;3)消防演练测试发现异常。

【不适用场景】1)设施采购请使用【物资采购审批流程】;2)紧急火警请使用【应急事件上报】。

【时效要求】一般故障 3 日内修复,重大故障 24 小时内修复。

【典型审批节点】申请人 → 部门安全员 → 消防安全管理人 → 维保单位 → 验收。

【必填项】设施名称、设施位置、故障类型、故障描述、故障照片。

【最佳实践】1)故障定位精准(消火栓编号、楼层);2)先报修再断设施,不要影响正常使用;3)紧急情况同步电话通知维保单位;4)维修后必须验收并填写结论。
```

### 1.3 SLA 默认配置

| 优先级 | 响应时限(分钟) | 解决时限(分钟) | 适用场景 |
|--------|---------------|---------------|----------|
| 紧急 | 30 | 1440 | 重大故障(24h) |
| 高 | 60 | 4320 | 较大故障(3 天) |
| 普通 | 120 | 10080 | 一般故障(7 天) |
| 低 | 240 | 20160 | 轻微故障(14 天) |

## 三、字段详细配置

### 字段 1:设施名称

| 配置项 | 值 |
|--------|-----|
| 组件类型 | select |
| 字段 ID | `facilityName` |
| 数据源 | 设备台账 API:`/api/facilities` |
| 占位文本 | `请选择设施(自动关联位置)` |
| 验证规则 | 必填 |

| 配置项 | 值 |
|--------|-----|
| 组件类型 | input |

|--------|-----|
| 组件类型 | input |
| 字段 ID | `facilityLocation` |
| 占位文本 | `例如:教学楼-1 层-大厅` |
| 验证规则 | 必填,最长 50 字 |

| 配置项 | 值 |
|--------|-----|
| 组件类型 | radio |
| 字段 ID | `facilityType` |

| 配置项 | 值 |
|--------|-----|
| 组件类型 | checkbox |
| 字段 ID | `faultTypes` |
| 选项 | 损坏 / 卡死 / 锈蚀 / 失效 / 缺失 / 误报 / 漏水 |

### 字段 6:故障等级

| 配置项 | 值 |
|--------|-----|
| 组件类型 | radio |
| 字段 ID | `faultLevel` |
| 选项 | 一般 / 较大 / 重大 |
| 默认值 | `一般` |

| 配置项 | 值 |
|--------|-----|
| 组件类型 | textarea |
| 字段 ID | `description` |
| 占位文本 | `例如:消火栓箱门损坏,水带老化,无法正常开启使用` |

| 配置项 | 值 |
|--------|-----|
| 组件类型 | upload |
| 字段 ID | `photos` |

| 配置项 | 值 |
|--------|-----|
| 组件类型 | checkbox |
| 字段 ID | `impactScope` |
| 选项 | 单点位失效 / 区域失效 / 系统联动失效 |

### 字段 10:预计费用

| 配置项 | 值 |
|--------|-----|
| 组件类型 | inputNumber |
| 字段 ID | `estimatedCost` |
| 单位 | 元 |
| 最小值 | 0 |
| 验证规则 | 当 estimatedCost ≥ 5000 时,需走财务审批 |

### 字段 11:期望完成时间

| 配置项 | 值 |
|--------|-----|
| 组件类型 | datePicker |
| 字段 ID | `expectedDate` |
| 默认值 | 当前日期 + 3 天 |

### 字段 12:工单编号

| 配置项 | 值 |
|--------|-----|
| 组件类型 | serialNumber |
| 字段 ID | `repairNo` |

## 五、流程节点清单

```
[开始] → [部门安全员审核] → [消防安全管理人审批] → [维保单位派单] → [维修执行] → [验收] → [结束]
                            ↘(费用 ≥ 5000)→ [财务审批]
```

| 节点 | 类型 | 处理人 | SLA |
|------|------|--------|-----|
| 开始 | start | - | - |
| 部门安全员审核 | approval | 角色:部门安全员 | 2h |
| 消防安全管理人审批 | approval | 角色:消防安全管理人 | 4h |
| 财务审批(条件) | approval | 角色:财务 | 1d |
| 维保单位派单 | task | 角色:维保单位管理员 | 4h |
| 维修执行 | task | 角色:维保工程师 | 按故障等级 |
| 验收 | approval | 角色:部门安全员 | 1d |
| 结束 | end | - | - |
