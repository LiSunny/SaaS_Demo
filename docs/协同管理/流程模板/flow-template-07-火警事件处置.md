### 1.2 工单说明(粘贴到"工单说明"字段)

```
本流程用于火警报警的响应与处置闭环。

【适用场景】消防控制室收到火警报警后,值班人员现场确认并处置的全过程记录。

【不适用场景】1)日常隐患排查请使用【火灾隐患排查上报】流程;2)设施故障请使用【故障事件处置】流程。

【时效要求】15 分钟内响应并处置。

【典型审批节点】报警确认 → 现场处置 → 领导审核 → 归档。

【必填项】报警位置、警情类型、确认时间、处置过程、处置结果。

【最佳实践】1)值班人员必须在 15 分钟内现场确认;2)处置过程要详细记录,包括到场时间、发现情况、采取的措施;3)误报要说明原因。
```

### 1.3 SLA 默认配置

| 优先级 | 响应时限(分钟) | 解决时限(分钟) | 适用场景 |
|--------|---------------|---------------|----------|
| 紧急 | 15 | 60 | 火警报警响应(15min 响应) |

## 三、字段详细配置

### 字段 1:报警位置

| 配置项 | 值 |
|--------|-----|
| 组件类型 | input |
| 字段 ID | `alarmLocation` |
| 占位文本 | `请输入报警位置,如:教学楼 3 层 301 教室` |
| 验证规则 | 必填,最长 100 字 |

### 字段 2:警情类型

| 配置项 | 值 |
|--------|-----|
| 组件类型 | radio |
| 字段 ID | `alarmType` |
| 选项 | 火警 / 故障 / 误报 / 测试 |
| 验证规则 | 必填 |

### 字段 3:报警时间

| 配置项 | 值 |
|--------|-----|
| 组件类型 | datePicker |
| 字段 ID | `alarmTime` |
| 类型 | datetime |
| 默认值 | 当前时间(只读) |
| 格式 | YYYY-MM-DD HH:mm:ss |

### 字段 4:确认时间

| 配置项 | 值 |
|--------|-----|
| 组件类型 | datePicker |
| 字段 ID | `confirmTime` |
| 类型 | datetime |
| 格式 | YYYY-MM-DD HH:mm |
| 验证规则 | 必填,不能早于报警时间 |

### 字段 5:确认人

| 配置项 | 值 |
|--------|-----|
| 组件类型 | userSelect |
| 字段 ID | `confirmUser` |
| 选择范围 | 消控室值班人员 |
| 验证规则 | 必填 |

### 字段 6:现场情况

| 配置项 | 值 |
|--------|-----|
| 组件类型 | textarea |
| 字段 ID | `sceneDescription` |
| 占位文本 | `请描述现场查看情况,例如:现场无火情,发现为厨房油烟过大导致报警` |

| 配置项 | 值 |
|--------|-----|
| 组件类型 | textarea |
| 字段 ID | `disposalMeasure` |
| 占位文本 | `请描述采取的处置措施,例如:现场确认为误报,复位报警设备,加强该区域巡查` |

| 最长 | 500 字 |
| 验证规则 | 必填,至少 10 字 |

### 字段 8:处置结果

| 配置项 | 值 |
|--------|-----|
| 组件类型 | radio |
| 字段 ID | `disposalResult` |
| 选项 | 已处置 / 待跟进 / 升级处理 |
| 验证规则 | 必填 |

### 字段 9:涉及设备

| 配置项 | 值 |
|--------|-----|
| 组件类型 | deviceSelect |
| 字段 ID | `relatedDevice` |
| 设备类型 | 消防报警设备 |

| 配置项 | 值 |

## 七、操作步骤

### 步骤 1:创建流程模板

1. 进入「协同管理 → 流程编排」
2. 点击「新建流程」
3. 填写基础信息:
   - 模版名称:火警事件处置
   - 工单说明:粘贴 §1.2 内容
   - 谁可发起:消控室值班员

### 步骤 2:配置表单

1. 点击「表单设计」
2. 导入 §四 form-create JSON
3. 调整字段顺序(可选)
4. 保存

### 步骤 3:配置流程节点

1. 点击「流程设计」
2. 按 §五 创建 4 个节点
3. 按 §六 配置每个节点的处理人、按钮、SLA
4. 保存

### 步骤 4:启用流程

1. 点击「发布」
2. 选择生效范围
3. 确认发布

### 步骤 5:配置自动触发(可选)

1. 对接消防报警系统 API
2. 火警报警自动创建工单
3. 自动填充报警时间、报警位置

## 附录

### 附录 A:警情类型说明

| 类型 | 说明 | 后续动作 |
|------|------|----------|
| 火警 | 确认有火情发生 | 立即启动应急预案,拨打 119 |
| 故障 | 设备故障报警 | 填写故障单,转维保处理 |
| 误报 | 设备误报或人为测试 | 复位设备,记录原因 |
| 测试 | 设备测试产生 | 记录测试原因,确认设备正常 |

### 附录 B:响应时效要求

| 场景 | 响应时限 | 解决时限 |
|------|---------|----------|
| 真实火警 | 15 分钟内到场确认 | 持续处置,直到安全 |
| 故障报警 | 30 分钟内确认 | 24 小时内修复 |
| 误报 | 15 分钟内确认 | 即时复位 |

### 附录 C:处置结果定义

| 结果 | 适用场景 |
|------|----------|
| 已处置 | 现场已处理完毕,无需后续跟进 |
| 待跟进 | 需要后续跟进,如维保、维修 |
| 升级处理 | 超出处置能力,需要上级或外部支援 |
