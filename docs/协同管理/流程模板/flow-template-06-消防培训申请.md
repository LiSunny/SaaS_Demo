### 1.2 工单说明(粘贴到"工单说明"字段)

```
本流程用于消防培训的计划申请与执行记录。

【适用场景】各部门/班组发起消防培训计划,包括消防安全知识培训、消防器材操作培训等。

【不适用场景】1)紧急突发事件请使用【火警事件处置】流程;2)演练类活动请使用【消防演练申请】流程。

【时效要求】培训前 3 日提交申请。

【典型审批节点】申请人 → 部门负责人 → 消防安全管理人 → 结束。

【必填项】培训类型、培训时间、培训地点、讲师、参训人员、培训内容。

【最佳实践】1)培训内容要符合年度培训计划;2)参训人员名单要准确;3)培训后要提交培训签到表和培训记录。
```

## 三、字段详细配置

### 字段 1:培训类型

| 配置项 | 值 |
|--------|-----|
| 组件类型 | radio |
| 字段 ID | `trainType` |
| 选项 | 消防安全知识 / 消防器材操作 / 综合培训 |
| 验证规则 | 必填 |

### 字段 2:培训名称

| 配置项 | 值 |
|--------|-----|
| 组件类型 | input |
| 字段 ID | `trainName` |
| 占位文本 | `请输入培训名称,如:2024年第一季度消防安全知识培训` |
| 验证规则 | 必填,最长 50 字 |

### 字段 3:培训时间

| 配置项 | 值 |
|--------|-----|
| 组件类型 | datePicker |
| 字段 ID | `trainTime` |
| 类型 | datetime |
| 格式 | YYYY-MM-DD HH:mm |
| 验证规则 | 必填,不能早于当前时间 |

### 字段 4:培训地点

| 配置项 | 值 |
|--------|-----|
| 组件类型 | input |
| 字段 ID | `trainLocation` |
| 占位文本 | `请输入培训地点,如:会议室 A` |

| 配置项 | 值 |
|--------|-----|
| 组件类型 | userSelect |
| 字段 ID | `trainer` |
| 选择范围 | 企业内用户 |
| 验证规则 | 必填 |

| 配置项 | 值 |
|--------|-----|

| 字段 ID | `trainContent` |
| 占位文本 | `请详细描述培训内容,包括:培训目标、主要知识点、实操环节` |

## 七、操作步骤

### 步骤 1:创建流程模板

1. 进入「协同管理 → 流程编排」
2. 点击「新建流程」
3. 填写基础信息:
   - 模版名称:消防培训申请
   - 工单说明:粘贴 §1.2 内容
   - 谁可发起:全部

### 步骤 2:配置表单

1. 点击「表单设计」
2. 导入 §四 form-create JSON
3. 调整字段顺序(可选)
4. 保存

### 步骤 3:配置流程节点

1. 点击「流程设计」
2. 按 §五 创建 4 个节点
3. 按 §六 配置每个节点的处理人、按钮、SLA
4. 保存

### 步骤 4:启用流程

1. 点击「发布」
2. 选择生效范围
3. 确认发布

## 附录

### 附录 A:培训类型说明

| 类型 | 说明 |
|------|------|
| 消防安全知识 | 火灾预防、逃生自救、消防安全责任等理论培训 |

| 综合培训 | 理论与实操相结合的全面培训 |

### 附录 B:培训频次建议

根据《消防法》和相关法规,建议:
- 新员工入职:入职后 1 个月内完成消防培训
- 重点岗位(消防控制室):每年不少于 2 次
- 全员培训:每年至少 1 次
- 特殊工种:根据行业要求执行
