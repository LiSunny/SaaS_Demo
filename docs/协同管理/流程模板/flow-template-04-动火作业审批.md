## 一、基础信息

### 1.1 流程元信息

| 字段 | 值 |
|------|-----|
| 模版名称 | **动火作业审批** |
| 谁可发起 | 全部(限有动火作业需求人员) |
| 创建人 | 超级管理员 |
| 特殊标记 | 风险作业,需提前 24h 申请 |

### 1.2 工单说明(粘贴到"工单说明"字段)

```
本流程用于动火作业(电焊、气焊、切割、烘烤等产生明火或高温)的审批。

【适用场景】1)设施维修需动火;2)装修施工涉及动火;3)设备拆除需切割。

【不适用场景】1)日常电气维修请使用【消防设施维修申请】;2)紧急排险需动火请同步电话报备,事后补单。

【时效要求】提前 24 小时申请,审批后实施,作业后 1 小时内验收。

【典型审批节点】申请人 → 部门安全员 → 消防安全管理人 → 分管领导 → 现场监护 → 验收。

【必填项】作业位置、作业类型、作业时间、作业人员、监护人员、安全措施。

【最佳实践】1)作业前 24h 申请,给审批留时间;2)必须配监护人全程在场;3)作业半径 5m 内清除可燃物;4)配备灭火器/水;5)作业后留场观察 30 分钟。
```

### 1.3 SLA 默认配置

|--------|---------------|---------------|----------|

| 普通 | 240 | 1440 | 二级动火(24h) |
| 低 | 480 | 4320 | 三级动火(72h) |

## 五、流程节点清单

```
[开始] → [部门安全员审核] → [消防安全管理人审批] → [(条件)分管领导审批] → [(条件)现场勘察] → [批准作业] → [(条件)现场监护确认] → [验收] → [结束]
```

| 节点 | 类型 | 处理人 | SLA |
|------|------|--------|-----|
| 开始 | start | - | - |
| 部门安全员审核 | approval | 角色:部门安全员 | 2h |
| 消防安全管理人审批 | approval | 角色:消防安全管理人 | 4h |
| 分管领导审批(条件) | approval | 角色:分管领导 | 1d |
| 现场勘察(条件) | task | 角色:消防安全管理人 | 4h |
| 批准作业 | approval | 角色:消防安全管理人 | - |
| 现场监护确认 | task | 角色:监护人员 | 作业期间 |
| 验收 | approval | 角色:部门安全员 | 1h(作业后) |
| 结束 | end | - | - |
