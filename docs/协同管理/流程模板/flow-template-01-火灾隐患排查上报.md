## 一、基础信息

### 1.1 流程元信息

| 字段 | 值 |
|------|-----|
| 模版名称 | **火灾隐患排查上报** |
| 谁可发起 | 全部 |
| 创建人 | 超级管理员 |

### 1.2 工单说明(粘贴到"工单说明"字段)

```
本流程用于日常消防安全隐患的排查上报。

【适用场景】巡查人员、安全员在日常检查中发现消防安全隐患时,通过本流程上报并跟进处置。

【不适用场景】1)紧急事件请使用【应急事件上报】流程;2)消防设施故障维修请使用【消防设施维修申请】流程。

【时效要求】7 日内闭环。

【典型审批节点】巡查人员 → 安全员 → 消防安全管理人。

【必填项】隐患位置、隐患类型、隐患等级、隐患描述、现场照片(≥3 张)。

【最佳实践】1)位置必须选到具体点位(楼栋-楼层-房间号);2)存疑就选"较大"等级,不要默认选"一般";3)现场照片按"远景-中景-近景"3 张以上标准上传。
```

### 1.3 SLA 默认配置

| 优先级 | 响应时限(分钟) | 解决时限(分钟) | 适用场景 |
|--------|---------------|---------------|----------|
| 紧急 | 30 | 1440 | 重大隐患(24h) |
| 高 | 60 | 4320 | 较大隐患(3 天) |
| 普通 | 120 | 10080 | 一般隐患(7 天) |
| 低 | 240 | 20160 | 轻微隐患(14 天) |

## 三、字段详细配置

### 字段 1:隐患位置

| 配置项 | 值 |
|--------|-----|
| 组件类型 | input |
| 字段 ID | `location` |
| 占位文本 | `请输入楼栋-楼层-房间号,例如:教学楼-3 层-301` |
| 验证规则 | 必填,最长 50 字 |

### 字段 2:隐患类型

| 配置项 | 值 |
|--------|-----|
| 组件类型 | radio |
| 字段 ID | `type` |
| 选项 | 消防 / 电气 / 机械 / 危化品 / 其他 |
| 验证规则 | 必填 |

### 字段 3:隐患等级

| 配置项 | 值 |
|--------|-----|
| 组件类型 | radio |
| 字段 ID | `level` |
| 选项 | 一般 / 较大 / 重大 |
| 默认值 | `一般` |
| 提示 | 存疑请选"较大",不要默认选"一般" |

### 字段 4:隐患描述

| 配置项 | 值 |
|--------|-----|
| 组件类型 | textarea |
| 字段 ID | `description` |
| 占位文本 | `请一句话描述问题,例如:消火栓箱门损坏,无法正常开启` |
| 行数 | 4 |
| 最长 | 500 字 |
| 验证规则 | 必填,至少 10 字 |

### 字段 5:现场照片

| 配置项 | 值 |
|--------|-----|
| 组件类型 | upload |
| 字段 ID | `photos` |
| 上传数量 | 3-9 张 |
| 接受类型 | image/* |
| 单文件大小 | ≤ 10 MB |
| 提示 | 请上传 ≥3 张:远景/中景/近景 |

### 字段 6:发现时间

| 配置项 | 值 |
|--------|-----|
| 组件类型 | datePicker |
| 字段 ID | `discoverTime` |
| 默认值 | 当前日期 |
| 格式 | YYYY-MM-DD |

### 字段 7:隐患编号

| 配置项 | 值 |
|--------|-----|
| 组件类型 | serialNumber |
| 字段 ID | `serialNo` |
| 编号格式 | `WO-YYYYMMDD-NNNN` |
| 是否只读 | ✅ |

## 六、节点详细配置

### 节点 1:安全员审核

| 配置项 | 值 |
|--------|-----|
| 节点名称 | 安全员审核 |
| 节点类型 | 审批(approver) |
| 策略类型 | 静态指派 |
| 处理人 | 安全员(选对应岗位/部门)|
| 按钮权限 | 同意 / 驳回 / 转办 |
| 抄送 | 发起人 |
| 超时通知 | 4h 未响应 → 通知上一级 |

### 节点 2:消防安全管理人审批

| 配置项 | 值 |
|--------|-----|
| 节点名称 | 消防安全管理人审批 |
| 节点类型 | 审批(approver) |
| 策略类型 | 静态指派 |
| 处理人 | 消防安全管理人 |
| 按钮权限 | 同意 / 驳回 |

| 条件 | 当 level=重大 时,自动加抄送消防安全责任人 |

## 七、操作步骤(浏览器手动配置)

### 步骤 1:基础信息(第 1 步)

1. 进入"协同管理 → 流程编排"
2. 点"创建流程"
3. 填写模版名称、工单说明(§1.2)
4. 配置 SLA(§1.3)
5. 点击"保存"

### 步骤 2:表单设计(第 2 步)

| 步骤 | 拖入组件 | 改名 | 字段 ID | 必填 | 额外配置 |
|------|---------|------|---------|------|---------|
| 1 | 输入框 | 隐患位置 | location | ✅ | 占位文本见 §三-字段1 |
| 2 | 单选框 | 隐患类型 | type | ✅ | 5 个选项 |
| 3 | 单选框 | 隐患等级 | level | ✅ | 3 个选项,默认一般 |
| 4 | 多行输入框 | 隐患描述 | description | ✅ | 占位文本见 §三-字段4 |
| 5 | 上传 | 现场照片 | photos | ✅ | 限 3-9 张 |
| 6 | 日期 | 发现时间 | discoverTime | ✅ | 默认当前 |
| 7 | 流水号 | 隐患编号 | serialNo | ❌ | 自动生成 |

> 💡 **快速方式**:把 §四 的 JSON 直接导入 form-create 设计器(若平台支持)。

### 步骤 3:流程设计(第 3 步)

| 步骤 | 操作 |
|------|------|
| 1 | 点"+ 添加节点"按钮 |
| 2 | 选"审核"类型 |
| 3 | 命名"安全员审核",配置处理人为"安全员"角色 |
| 4 | 再点"+ 添加节点",选"审核" |
| 5 | 命名"消防安全管理人审批",配置处理人 |
| 6 | 在节点 2 加条件:level=重大 → 自动加抄送消防安全责任人 |
| 7 | 再点"+ 添加节点",选"执行" |
| 8 | 命名"隐患整改",处理人=表单字段指定(需在表单加人员控件)|
| 9 | 再点"+ 添加节点",选"审核" |
| 10 | 命名"验收",处理人=部门负责人 |
| 11 | 用连线串起所有节点 |
| 12 | 点"保存"(先不要"保存并启用",等测试) |
