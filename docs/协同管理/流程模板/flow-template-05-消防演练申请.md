### 1.2 工单说明(粘贴到"工单说明"字段)

```
本流程用于消防演练的计划申请与执行记录。

【适用场景】各部门/班组发起消防演练计划,包括灭火演练、疏散演练、防暴演练等。

【不适用场景】1)紧急突发事件请使用【火警事件处置】流程;2)日常培训请使用【消防培训申请】流程。

【时效要求】演练前 3 日提交申请。

【典型审批节点】申请人 → 部门负责人 → 安全管理人 → 结束。

【必填项】演练类型、演练时间、演练地点、参与人员、演练方案。

【最佳实践】1)演练方案要包含详细步骤和人员分工;2)参与人员名单要准确;3)演练后要提交演练记录和评估报告。
```

## 三、字段详细配置

### 字段 1:演练类型

| 配置项 | 值 |
|--------|-----|
| 组件类型 | radio |
| 字段 ID | `drillType` |
| 选项 | 灭火演练 / 疏散演练 / 防暴演练 / 综合演练 |
| 验证规则 | 必填 |

### 字段 2:演练名称

| 配置项 | 值 |
|--------|-----|
| 组件类型 | input |
| 字段 ID | `drillName` |
| 占位文本 | `请输入演练名称,如:2024年第一季度消防疏散演练` |
| 验证规则 | 必填,最长 50 字 |

### 字段 3:演练时间

| 配置项 | 值 |
|--------|-----|
| 组件类型 | datePicker |
| 字段 ID | `drillTime` |
| 类型 | datetime |
| 格式 | YYYY-MM-DD HH:mm |
| 验证规则 | 必填,不能早于当前时间 |

### 字段 4:演练地点

| 配置项 | 值 |
|--------|-----|
| 组件类型 | input |
| 字段 ID | `drillLocation` |
| 占位文本 | `请输入演练地点,如:办公大楼 3 层` |
| 验证规则 | 必填,最长 100 字 |

### 字段 5:演练方案

| 配置项 | 值 |
|--------|-----|
| 组件类型 | textarea |
| 字段 ID | `drillPlan` |
| 占位文本 | `请详细描述演练方案,包括:演练目的、步骤分解、人员分工、所需物资` |

| 验证规则 | 必填,至少 50 字 |

### 字段 6:参与人员

|--------|-----|

| 字段 ID | `participants` |

### 字段 8:预算金额

|--------|-----|

| 字段 ID | `budget` |

## 七、操作步骤

### 步骤 1:创建流程模板

1. 进入「协同管理 → 流程编排」
2. 点击「新建流程」
3. 填写基础信息:
   - 模版名称:消防演练申请
   - 工单说明:粘贴 §1.2 内容
   - 谁可发起:全部

### 步骤 2:配置表单

1. 点击「表单设计」
2. 导入 §四 form-create JSON
3. 调整字段顺序(可选)
4. 保存

### 步骤 3:配置流程节点

1. 点击「流程设计」
2. 按 §五 创建 4 个节点
3. 按 §六 配置每个节点的处理人、按钮、SLA
4. 保存

### 步骤 4:启用流程

1. 点击「发布」
2. 选择生效范围
3. 确认发布

## 附录

### 附录 A:演练类型说明

| 类型 | 说明 |
|------|------|
| 灭火演练 | 灭火器、消火栓等消防器材使用训练 |
| 疏散演练 | 火灾等紧急情况下的疏散逃生训练 |
| 防暴演练 | 暴力突发事件应对演练 |
| 综合演练 | 多种场景组合的综合演练 |

### 附录 B:演练频次建议

根据《消防法》和相关法规,建议:
- 重点单位:每半年至少 1 次
- 一般单位:每年至少 1 次
- 新员工入职:入职后 1 个月内完成消防培训
