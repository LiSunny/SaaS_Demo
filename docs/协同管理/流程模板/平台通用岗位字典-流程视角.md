## 五、配置建议

### 5.1 选人原则

- ✅ **优先按岗位**:配置流程节点时选择岗位而非具体人
- ✅ **按角色配置**:跨部门角色(如"评估委员会")用虚拟角色
- ❌ **避免按具体人**:人员变动后流程容易断链

### 5.2 服务主体隔离

配置流程时注意:
- 维保公司岗位只出现在维修/维保相关流程
- 社会单位岗位负责审批和管理
- 监管部门岗位用于监督执法场景

### 5.3 常见配置组合

| 流程 | 典型审批链 |
|------|-----------|
| 火灾隐患排查上报 | 申请人 → 部门安全员 → 消防安全管理人 → 部门负责人 → 分管领导(抄送) |
| 火灾隐患整改处置 | 整改责任人 → 部门安全员 → 消防安全管理人 → 安全责任人 |
| 消防设施维修申请 | 申请人 → 部门安全员 → 消防安全管理人 → 财务(条件) → 维保单位 → 维保工程师 |
| 动火作业审批 | 申请人 → 部门安全员 → 消防安全管理人 → 分管领导(条件) → 监护人员 |
| 火警事件处置 | 消控室值班员 → 现场处置人员 → 消防安全管理人 |
| 故障事件处置 | 申请人 → 维修人员 → 设备管理员 |
