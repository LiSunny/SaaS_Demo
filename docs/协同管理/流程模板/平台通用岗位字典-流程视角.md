## 二、核心概念定义

### 1. 服务主体

指岗位所属的组织类型，决定了岗位的归属和职责边界。

| 服务主体 | 定义 | 典型场景 |
|---------|------|---------|
| **社会单位** | 消防安全管理的对象方，即被服务的单位（商场、学校、企业等） | 隐患排查、设施使用、应急响应 |
| **维保公司** | 提供消防设施维保服务的技术公司 | 设施巡检、维修、故障处置 |
| **消防技术服务机构** | 提供检测、评估等技术服务的第三方机构 | 年度检测、风险评估 |
| **监管部门** | 消防救援机构、行业主管部门 | 监督检查、执法处理 |

> **注意**：同一自然人在不同流程中可能扮演不同角色（如社会单位的员工也可以是维保公司派来的维保人员），但在本字典中按服务主体分类是为了明确职责边界，不绑定具体个人。

### 2. 职能分类

指同一服务主体内的职责领域，按工作性质划分。

| 职能分类 | 定义 | 适用服务主体 |
|---------|------|-------------|
| **消防安全管理** | 法定职责或安全管理统筹工作 | 社会单位 |
| **日常巡查** | 日常性安全检查、巡查看护 | 社会单位 |
| **设施运维** | 消防设施的操作、维护、管理 | 社会单位、维保公司 |
| **应急响应** | 突发事件处置、救援、监护 | 社会单位 |
| **综合管理** | 行政审批、部门管理 | 社会单位 |
| **维保服务** | 维保项目的组织实施、作业 | 维保公司 |
| **技术服务** | 检测、评估、技术审核 | 维保公司、消防技术机构 |
| **监督执法** | 行政监管、执法检查 | 监管部门 |

## 五、配置建议

### 5.1 选人原则

- ✅ **优先按岗位**:配置流程节点时选择岗位而非具体人
- ✅ **按角色配置**:跨部门角色(如"评估委员会")用虚拟角色
- ❌ **避免按具体人**:人员变动后流程容易断链

### 5.2 服务主体隔离

配置流程时注意:
- 维保公司岗位只出现在维修/维保相关流程
- 社会单位岗位负责审批和管理
- 监管部门岗位用于监督执法场景

### 5.3 常见配置组合

| 流程 | 典型审批链 |
|------|-----------|
| 火灾隐患排查上报 | 申请人 → 安全员/巡查人员 → 消防安全管理人 → 部门负责人 |
| 火灾隐患整改处置 | 申请人 → 安全员 → 消防安全管理人 → 消防安全责任人 |
| 消防设施维修申请 | 申请人 → 安全员 → 消防安全管理人 → 消防设施操作员 → 维保公司(项目负责人/操作员) |
| 动火作业审批 | 申请人 → 安全员 → 消防安全管理人 → 监护人员 |
| 火警事件处置 | 消防控制室值班员 → 现场处置人员 → 消防安全管理人 |
| 故障事件处置 | 申请人 → 消防设施操作员 → 项目负责人 → 消防设施操作员(验收) |
