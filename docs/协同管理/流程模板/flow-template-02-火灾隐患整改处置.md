### 1.2 工单说明(粘贴到"工单说明"字段)

```
本流程用于火灾隐患的整改落实与验收闭环。

【适用场景】隐患排查上报后,责任人对隐患进行整改,整改完成后提交验收。

【不适用场景】1)紧急火警请使用【火警事件处置】流程;2)日常隐患排查请使用【火灾隐患排查上报】流程。

【时效要求】7 日内闭环(紧急 24h)。

【典型审批节点】整改责任人 → 部门安全员 → 消防安全管理人 → 验收人。

【必填项】关联隐患、整改措施、整改期限、现场照片(整改后)、验收结果。

【最佳实践】1)整改措施要具体可执行,不能写"加强管理";2)整改照片要体现整改效果;3)验收必须现场核查,不能仅看照片。
```

### 1.3 SLA 默认配置

| 优先级 | 响应时限(分钟) | 解决时限(分钟) | 适用场景 |
|--------|---------------|---------------|----------|
| 紧急 | 60 | 1440 | 重大隐患整改(24h) |
| 普通 | 240 | 10080 | 一般/较大隐患整改(7d) |

## 二、表单字段清单

| # | 字段名称 | 类型 | 必填 | 默认 | 说明 |

## 三、字段详细配置

### 字段 1:关联隐患

| 配置项 | 值 |
|--------|-----|
| 组件类型 | relationSelect |
| 字段 ID | `sourceHazard` |
| 关联类型 | 火灾隐患排查上报 |
| 显示字段 | 隐患位置 + 隐患类型 |
| 验证规则 | 必填 |

### 字段 2:整改措施

| 配置项 | 值 |
|--------|-----|
| 组件类型 | textarea |
| 字段 ID | `rectifyMeasure` |
| 占位文本 | `请详细描述整改措施,例如:更换受损的应急照明灯,增加安全出口标识` |
| 行数 | 4 |
| 最长 | 500 字 |
| 验证规则 | 必填,至少 50 字 |

### 字段 3:整改期限

| 配置项 | 值 |
|--------|-----|
| 组件类型 | datePicker |
| 字段 ID | `deadline` |
| 格式 | YYYY-MM-DD |
| 验证规则 | 必填,不能早于今天 |

### 字段 4:整改负责人

| 配置项 | 值 |
|--------|-----|
| 组件类型 | userSelect |
| 字段 ID | `responsibleUser` |
| 选择范围 | 企业内用户 |
| 验证规则 | 必填 |

### 字段 5:整改照片

| 配置项 | 值 |
|--------|-----|
| 组件类型 | upload |
| 字段 ID | `rectifyPhotos` |
| 上传数量 | 3-9 张 |
| 接受类型 | image/* |
| 单文件大小 | ≤ 10 MB |
| 提示 | 请上传整改后的现场照片,体现整改效果 |

### 字段 6:整改说明

| 配置项 | 值 |
|--------|-----|
| 组件类型 | textarea |
| 字段 ID | `rectifyRemark` |
| 占位文本 | `补充说明整改过程中的特殊情况` |
| 行数 | 3 |
| 最长 | 200 字 |

### 字段 7:验收结果

| 配置项 | 值 |
|--------|-----|
| 组件类型 | radio |
| 字段 ID | `acceptResult` |
| 选项 | 通过 / 不通过 / 部分通过 |
| 验证规则 | 必填 |

### 字段 8:验收意见

| 配置项 | 值 |
|--------|-----|
| 组件类型 | textarea |
| 字段 ID | `acceptRemark` |
| 占位文本 | `填写验收意见,不通过需说明原因` |
| 行数 | 3 |
| 最长 | 200 字 |

## 七、操作步骤

### 步骤 1:创建流程模板

1. 进入「协同管理 → 流程编排」
2. 点击「新建流程」
3. 填写基础信息:
   - 模版名称:火灾隐患整改处置
   - 工单说明:粘贴 §1.2 内容
   - 谁可发起:全部

### 步骤 2:配置表单

1. 点击「表单设计」
2. 导入 §四 form-create JSON
3. 调整字段顺序(可选)
4. 保存

### 步骤 3:配置流程节点

1. 点击「流程设计」
2. 按 §五 创建 5 个节点
3. 按 §六 配置每个节点的处理人、按钮、SLA
4. 保存

### 步骤 4:启用流程

1. 点击「发布」
2. 选择生效范围
3. 确认发布
