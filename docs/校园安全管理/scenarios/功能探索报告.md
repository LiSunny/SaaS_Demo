# 校园安全管理 — 全业务域功能探索报告

> 探索时间：2026-07-16
> 覆盖项目：港南项目（Flutter 移动端）+ neat-ui（Vue 3 Web 后台）

---

## 一、业务定位

校园安全管理是平台在"公共安全"大框架下向教育行业的垂直延伸。与工贸企业场景不同，校园安全的核心场景围绕**人的安全**展开——学生的食品安全、住宿安全、防欺凌、应急疏散——而非设备/生产安全。

系统覆盖 **寄宿制学校**和**非寄宿制学校**两种类型，串联教育局监管方、学校管理方、教师、保安、食堂从业者等多方角色。

## 二、功能域全景（7 域）

### 1. 校园安全大屏（驾驶舱）

> 核心载体：neat-ui 3 套大屏模板 + 港南项目首页卡片组

| 大屏/组件 | 位置 | 适用场景 |
|-----------|------|------|
| **校园安全综合大屏（template5）** | neat-ui `dutyScreen/template5/` | 通用校园安全态势，含 AI 防欺凌、厨房监控、电消巡检、隐患台账 |
| **寄宿学校大屏（templateSchoolForBoarding）** | neat-ui `dutyScreen/templateSchoolForBoarding/` | 寄宿制学校专项，含宿舍/教室/公共区域三维管理，教师+保安双角色履责 |
| **教育系统应急大屏（templateEmergency）** | neat-ui `dutyScreen/templateEmergency/` | 教育局视角，按寄宿/非寄宿分类的火灾/霸凌/电气预警 + 校长履职打卡 |
| **移动端首页校园卡片** | 港南项目 `widgets/card/` | 3 张卡片：AI 防欺凌告警、食品安全检查、平安校园应急联动 |

**寄宿学校大屏关键组件（16 个文件）：**

| 组件 | 功能 |
|------|------|
| `bullyInspection.vue` | **课间防欺凌巡检** — 按区域 Tab（教学区/宿舍）查看巡检点位打卡状态 |
| `dutyInspection.vue` | **学生欺凌防范行动** — 按区域查看防欺凌履职打卡 |
| `kitchenMonitor.vue` | **校园食品安全检查** — 三餐（早/午/晚）检查状态 + 点位巡检记录 |
| `electricalAndFireInspection.vue` | **电消安全隐患巡检** — 电气+消防设备巡检打卡 |
| `hiddenDangerLedger.vue` | **上报隐患处置反馈** — 待认领/待确认/已确认统计 + 隐患列表 |
| `alarmLinkage.vue` | **安消报警联动救援** — 手动火灾报警按钮 + 一键式声光报警器状态监控 |
| `emergencyPlan.vue` | **应急预案** — 8 类预案：应急疏散、食品安全、地质灾害、消防灭火、防汛抗旱、校园暴力、意外伤害、心理健康 |
| `workShow.vue` | **教师履责尽责** — 按月统计履职数据（总数/已完成/占比） |
| `workShowForGuard.vue` | **保安履责尽责** — 保安巡检履职统计 |
| `aiRobot.vue` | **AI 助手** — 语音/文字交互 |

**区域配置（unitTabsConfig.ts）：** 支持寄宿/非寄宿两种模式，管理单元分宿舍、教室、公共区域三类。

### 2. AI 防欺凌

> 覆盖：两端均有独立组件

| 端 | 组件 | 能力 |
|----|------|------|
| **Web 大屏** | `template5/bullyAlarmEvent.vue` | 校园AI防欺凌告警 — 6 区域 Tab（男生宿舍/男生公共/女生宿舍/女生公共/公共区/教学区），事件来源区分 SOS/打架/语音，已处置/已接警状态 |
| **移动端首页** | `card_bl_event.dart` | 校园AI防欺凌告警卡片 — 同 6 区域 Tab，事件列表 + 跳转详情 |
| **Web 寄宿** | `templateSchoolForBoarding/bullyInspection.vue` | 课间防欺凌巡检 — 课间时段定点巡查打卡 |
| **Web 应急** | `templateEmergency/educationSystemMonitor.vue` | 霸凌预警统计 — 按寄宿/非寄宿学校分类计数 |

**告警来源类型**（从代码识别）：
- `5182` — SOS 紧急呼叫
- `5195` — 打架检测
- 其他 — 语音识别（关键词触发）

**关键 API：**
- `/dataCenter/duty/event/eventList` — 告警事件列表
- `/dataCenter/duty/event/eventCountByConditions` — 事件标签统计
- `/dataCenter/bigScreen/school/alarmHandButtonStatusInGirlBoyDorm` — 男女生宿舍手报/声光报警状态

### 3. 食品安全管理

> 这是校园场景中**功能最完整**的业务域，覆盖从食材入库到餐后评价的全链条。

#### Web 端（neat-ui，5 子模块）

| 模块 | 路径 | 功能 |
|------|------|------|
| **食品分类** | `admin/foodClassification/` | 食品大类/小类二级分类管理，支持导入导出 |
| **食品台账** | `admin/foodLedger/` | 食材物品台账（入库/库存/二维码），含食品详情、信息详情 |
| **出库明细** | `admin/foodOutboundDetails/` | 食品出库记录，支持新增/编辑/导出 |
| **食品留样** | `admin/foodSampleRetention/` | 留样记录管理（法规要求：每餐留样 48 小时） |
| **库存状态** | `admin/foodStorageStatus/` | 库存实时状态、临期食品统计 |

**关键 API：**
- `/thing/ledger/*` — 物品台账 CRUD
- `/thing/category/*` — 食品分类管理
- `/thing/stats/summary` — 临期食品统计
- `/admin/web/entUser/userHealthCardPage` — 从业人员健康卡

#### 移动端（港南项目，3 模块）

| 模块 | 路径 | 功能 |
|------|------|------|
| **校园食品安全检查（首页卡片）** | `widgets/card/card_kitchen_status.dart` | 三餐检查状态（早/午/晚）+ 巡检点位打卡列表 |
| **明厨亮灶后厨视频** | 大屏/首页集成 | 通过 API `getDeviceCameraPageForDaPing` 实时查看后厨监控 |
| **陪餐管理** | `page/accompanyMeal/` | 陪餐记录：餐别选择、食品评价、卫生环境评价、从业人员监督 + 拍照上传（最多 3 张） |
| **陪餐记录列表** | `page/accompanyMealRecord/` | 陪餐历史记录查看 |

**陪餐评价维度（4 项）：**
1. 餐别（早/午/晚餐）
2. 食品评价（色香味/营养搭配等）
3. 卫生环境评价
4. 从业人员监督（着装/操作规范）

## 三、两端功能互补关系

```
移动端（现场操作）              Web 端（管理配置）
─────────────────              ─────────────────
AI 防欺凌告警查看 + 处置   ←→   告警大屏 + 区域 Tab 分类监控
陪餐拍照上传 + 评价录入    ←→   食品安全台账 + 出库 + 留样管理
明厨亮灶实时视频查看      ←→   后厨摄像头配置 + AI 巡检
应急联动预案 PDF 查阅     ←→   8 类预案配置 + 大屏展示
巡检点位扫码打卡          ←→   巡检计划 + 任务统计 + 履职排名
手报/声光报警一键确认    ←→   报警设备状态监控 + 联动策略
校园首页卡片概览          ←→   3 套大屏模板（综合/寄宿/应急）
```

## 六、技术要点

- **校园大屏共用基础设施**：3 套校园模板均复用 `dutyScreen/components/` 下的公共组件（地图描点、视频弹窗、事件弹窗、场景弹窗、管理单元弹窗）
- **区域配置灵活**：通过 `unitTabsConfig.ts` 区分寄宿/非寄宿学校，管理单元 ID 可配置
- **两端数据同源**：港南移动端首页卡片的数据结构（`PatTaskList`、`AlarmEventList`、`LinkPlanList`）与 neat-ui 大屏组件调用同一套后端 API
- **AI 能力集成**：AI 机器人组件、AI 防欺凌（语音/行为识别）、AI 电气/消防巡检
