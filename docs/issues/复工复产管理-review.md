### 🔴 P0 阻塞问题

1. **种子数据中隐患和设备 formData 为空**
   - 复现路径：打开大屏 → 隐患汇总、设备汇总始终显示 0
   - 预期行为：done 状态的步骤 5/6 应包含 HazardRecord[] 和 DeviceCheckItem[] 示例数据
   - 修复：`src/api/adapters/resumption-dao.ts` SEED_STEPS 中，给 stepOrder=5、6 的 done 记录补充 formData

2. **加载状态未使用 + 错误处理缺失**
   - `BigscreenResumption.vue` 中 `loading` ref 已定义但模板中未渲染任何 loading 指示器，数据加载中用户看到空白卡片
   - `fetchData` 的 catch 块为空——API 失败时用户完全无感知
   - 修复：添加 loading 骨架屏/指示器；catch 中 console.error + 展示错误提示

### 🟡 P1 体验问题

3. **KPI 标签与设计文档 §4.6 同物不同名**
   - "进行中"、"待审核/签发"、"已复产"均非标准 4 阶段标签
   - 标准标签：复工准备 / 复工审核 / 试产观察 / 正式复产
   - 建议方案 A：KPI 改为 5 卡片展示完整 4 阶段分布（prepare/review/trial/production/复工率）
   - 建议方案 B：保留聚合，但"已复产"→"正式复产"，"待审核/签发"→"复工审核"，"进行中"需在设计文档中先定义

4. **热力图中验收分水岭无视觉区分**
   - 步骤 8（联合验收）是业务关键关卡，但在 11 格中和前后步骤视觉完全平等
   - 修复：步骤 7（整改闭环）和步骤 8（联合验收）之间加分隔线或加宽间距；步骤 8 单元格增加边框高亮

5. **热力图表头用数字而非步骤简称**
   - 用户看到 1-11 数字，需 hover tooltip 才知含义
   - 修复：表头改用步骤简称（建/签/培/交/患/设/改/验/令/值/档）或 2 字标签

### 🟢 P2 优化建议

6. **大屏数据不自动刷新**：从详情页修改数据后返回大屏，显示旧数据。建议在路由守卫或 `onActivated` 中重新拉取

7. **ActivityTimeline 用索引做 v-for key**：`:key="i"` → 列表更新时可能渲染错位。建议用 `` `${planId}-${completedAt}` ``

8. **隐患汇总信息密度偏高**：同屏 4 统计卡 + 5 段条形图 + 5 标签 = 14 个信息单元。建议合并"已处置+已整改+已验收"为"已处理"
