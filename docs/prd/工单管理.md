# 工单管理 — 产品需求文档

> 版本：v1.0 | 日期：2026-06-02 | 状态：草稿

## 1. 背景与目标

### 1.1 业务背景
当前工单监控列表的 Mock 数据是写死的，物业管理员无法从系统创建新工单。需要补齐"模板选择→表单填写→提交创建"入口，打通"配置→发起→监控"闭环的第一步。

### 1.2 模块目标
- **用户目标**：物业管理员在监控列表页快速发起标准化工单
- **业务目标**：支撑"平均 TTS ≤ 时限 80%"指标，从源头规范化工单创建

### 1.3 适用范围
- **角色**：物业管理员（平台运营方、业主企业管理员）
- **场景**：发现消防隐患、设备故障、日常巡检异常后，从模板快速生成工单

## 2. 功能规格

### 2.1 功能清单

| 功能点 | 优先级 | 说明 |
|--------|--------|------|
| 模板选择 | P0 | 展示可用模板卡片，点击选中 |
| 工单信息填写 | P0 | 优先级选择 + 工单描述 |
| 提交创建 | P0 | 提交后生成草稿工单，刷新列表 |

### 2.2 详细功能说明

#### F1：模板选择

**用户故事**：作为物业管理员，我希望从已发布的模板列表中选择合适的工单类型，以便按标准化流程发起工单。

**交互说明**：
1. 用户点击列表页"发起工单"按钮 → 弹窗打开，默认展示模板选择区
2. 模板以 2×2 卡片网格展示，每张卡片显示：模板名称、版本号、节点数
3. 点击卡片选中，选中态蓝色高亮边框，再次点击取消选中
4. 选中模板后，下方表单区展开

**业务规则**：
- 仅展示"执行中"状态的模板
- 默认显示 4 个模板：设备维修、隐患整改、安全生产督办、故障报修
- 未选模板时"确认发起"按钮 disabled

**异常处理**：
| 场景 | 触发条件 | 系统处理 | 用户提示 |
|------|---------|---------|---------|
| 无可用模板 | 所有模板均为停用/过期状态 | 弹窗显示空状态 | "暂无可用的工单模板，请先配置模板" |
| 模板加载失败 | API 返回异常 | 弹窗内显示错误 + 重试按钮 | "模板列表加载失败，请重试" |

**验收标准（AC）**：
- [ ] AC1：弹窗打开时模板卡片可见，每张显示名称+节点数
- [ ] AC2：点击卡片蓝色高亮，再次点击取消选中
- [ ] AC3：未选模板时确认按钮 disabled

#### F2：工单信息填写

**用户故事**：作为物业管理员，我希望在发起工单时设置优先级和补充描述，以便处理人能准确理解任务紧急程度和内容。

**交互说明**：
1. 选中模板后，表单区展开
2. 优先级：radio group（普通 / 紧急 / 低优），默认"普通"
3. 工单描述：textarea（选填，最多 200 字），placeholder="请简要描述工单内容"

**业务规则**：
- 优先级默认"普通"
- 工单描述选填
- 工单编号由系统自动生成
- 创建后状态固定为"草稿"，进度 1/5

**异常处理**：
| 场景 | 触发条件 | 系统处理 | 用户提示 |
|------|---------|---------|---------|
| 描述超长 | textarea 超过 200 字 | 阻止输入 | "最多200字" |
| 提交失败 | API 网络异常 | 按钮恢复可用 | "创建失败，请重试" |

**验收标准（AC）**：
- [ ] AC4：选中模板后表单区出现，优先级默认"普通"
- [ ] AC5：工单描述支持输入，超过 200 字限制

#### F3：提交创建

**用户故事**：作为物业管理员，我希望点击确认后将工单创建到系统中，以便在列表中跟踪后续处理。

**交互说明**：
1. 用户点击"确认发起"
2. 按钮显示"提交中..."，不可重复点击
3. 成功后弹窗关闭，列表刷新
4. 失败时 toast 提示错误

**验收标准（AC）**：
- [ ] AC6：提交后弹窗关闭，列表顶部出现新工单
- [ ] AC7：新工单状态=草稿，进度=1/5

## 3. 数据结构

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| templateId | number | 是 | 模板 ID |
| templateName | string | 是 | 模板名称 |
| templateVersion | number | 是 | 模板版本号 |
| priority | string | 是 | urgent/normal/low |
| creatorName | string | 是 | 发起人姓名 |

## 4. 接口

> 详见 [docs/api/工单管理.md](../api/工单管理.md)

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 创建工单 | POST | /api/v1/work-order/instances | 从模板创建草稿工单 |

## 5. 非功能需求

- **性能**：弹窗即时渲染，提交响应 < 300ms（mock）
- **兼容性**：Chrome/Firefox/Edge 最新版
- **安全**：需登录，限物业管理员角色
