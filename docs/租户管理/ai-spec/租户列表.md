# 租户列表 — 设计文档

---

## 一、页面元信息

| 项目 | 内容 |
|------|------|
| 页面名称 | `租户列表` |
| 所属模块 | `租户管理` |
| 页面类型 | `列表管理` |
| 路由路径 | `/admin/enterpriseManagement/index` |

### 功能描述

租户管理列表页面，支持按企业名称、平台管理角色、消防类别、行业分类、场所类型搜索筛选，批量选择、新增租户入口，行操作（详情/编辑/锁定/延期/个性化配置/应用配置）。

---

## 二、页面结构

### 列表管理 页布局

| # | 区域名称 | 位置 | 注册表组件 | 包含元素 |
|---|---------|------|-----------|---------|
| 1 | 引导说明区 | 顶部 | 自定义 `el-card` | 标题"什么是租户？"+ 说明"租户是指使用平台服务…" + 三步使用说明（新增租户→租户授权→租户关系管理），浅蓝背景，可折叠 |
| 2 | 搜索筛选操作区 | 顶部 | `FilterBar` | **同行左右布局**：左侧 `.filter-left` 放 企业名称输入框 + 维度A 平台管理角色下拉(一级) + 查询/重置按钮，折叠项放 维度B 消防类别下拉 + 维度C 行业分类下拉 + 维度D 场所类型下拉(折叠)；右侧 `.filter-right` 放 [新增租户] 按钮(primary) |
| 3 | 操作栏 | 全宽 | `ToolBar` | left：已选 {n} 项；right：[批量删除] 按钮(danger, 需选中≥1) |
| 4 | 数据表格 | 全宽 | `DataTable` | 复选框列 + 企业名称 + 企业唯一码 + 维度A 平台管理角色(StatusTag) + 维度B 消防单位类别 + 维度C 行业分类 + 维度D 场所类型 + 行政区划 + 负责人 + 负责人手机号 + 状态(StatusTag) + 有效期 + 创建时间 + 操作列(fixed right) |
| 5 | 分页器 | 底部 | `el-pagination` | layout="total, sizes, prev, pager, next, jumper"，pageSizes=[10,20,50,100] |

**操作列按钮（按企业状态动态展示）**：

| 按钮 | 图标 | 展示条件 |
|------|------|---------|
| 详情 | `View` | 始终 |
| 编辑 | `Edit` | 状态=有效 |
| 锁定 | `Lock` | 状态=有效, 非平台运营方自身 |
| 延期 | `Timer` | 状态=有效 且 validTo 已设置 |
| 个性化配置 | `Setting` | 始终 |
| 应用配置 | `Operation` | 始终 |

## 三、数据模型

### 3.1 实体字段

| 字段名 | 中文名 | 类型 | 必填 | 说明 |
|--------|--------|------|------|------|
| `id` | ID | `string` | 是 | 企业唯一 ID（雪花 ID） |
| `name` | 企业名称 | `string` | 是 | max:100 |
| `code` | 企业唯一码 | `string` | 是 | QY + 雪花 ID，自动生成 |
| `dimA.level1` | 平台管理角色一级 | `string` | 是 | 监管方/管理方/社会单位/服务单位/平台运营方 |
| `dimA.level2` | 平台管理角色二级 | `string` | 否 | 空间管理方/集团管理方 |
| `dimA.level3` | 平台管理角色三级 | `string` | 否 | 消防救援机构/应急管理部门/属地政府/行业主管部门/物业管理方/园区管理方/市场管理方/综合体管理方/商业街管理方/消防技术服务机构 |
| `dimB` | 消防单位类别 | `string` | 否 | XF/T 3016.1-2022，如"餐饮场所""商场市场"，仅社会单位必填 |
| `dimC` | 行业分类 | `string` | 否 | GB/T 4754-2017 大类，如"零售业""餐饮业""教育" |
| `dimD` | 场所/建筑类型 | `string` | 否 | 如"人员密集场所""高层建筑""普通商铺"，仅社会单位必填 |
| `region` | 行政区划 | `string` | 否 | 省/市/区三级 |
| `contactName` | 负责人 | `string` | 是 | max:20 |
| `contactPhone` | 负责人手机号 | `string` | 是 | pattern: 手机号 |
| `status` | 状态 | `number` | 是 | 见状态枚举 |
| `validFrom` | 有效期起 | `string` | 否 | ISO 8601 date |
| `validTo` | 有效期止 | `string` | 否 | ISO 8601 date |
| `parentId` | 上级企业 ID | `string` | 否 | 关联链上级 |
| `tags` | 企业标签 | `string[]` | 否 | 逗号分隔 |
| `createdAt` | 创建时间 | `string` | 是 | ISO 8601 |

### 3.2 状态枚举

| 枚举值 | 标签文字 | 颜色类型 | 说明 |
|--------|---------|---------|------|
| `1` | 有效 | `success` | 正常使用中 |
| `0` | 已锁定 | `danger` | 管理员锁定，不可登录 |
| `2` | 已过期 | `normal` | 超过有效期 |

## 六、业务逻辑

### 6.1 交互行为

| 操作 | 触发条件 | 行为描述 |
|------|---------|---------|
| 查询 | 点击[查询] | 按当前筛选条件请求列表接口，刷新表格；折叠的维度 B/C/D 筛选同样生效 |
| 新增 | 点击[新增租户] | 跳转 `/admin/enterpriseManagement/create` |
| 详情 | 点击行操作[详情] | 跳转 `/admin/enterpriseManagement/detail?id={id}` |
| 编辑 | 点击行操作[编辑] | 跳转 `/admin/enterpriseManagement/edit?id={id}` |
| 锁定 | 点击行操作[锁定] | ElMessageBox.confirm "确认锁定 {name}？锁定后该企业不可登录"，确认后调接口 |
| 延期 | 点击行操作[延期] | 打开 FormDialog：有效期止(date-picker) + 确定 |
| 个性化配置 | 点击行操作[个性化配置] | 打开 FormDialog：域名、版权公告、ICP 备案、平台标题 |
| 应用配置 | 点击行操作[应用配置] | 打开应用配置弹窗（13 域 Tab × 模块树） |
| 批量删除 | 选中≥1行，点击[批量删除] | ElMessageBox.confirm "确认删除选中的 {n} 个企业？"，确认后调接口 |

### 6.2 特殊规则

- 企业唯一码（code）格式 QY + 雪花 ID，自动生成不可编辑
- 平台运营方自身的租户行不展示编辑/锁定/延期按钮
- 维度 A 列展示逻辑：三级联动显示，只显示到有值的最深层级（如"管理方 › 空间管理方 › 物业管理方"）
- 维度 B/D 列：非社会单位角色显示"—"
- 引导说明区折叠状态 localStorage 持久化
- 列表默认按创建时间倒序

## 七、UI 组件分配

| 页面区域 | 注册表组件 | 关键 Props / 自定义说明 |
|---------|-----------|----------------------|
| 搜索筛选区 | `FilterBar` | 筛选项：企业名称(input)+维度A一级(select)；折叠：维度B/C/D(select)；extra slot：[新增租户](primary) |
| 操作按钮栏 | `ToolBar` | left：已选计数；right：[批量删除](danger) |
| 数据表格 | `DataTable` | checkbox + 维度A列(StatusTag 或级联文字) + 状态列(StatusTag) + 操作列(fixed right) |
| 状态标签 | `StatusTag` | 见 §3.2；维度 A 标签颜色按一级分类(监管方=info/管理方=warning/社会单位=success/服务单位=normal/平台运营方=normal) |
| 引导说明区 | 自定义 `el-card` | shadow="never"，浅蓝 bg，可折叠 |
