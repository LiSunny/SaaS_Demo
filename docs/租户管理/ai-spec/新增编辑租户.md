# 新增/编辑租户 — 设计文档

> **最后更新**: 2026-06-29（v2.1 — 创建企业自动初始化管理员账号+岗位+关联）

---

## 一、页面元信息

| 项目 | 内容 |
|------|------|
| 页面名称 | `新增/编辑租户` |
| 所属模块 | `租户管理` |
| 页面类型 | `表单提交` |
| 路由路径 | `/admin/enterpriseManagement/create` `/admin/enterpriseManagement/edit?id=` |

### 功能描述

新增或编辑租户企业的多步骤向导表单。步骤1填写企业基本信息和三维度属性（B/C/D），步骤2配置应用功能权限。新增时自动生成企业唯一码和二维码，并自动初始化企业管理员账号（创建/匹配 User → 分配岗位 → 建立企业关联；若选了上级企业则自动建立下级管理关联）。

## 五、业务逻辑

### 5.1 维度 B 重点单位自动标记

```
维度 B select 变化：
  ├── 选中 XF/T 3016.1-2022 中任一类别
  │     └── 提示"该类别将自动标记为'消防安全重点单位'"
  │     └── 保存时 tags 自动追加"消防安全重点单位"（如已有则跳过）
  ├── 清空或选择未命中类别
  │     └── 自动移除"消防安全重点单位"标签（手动添加的保留）
```

### 5.2 新增时自动初始化管理员账号 ⭐

提交创建企业时，后端在**同一事务**内级联执行以下操作：

```
POST /api/admin/enterprises
  │
  ├── ① 创建企业记录（生成企业唯一码 + 二维码）
  │
  ├── ② 账号创建 / 匹配
  │     以 contactPhone 检索 User 表：
  │     ├── 已存在 → 匹配已有 User，不重复创建
  │     └── 不存在 → 新建 User
  │           phone    = contactPhone
  │           realName = contactName
  │           password = bcrypt("admin123!@#")
  │           status   = 启用
  │
  ├── ③ 岗位绑定 + 企业关系
  │     写入 UserEnterprise：
  │       userId      = ②中匹配或新建的 User.id
  │       enterpriseId = ①中新建的 Enterprise.id
  │       position    = "企业管理员"（key=org-admin，平台统一通用岗位）
  │       status      = 正常
  │
  └── ④ 企业间关联（条件触发）
        若 parentId 非空：
        ├── 校验一企业一上级（该企业未被其他企业纳为下级）
        ├── 校验环检测（parentId 不能间接是当前企业的下级）
        └── 创建关联：parentId ──下级管理→ 新企业
            数据权限沿链自动透传
```

**失败处理**：任一步骤失败则整体回滚，前端展示具体失败原因（如"该手机号对应的用户已被停用""上级企业选择不合法"等）。

### 5.3 交互行为

| 操作 | 触发条件 | 行为描述 |
|------|---------|---------|
| 进入新增 | 列表页点击[新增租户] | 打开新增页面，步骤=1，表单为空 |
| 进入编辑 | 列表页点击[编辑] | 打开编辑页面，回填已有数据（含三维度 + 应用配置），步骤=1。不展示管理员账号信息 |
| 下一步 | 步骤1 点击[下一步] | 校验步骤1所有可见必填字段 → 切换步骤=2 |
| 上一步 | 步骤2 点击[上一步] | 切换步骤=1，已填数据保留 |
| 保存(新增) | 步骤2 点击[保存] | 全量校验 → POST（含 §5.2 级联操作）→ 成功跳转详情页 |
| 保存(编辑) | 任一步骤点击[保存] | 全量校验 → PUT → 成功返回详情页。**仅更新企业信息**，不修改 User 或 UserEnterprise |
| 取消 | 点击[取消] | 如有修改，ElMessageBox.confirm "放弃已填写内容？"确认后返回列表 |
| 工商数据查询 | 企业名称 input 失焦 | 调工商数据接口，自动回填 dimC + region + address（若为空） |
| 应用配置 | 步骤2 初始化 | 新增：默认全部关闭；编辑：回填已保存配置 |
| 上级企业选择 | parentId select 远程搜索 | 仅检索/选择已有企业，不支持在 select 下拉中新建。防抖 300ms |

### 5.4 特殊规则

- 编辑时企业唯一码（code）不可修改，不在表单中展示
- 编辑时企业二维码不可修改（唯一码不变则二维码不变），不在表单中展示
- **编辑时修改联系人信息（contactName/contactPhone）不自动同步 User 或 UserEnterprise**。更换联系人 ≠ 更换管理员，管理员移交走用户管理模块独立流程
- 步骤切换时已填数据保留在当前页面状态（Pinia store）
- 三维度 B/C/D 均为非必填，建议填写
- 维度 C 推荐对接工商数据自动带出，减少手工填写
- 维度 B 选中重点类别时自动打标签，清空时自动移除
- 企业不再有固定角色（原维度 A 已移除；角色在相关方关联时指定，见 [企业详情.md §Tab: 相关方管理](企业详情.md#tab-相关方管理)）
- **上级企业选择器仅检索/选择已有企业**，不支持在组件内新增。如需创建新上级企业，先到租户列表创建该企业再回来选择
- **企业管理员岗位为平台统一 "企业管理员"（org-admin）**，不区分物业/服务/监管方变体。后续可在用户管理中手动调整为细分变体
