# 新增/编辑租户 — 设计文档

---

## 一、页面元信息

| 项目 | 内容 |
|------|------|
| 页面名称 | `新增/编辑租户` |
| 所属模块 | `租户管理` |
| 页面类型 | `表单提交` |
| 路由路径 | `/admin/enterpriseManagement/create` `/admin/enterpriseManagement/edit?id=` |

### 功能描述

新增或编辑租户企业的多步骤向导表单。步骤1填写企业基本信息和四维度属性，步骤2配置应用功能权限。新增时自动生成企业唯一码和二维码。

---

## 二、页面结构

### 表单提交 页布局（多步骤向导）

| # | 区域名称 | 位置 | 注册表组件 | 包含元素 |
|---|---------|------|-----------|---------|
| 1 | 步骤导航 | 顶部 | `el-steps` | 2 步：填写企业信息 → 应用功能配置，`active` 表当前步骤 |
| 2 | 步骤1：基本信息区块 | 顶部 | `FormDrawer` 内 `el-card` | 企业名称*(input) + 企业负责人*(input) + 负责人联系电话*(input) + 企业标签(input) + 有效期(date-range) + 行政区划(cascader 省/市/区) + 上级企业(select 远程搜索) + 详细地址(input) + 备注(textarea) + 企业 logo(upload) + 地图标注(input+定位按钮) |
| 3 | 步骤1：企业属性区块 — 维度 A | 中部 | `FormDrawer` 内 `el-card` | **卡片标题"平台管理角色"** + 维度A 一级*(select: 监管方/管理方/社会单位/服务单位/平台运营方) → 二级(select, 一级=管理方时显示) → 三级(select, 二级=空间管理方时显示) |
| 4 | 步骤1：企业属性区块 — 维度 C | 中部 | `FormDrawer` 内 `el-card` | **卡片标题"行业分类 (GB/T 4754-2017)"** + 维度C 行业分类(select, 97 大类) — 推荐对接工商数据自动带出 |
| 5 | 步骤1：企业属性区块 — 维度 B + D | 中部 | `FormDrawer` 内 `el-card` | **卡片标题"消防属性"** + 维度B 消防单位类别(select, XF/T 3016.1-2022, ~30 项) + 维度D 场所/建筑类型(select)。**联动规则**：维度A一级=社会单位时，B/D 必填且卡片展开；非社会单位时 B/D 隐藏，卡片收起。卡片副标题提示"社会单位必填" |
| 6 | 步骤2：应用功能配置 | 中部 | `FormDrawer` 内 `el-card` | 13 域 Tab × 模块树 checkbox，按维度 A 推荐默认勾选（见 §5.3） |
| 7 | 底部操作栏 | 底部 | `ToolBar` | left：[取消](link)；right：[上一步](default, 步骤2) + [下一步/保存](primary) |

## 五、业务逻辑

### 5.1 维度 A 联动规则（核心）

```
一级 select 变化：
  ├── "管理方"
  │     └── 显示 二级 select（空间管理方 / 集团管理方）
  │           ├── "空间管理方" → 显示 三级 select（物业管理方/园区管理方/市场管理方/综合体管理方/商业街管理方）
  │           └── "集团管理方" → 隐藏 三级
  ├── "监管方"
  │     └── 无二级 → 直接显示 三级 select（消防救援机构/应急管理部门/属地政府/行业主管部门）
  ├── "社会单位"
  │     └── 无二级/三级 → 显示并展开"消防属性"区块（dimB + dimD 必填）
  ├── "服务单位"
  │     └── 无二级 → 显示 三级 select（消防技术服务机构）
  └── "平台运营方"
        └── 无二级/三级
```

### 5.2 维度 B/D 可见性规则（§3.6 适用性）

| 维度 A 一级 | dimB 消防类别 | dimC 行业分类 | dimD 场所类型 |
|------------|:--:|:--:|:--:|
| 监管方 | 隐藏 | 可选 | 隐藏 |
| 管理方 | 隐藏 | 可选 | 可选 |
| 社会单位 | **必填** | 推荐 | **必填** |
| 服务单位 | 隐藏 | 可选 | 隐藏 |
| 平台运营方 | 隐藏 | 可选 | 隐藏 |

### 5.3 应用配置默认推荐

| 维度 A 一级 | 推荐的默认应用 |
|------------|--------------|
| 监管方 | 数据可视化 + 政务管理 + 巡查检查 + 隐患管理 |
| 管理方 | 设备管理 + 巡查检查 + 隐患管理 + 项目管理 |
| 社会单位 | 维保应用 + 培训与演练 |
| 服务单位 | 维保应用 + 工单管理 |
| 平台运营方 | 全部 |

### 5.4 交互行为

| 操作 | 触发条件 | 行为描述 |
|------|---------|---------|
| 进入新增 | 列表页点击[新增租户] | 打开新增页面，步骤=1，表单为空 |
| 进入编辑 | 列表页点击[编辑] | 打开编辑页面，回填已有数据（含四维度 + 应用配置），步骤=1 |
| 维度 A 联动 | 一级 select 变化 | 清空已选的二级/三级 → 按 §5.1 规则显隐后续 select → 按 §5.2 规则显隐维度 B/D 区块 |
| 下一步 | 步骤1 点击[下一步] | 校验步骤1所有可见必填字段 → 切换步骤=2 |
| 上一步 | 步骤2 点击[上一步] | 切换步骤=1，已填数据保留 |
| 保存(新增) | 步骤2 点击[保存] | 全量校验 → POST → 成功跳转详情页，企业唯一码+二维码后台生成 |
| 保存(编辑) | 任一步骤点击[保存] | 全量校验 → PUT → 成功返回详情页 |
| 取消 | 点击[取消] | 如有修改，ElMessageBox.confirm "放弃已填写内容？"确认后返回列表 |
| 工商数据查询 | 企业名称 input 失焦 | 调工商数据接口，自动回填 dimC + region + address（若为空） |
| 应用配置 | 步骤2 初始化 | 新增：按维度 A 推荐默认勾选；编辑：回填已保存配置 |

### 5.5 特殊规则

- 编辑时企业唯一码（code）不可修改，不在表单中展示
- 编辑时企业二维码不可修改（唯一码不变则二维码不变），不在表单中展示
- 步骤切换时已填数据保留在当前页面状态（Pinia store）
- 维度 A 一级为必填（所有企业），维度 B/D 条件必填（仅社会单位）
- 维度 C 推荐对接工商数据自动带出，减少手工填写
- 二级/三级 select 联动清空：父级变化时子级选项重置为未选

- 一级 = `service_unit` → 无二级，三级必选（`fire_tech_service`）
