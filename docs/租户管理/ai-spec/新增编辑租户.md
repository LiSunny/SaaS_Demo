# 新增/编辑租户 — 设计文档

---

## 一、页面元信息

| 项目 | 内容 |
|------|------|
| 页面名称 | `新增/编辑租户` |
| 所属模块 | `租户管理` |
| 页面类型 | `表单提交` |
| 路由路径 | `/admin/enterpriseManagement/create` `/admin/enterpriseManagement/edit?id=` |

### 功能描述

新增或编辑租户企业的多步骤向导表单。步骤1填写企业基本信息和三维度属性（B/C/D），步骤2配置应用功能权限。新增时自动生成企业唯一码和二维码。

## 二、页面结构

### 表单提交 页布局（多步骤向导）

| # | 区域名称 | 位置 | 注册表组件 | 包含元素 |
|---|---------|------|-----------|---------|
| 1 | 步骤导航 | 顶部 | `el-steps` | 2 步：填写企业信息 → 应用功能配置，`active` 表当前步骤 |
| 2 | 步骤1：基本信息区块 | 顶部 | `FormDrawer` 内 `el-card` | 企业名称*(input) + 企业负责人*(input) + 负责人联系电话*(input) + 企业标签(input) + 有效期(date-range) + 行政区划(cascader 省/市/区) + 上级企业(select 远程搜索) + 详细地址(input) + 备注(textarea) + 企业 logo(upload) + 地图标注(input+定位按钮) |
| 3 | 步骤1：企业属性区块 — 维度 B + D（消防属性） | 中部 | `FormDrawer` 内 `el-card` | **卡片标题"消防属性"** + 维度B 消防单位类别(select, XF/T 3016.1-2022, ~28 项) + 维度D 场所/建筑类型(select, ~13 项)。均为可选填。卡片副标题"建议填写"。维度 B 选中命中类别时提示"将自动标记为消防安全重点单位" |

| 6 | 底部操作栏 | 底部 | `ToolBar` | left：[取消](link)；right：[上一步](default, 步骤2) + [下一步/保存](primary) |

## 三、数据模型

### 3.1 表单字段

| 字段名 | 中文名 | 类型 | 必填 | 控件类型 | 校验 / 说明 |
|--------|--------|------|:--:|---------|------|
| `name` | 企业名称 | `string` | ✅ | `input` | required, max:100 |
| `contactName` | 企业负责人 | `string` | ✅ | `input` | required, max:20 |
| `contactPhone` | 负责人联系电话 | `string` | ✅ | `input` | pattern:/^1[3-9]\d{9}$/ |
| `tags` | 企业标签 | `string` | — | `input` | 逗号分隔多个标签；维度 B 命中重点类别时自动追加"消防安全重点单位" |
| `validFrom` | 有效期起 | `string` | — | `date-picker` | — |
| `validTo` | 有效期止 | `string` | — | `date-picker` | — |
| `region` | 行政区划 | `string` | — | `cascader` | 省/市/区三级联动 |
| `parentId` | 上级企业 | `string` | — | `select` | 远程搜索，防抖 300ms |
| `address` | 详细地址 | `string` | — | `input` | max:200 |
| `remark` | 备注 | `string` | — | `textarea` | max:500 |
| `logo` | 企业 logo | `string` | — | `upload` | accept:image/jpeg,image/png, maxSize:2MB |
| `mapLocation` | 地图标注 | `string` | — | `input`+定位按钮 | 点击定位打开地图选点 |
| **维度 B** |
| `dimB` | 消防单位类别 | `string` | 否 | `select` | XF/T 3016.1-2022 预定义 ~28 项，所有企业可选填；选中命中类别自动打「消防安全重点单位」标签 |
| **维度 C** |
| `dimC` | 国民经济行业分类 | `string` | 否 | `select` | GB/T 4754-2017 大类 97 项，推荐对接工商数据自动带出 |
| **维度 D** |
| `dimD` | 场所/建筑类型 | `string` | 否 | `select` | 各省消防重点单位标准 ~13 项，所有企业可选填 |
| **步骤2** |
| `appConfig` | 应用功能配置 | `object` | — | — | 13 域模块树勾选状态，保存时一并提交 |

### 3.2 表单分区块

| 步骤 | 区块 | 卡片标题 | 包含字段 |
|------|------|---------|---------|
| 步骤1 | 基本信息 | 企业基本信息 | name, contactName, contactPhone, tags, validFrom, validTo, region, parentId, address, remark, logo, mapLocation |
| 步骤1 | 维度 B+D | 消防属性 | dimB, dimD（均非必填） |
| 步骤1 | 维度 C | 行业分类 (GB/T 4754-2017) | dimC（非必填，推荐对接工商数据） |
| 步骤2 | 应用配置 | 应用功能配置 | appConfig（13 域 Tab × 模块树） |

## 五、业务逻辑

### 5.1 维度 B 重点单位自动标记

```
维度 B select 变化：
  ├── 选中 XF/T 3016.1-2022 中任一类别
  │     └── 提示"该类别将自动标记为'消防安全重点单位'"
  │     └── 保存时 tags 自动追加"消防安全重点单位"（如已有则跳过）
  ├── 清空或选择未命中类别
  │     └── 自动移除"消防安全重点单位"标签（手动添加的保留）
```

### 5.2 交互行为

| 操作 | 触发条件 | 行为描述 |
|------|---------|---------|
| 进入新增 | 列表页点击[新增租户] | 打开新增页面，步骤=1，表单为空 |
| 进入编辑 | 列表页点击[编辑] | 打开编辑页面，回填已有数据（含三维度 + 应用配置），步骤=1 |
| 下一步 | 步骤1 点击[下一步] | 校验步骤1所有可见必填字段 → 切换步骤=2 |
| 上一步 | 步骤2 点击[上一步] | 切换步骤=1，已填数据保留 |
| 保存(新增) | 步骤2 点击[保存] | 全量校验 → POST → 成功跳转详情页，企业唯一码+二维码后台生成 |
| 保存(编辑) | 任一步骤点击[保存] | 全量校验 → PUT → 成功返回详情页 |
| 取消 | 点击[取消] | 如有修改，ElMessageBox.confirm "放弃已填写内容？"确认后返回列表 |
| 工商数据查询 | 企业名称 input 失焦 | 调工商数据接口，自动回填 dimC + region + address（若为空） |
| 应用配置 | 步骤2 初始化 | 新增：默认全部关闭；编辑：回填已保存配置 |

### 5.3 特殊规则

- 编辑时企业唯一码（code）不可修改，不在表单中展示
- 编辑时企业二维码不可修改（唯一码不变则二维码不变），不在表单中展示
- 步骤切换时已填数据保留在当前页面状态（Pinia store）
- 三维度 B/C/D 均为非必填，建议填写
- 维度 C 推荐对接工商数据自动带出，减少手工填写
- 维度 B 选中重点类别时自动打标签，清空时自动移除
- 企业不再有固定角色（原维度 A 已移除；角色在相关方关联时指定，见 [企业详情.md §Tab: 相关方管理](企业详情.md#tab-相关方管理)）
