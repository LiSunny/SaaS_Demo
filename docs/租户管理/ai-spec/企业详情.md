# 企业详情 — 设计文档

---

## 一、页面元信息

| 项目 | 内容 |
|------|------|
| 页面名称 | `企业详情` |
| 所属模块 | `租户管理` |
| 页面类型 | `详情展示` |
| 路由路径 | `/admin/enterpriseManagement/detail?id=` |

### 功能描述

企业详情展示页面。概览卡片（人员/管理单元/关联企业）+ 企业二维码 + 企业属性详情（三维度 B/C/D + 基本信息），以及下级管理、相关方管理、操作日志四个 Tab。支持编辑入口和返回列表。

## 二、页面结构

## 四、接口定义

| 操作 | 方法 | 路径 | 响应类型 |
|------|------|------|---------|
| 获取企业详情 | `GET` | `/api/admin/enterprises/{id}` | `EnterpriseItem` |
| 获取下级列表 | `GET` | `/api/admin/enterprises/{id}/subordinates` | `PaginatedData<SubordinateItem>` |
| 关联下级 | `POST` | `/api/admin/enterprises/{id}/subordinates` | — |
| 取消下级关联 | `DELETE` | `/api/admin/enterprises/{id}/subordinates` | — |
| 获取相关方列表 | `GET` | `/api/admin/enterprises/{id}/partners` | `PaginatedData<PartnerItem>` |
| 关联相关方 | `POST` | `/api/admin/enterprises/{id}/partners` | — |
| 取消相关方关联 | `DELETE` | `/api/admin/enterprises/{id}/partners` | — |
| 保存数据授权 | `PUT` | `/api/admin/enterprises/partners/{relationId}/auth` | `PartnerItem` |
| 获取操作日志 | `GET` | `/api/admin/enterprises/{id}/logs` | `PaginatedData<OperationLogItem>` |
| 下载二维码 | `GET` | `/api/admin/enterprises/{id}/qrcode/download` | `image/png` |
| 重新生成二维码 | `POST` | `/api/admin/enterprises/{id}/qrcode/regenerate` | `{qrcode:string}` |

## 五、业务逻辑

### 5.1 维度卡片展示规则

| 维度 | 卡片 | 展示条件 | 内容 |
|------|------|---------|------|
| B | 消防单位类别 | **始终显示** | 如"餐饮场所""商场市场"；未填写时显示"—" |
| C | 行业分类 | 始终显示 | 代码 + 名称，如"62 餐饮业"；未填写时显示"—" |
| D | 场所类型 | **始终显示** | 如"普通商铺""人员密集场所"；未填写时显示"—" |

> 维度 B+D 共用一个"消防属性"卡片（columns=2）。所有企业均展示，未填写时对应字段显示"—"。不再有条件显隐。

### 5.2 交互行为

| 操作 | 触发条件 | 行为描述 |
|------|---------|---------|
| 返回列表 | 点击[返回租户列表] | 跳转列表页 |
| 编辑 | 点击[编辑] | 跳转编辑页 `/admin/enterpriseManagement/edit?id={id}` |
| 下载二维码 | 点击[下载 PNG] | 浏览器下载 "{企业名称}_二维码.png" |
| 重新生成 | 点击[重新生成] | ElMessageBox.confirm "重新生成将覆盖现有二维码"，确认后调接口刷新 |
| 关联下级 | Tab下级管理 点击[关联下级] | FormDialog：多选远程搜索企业选择器 + 确定，提交后刷新 |
| 取消下级关联 | Tab下级管理 选中后点击[取消关联] | ElMessageBox.confirm，确认后调接口。若该下级有孙级 → 提示"该企业存在下级，请先解除其下级关联" |
| 关联相关方 | Tab相关方管理 点击[关联相关方] | FormDialog：多选远程搜索企业选择器 + 关系角色(必选) + 确定。提交后刷新，相关方列表展示关系角色列 |
| 取消相关方关联 | Tab相关方管理 选中后点击[取消关联] | ElMessageBox.confirm，确认后调接口 |
| 数据授权 | Tab相关方管理 点击行[数据授权] | FormDialog：管理单元 select + 操作权限 switch |
| 查看下级详情 | 下级表格点击企业名称 | 跳转该企业的详情页 |
| 切换 Tab | 点击 Tab 标签 | 下级管理/相关方管理/操作日志 Tab 首次进入时加载数据 |

### 5.3 特殊规则

- 指标卡片数据（staffCount/unitCount/relCount）从详情接口一次性返回
- 下级管理一企业一上级约束：取消前需校验孙级
- 相关方关联无数量限制，关联时必须指定关系角色
- 相关方列表增加"关系角色"列，支持按关系角色筛选
- 操作日志只读
- 二维码编码：H5 入口 URL + `?qy={code}`，code 不变则二维码不变
- 上级企业字段点击可跳转该上级的详情页
- 维度卡片均标注来源标准（XF/T 3016.1-2022 / GB/T 4754-2017 / 各省消防标准）

## 七、附录：维度卡片展示格式

### 维度卡片展示格式

| 维度 | 卡片标题 | 展示内容格式 | 示例 |
|------|---------|------------|------|
| B | — | 类别名称（含于"消防属性"卡片） | `餐饮场所` |
| C | 国民经济行业分类（维度 C） | 代码 + 空格 + 行业名称 | `62 餐饮业` |
| D | — | 类型名称（含于"消防属性"卡片） | `普通商铺` |

### 来源标准标注

| 维度 | 来源标注文字 | 颜色 |
|------|------------|------|
| B | XF/T 3016.1-2022 | `var(--text-secondary)` |
| C | GB/T 4754-2017 | `var(--text-secondary)` |
| D | 各省消防重点单位界定标准 | `var(--text-secondary)` |

> **v2.0 变更**：不再有维度 A 卡片和平台自定义来源标注。B+D 卡片不再按角色条件显隐（始终显示）。
