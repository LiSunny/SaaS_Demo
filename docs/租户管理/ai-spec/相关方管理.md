## 一、页面元信息

| 项目 | 内容 |
|------|------|
| 功能名称 | `相关方管理` |
| 所属模块 | `租户管理 > 企业详情 > Tab: 相关方管理` |
| 功能类型 | `列表管理 + 关联操作 + 数据授权` |

### 功能描述

在企业详情页的相关方管理 Tab 中，管理当前企业与外部企业的**数据共享关系**。核心操作：
- **关系绑定**：选择目标企业 + 指定关系角色（从"我的"视角）+ 可选标签，建立关联
- **数据授权**：为每个相关方配置管理单元范围 + 操作权限开关
- **关系解除**：解除数据共享关系
- 列表支持按企业名称、关系角色筛选

## 三、数据模型

### 3.1 相关方实体 (PartnerItem)

| 字段名 | 中文名 | 类型 | 说明 |
|--------|--------|------|------|
| `id` | 关联 ID | `string` | 关联关系唯一标识 |
| `enterpriseId` | 相关方企业 ID | `string` | 对方企业 ID |
| `enterpriseName` | 相关方企业名称 | `string` | — |
| `role` | 关系角色 | `PartnerRole` | **必填**，关联时指定，见 §3.2 |
| `roleLabel` | 关系角色显示 | `string` | 层级展示文本，如"我的管理方>空间管理方>商业街" |
| `tags` | 企业标签 | `string[]` | 对方企业的标签列表 |
| `contactName` | 负责人 | `string` | — |
| `contactPhone` | 联系方式 | `string` | — |
| `relatedAt` | 关联日期 | `string` | ISO 8601 |
| `operatorName` | 操作人 | `string` | 谁执行的关联操作 |
| `authUnits` | 授权管理单元 | `string[]` | 该相关方可访问的管理单元 ID 列表 |
| `allowOperation` | 允许操作 | `boolean` | 是否允许该相关方在企业内执行操作 |

### 3.2 关系角色枚举 (PartnerRole)

**设计原则**：从发起方（数据持有方）"我的"视角定义，角色标签始终以"我的"开头避免歧义。角色支持**二级结构**（父角色 > 子角色），满足平台化部署时不同场景的细分需求。

| 枚举值 | 标签文字 | 子类（示例） | 含义 |
|--------|---------|-------------|------|
| `my_supervisor` | 我的监管方 | 消防救援机构 / 应急管理部门 / 属地政府（街道/社区等） / 行业主管部门 | 对方对我有监管/检查职能 |
| `my_manager` | 我的管理方 | 空间管理方（物业/园区/市场/综合体/商业街等） / 集团管理方 | 对方是我的上级管理单位 |
| `social_unit` | 社会单位 | — | 落实消防安全主体责任的企业 |
| `my_service_unit` | 我的服务单位 | 消防技术服务机构（维保、检测、评估、工程安装等） | 对方为我提供消防技术服务 |
| `my_operator` | 我的运营方 | 运营管理方 | 对方负责我的日常运营管理 |

> **与旧版差异**：v1.0 中"我的服务商""我的客户""我的协作方"已移除，替换为"社会单位""我的服务单位""我的运营方"。

### 3.3 关系角色 StatusTag 颜色

| 角色 | 颜色类型 | el-tag type |
|------|:--:|------|
| 我的监管方 | `info` | 蓝色 |
| 我的管理方 | `warning` | 橙色 |
| 社会单位 | 自定义 `#10B981` | 绿色 |
| 我的服务单位 | 自定义 `#8B5CF6` | 紫色 |
| 我的运营方 | `normal` | 灰色 |

## 四、接口定义

| 操作 | 方法 | 路径 | 请求参数 | 响应类型 |
|------|------|------|---------|---------|
| 获取相关方列表 | `GET` | `/api/admin/enterprises/{id}/partners` | `{keyword?, role?, page, size, sortBy?, sortOrder?}` | `PaginatedData<PartnerItem>` |

| 编辑关联 | `PUT` | `/api/admin/enterprises/{id}/partners/{relationId}` | `{role?: PartnerRole, tags?: string[]}` | — |
| 取消相关方关联 | `DELETE` | `/api/admin/enterprises/{id}/partners` | `{ids: string[]}` | — |

## 六、业务逻辑

### 6.1 关联相关方流程

```
点击 [关联相关方]
  │
  ├── 打开关联弹窗（title="关系绑定"）
  │     ├── 企业名称：远程搜索企业（单选，防抖 300ms）
  │     │     ├── 排除当前企业自身
  │     │     ├── 排除已是相关方的企业
  │     │     └── 排除已是下级的被管企业（避免双重关联）
  │     ├── 关系角色：select（必选），带 Help 图标，悬停展示角色说明 tooltip
  │     └── 企业标签：select（可选），从字典接口加载
  │
  └── 点击 [保存]
        ├── 校验：必须选企业 + 必须选关系角色
        ├── POST /api/admin/enterprises/{id}/partners { enterpriseId, role, tags? }
        ├── 成功：ElMessage.success('关联成功') + 关闭弹窗 + 刷新列表
        └── 失败：ElMessage.error(后端返回的 message)
```

### 6.2 取消关联流程

```
选中行(checkbox) → 点击 [关系解除]
  │
  ├── 未选中行 → ElMessage.warning('请先选择相关方')
  │
  └── 已选中
        ├── ElMessageBox.confirm('确认解除与「{企业名称}」的相关方关联？解除后该企业将无法访问你的数据。')
        ├── [确认] → DELETE /api/admin/enterprises/{id}/partners { ids: [...] }
        ├── 成功 → ElMessage.success('已解除关联') + 刷新列表
        └── [取消] → 不做任何操作
```

### 6.3 数据授权流程

```
点击行操作 [数据授权]
  │
  ├── 打开数据授权弹窗
  │     ├── GET 接口获取当前授权状态（authUnits + allowOperation），回填表单
  │     ├── 管理单元 select：远程加载当前企业可用的管理单元列表
  │     └── 操作权限 switch：默认"不允许操作"
  │
  └── 点击 [保存]
        ├── PUT /api/admin/enterprises/partners/{relationId}/auth { authUnits, allowOperation }
        ├── 成功 → ElMessage.success('数据授权已保存') + 关闭弹窗
        └── 失败 → ElMessage.error
```

### 6.4 交互行为汇总

| 操作 | 触发条件 | 行为描述 |
|------|---------|---------|
| 查询 | 点击[查询] / 筛选条件变化 | 按当前筛选条件请求列表接口，刷新表格 |
| 关联相关方 | 点击[关联相关方] | 打开关联弹窗（见 §6.1） |
| 批量关系解除 | 选中 ≥1 行，点击[关系解除] | 走 §6.2 流程 |
| 单行关系解除 | 点击行操作 Delete 图标 | 自动选中该行 → 走 §6.2 流程 |
| 数据授权 | 点击行操作 Data-lock 图标 | 打开数据授权弹窗（见 §6.3） |
| 编辑关联 | 点击行操作 Edit 图标 | 打开编辑关联弹窗（可修改关系角色和企业标签） |
| 关联日期排序 | 点击表头排序按钮 | 切换升序/降序/默认（关联日期倒序） |
| 切换 Tab | 点击「相关方管理」Tab | Tab 首次进入时加载数据 |

### 6.5 特殊规则

- 相关方关联**无数量限制**，同一企业可关联无数个相关方
- **不阻止重复关联**同一企业——如果 A 已经以"我的服务单位"关联了 B，用户仍然可以再次以"我的运营方"关联 B（不同角色视为不同关联）。如需限制，可在后端添加 `enterpriseId + role` 唯一约束
- 关联弹窗中的企业选择器**拉取全平台企业**（排除自身 + 已有相关方 + 已有下级关联的企业），**单选**
- 关联弹窗中的关系角色旁有 Help 图标，悬停展示角色说明 tooltip（含各角色的子类示例，见 §3.2）
- 关系解除不校验数据依赖，直接解除（数据授权随之失效）
- 关系角色列展示为 StatusTag，按 §3.3 的颜色规则
- 列表默认按关联日期倒序（最近关联的在前），表头支持点击排序
- 分页器简化样式，无 pageSize 切换和跳页输入

## 八、与下级管理 Tab 的对照

| | 下级管理 | 相关方管理 |
|---|---|---|
| **语义** | "我管你" | "我把数据分享给你" |
| **发起方** | 上级发起 | 数据持有方发起 |
| **数据权限** | 自动全量 | 手动配置（数据授权弹窗） |
