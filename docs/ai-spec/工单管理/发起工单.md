## 一、页面元信息

| 项目 | 内容 |
| --- | --- |
| 页面名称 | 发起工单抽屉 |
| 所属模块 | 工单管理 |
| 页面类型 | 表单提交（el-drawer 抽屉模式，右侧 640px） |
| 路由路径 | 无独立路由（el-drawer，由 WorkOrderMonitor + QuickActionsWidget 触发） |
| 功能描述 | 从流程模板列表中选择模板，动态渲染模板定义的发起节点表单字段，用户填写后提交创建工单实例。 |

```
┌────────────────────────────────────────────────┐

│  direction="rtl"                               │
├────────────────────────────────────────────────┤
│  固定区域（不滚动）                             │
│                                                │
│  1. 模板选择区                                  │

│                                                │
│  2. 优先级选择（始终显示）                       │
│     el-radio-group: 普通 / 紧急 / 低优           │
│                                                │
├────────────────────────────────────────────────┤
│  滚动区域（flex:1, overflow-y:auto）            │
│                                                │
│  3. 表单区（选中模板后显示，只显示模板表单信息）   │
│     DynamicForm                                 │
│     :fields="formFields"                        │
│     :permissions="startNodePermissions"         │
│     ref="dynamicFormRef"                        │
│                                                │
├────────────────────────────────────────────────┤
│  底部按钮（固定，不随内容滚动）                  │

│  el-button type="primary" @click="submit"       │
│    提交（模板未选时 disabled）                   │
└────────────────────────────────────────────────┘
```

| # | 区域名称 | 位置 | 注册表组件 | 包含元素 |
| --- | --- | --- | --- | --- |
| 1 | 模板选择区 | **固定区**顶部 | `el-select filterable` | filterable 支持模糊搜索；**选中后可二次切换**（不禁用），切换后重新加载 DynamicForm |
| 2 | 优先级选择 | **固定区**（模板选择下方） | `el-radio-group` | 三个选项：普通（默认选中）、紧急、低优。**常显，不随表单滚动** |
| 3 | 动态表单区 | **滚动区**（flex:1, overflow-y:auto） | **`DynamicForm`** | 传入模板发起节点的 `fields` + 权限配置。模板未选时隐藏。**仅此区域可垂直滚动** |
| 4 | 提交按钮 | 抽屉底部固定 | `el-button` | 模板未选时 `disabled`；提交时调用 `dynamicFormRef.validate()` + `store.createOrder()` |

## 三、数据模型

### 3.1 新增类型（src/types/work-order.ts）

在现有类型基础上新增：

```typescript
// ===== 新增：表单数据相关 =====

/** 表单数据（聚合所有节点已提交的字段值），key 为 fieldId */
export type FormData = Record<string, any>

/** 节点表单记录 */
export interface NodeFormRecord {
  id: number
  nodeId: string
  nodeName: string
  submittedBy: string
  submittedByOrg: string
  submittedAt: string
  data: FormData
}
```

`WorkOrderItem` 新增字段：
```typescript
export interface WorkOrderItem {
  // ... 现有字段不变
  formData?: FormData  // ← 新增
}
```

`WorkOrderDetail` 新增字段：
```typescript
export interface WorkOrderDetail extends WorkOrderItem {
  // ... 现有字段不变
  nodeRecords?: NodeFormRecord[]  // ← 新增
}
```

### 3.2 创建工单参数（新增类型）

```typescript
export interface CreateOrderParams {
  templateId: number
  templateName: string
  templateVersion: number
  priority: 'normal' | 'urgent' | 'low'
  creatorName: string
  formData: FormData              // ← 用户填写的表单数据
  totalNodes: number              // ← 来自 flowDefinition.nodes.length
  ttrMinutes: number | null       // ← 来自模板 baseInfo.defaultTtrMinutes
  ttsMinutes: number              // ← 来自模板 baseInfo.defaultTtsMinutes
}
```

### 3.3 DynamicForm 组件接口

```typescript
// src/components/business/DynamicForm.vue

interface Props {
  fields: FormField[]              // 来自 formSchema[startNodeId].fields
  permissions: FieldPermission[]    // 来自 formSchema[startNodeId] 的节点权限
  initialData?: Record<string, any> // 预填数据（发起时为空）
  readonly?: boolean               // 全局只读模式
}

// 暴露方法
defineExpose({
  getFormData: () => Record<string, any>,   // 收集表单数据
  validate: () => Promise<boolean>,          // 校验必填字段
  reset: () => void,                         // 重置表单
})
```

## 六、业务逻辑

### 6.1 模板选择流程

```
1. onMounted → workflowStore.fetchList() → 获取已发布的模板列表
2. 用户从 el-select 选择模板
3. onChange(templateId) → getTemplateDetail(templateId)
4. 从 detail 提取:
   - formFields     = detail.formSchema[第一个节点].fields
   - permissions    = detail.formSchema[第一个节点].fieldPermissions（如有）
   - totalNodes     = detail.flowDefinition.nodes.length
   - ttrMinutes     = detail.baseInfo.defaultTtrMinutes
   - ttsMinutes     = detail.baseInfo.defaultTtsMinutes
5. 显示 DynamicForm，传入 fields + permissions
```

### 6.2 提交流程

```
1. 校验 dynamicFormRef.validate() → 必填字段检查
2. 收集 dynamicFormRef.getFormData() → Record<string, any>
3. 拼装 CreateOrderParams
4. 调用 store.createOrder(params)
5. emit('created', workOrder) → 父组件刷新列表
6. 关闭弹窗
```

### 6.3 特殊规则

- 模板列表应过滤只显示 **已发布状态（status === 1）** 的模板
- 默认 priority 为 `normal`
- `creatorName` 使用当前登录用户（当前为 mock：'张三'）
- 抽屉打开时重置 DynamicForm 状态（避免上次填写残留）
- **支持切换模板**：选中模板后 el-select 不禁用，切换后重新调用 `getTemplateDetail()` 加载新模板的表单字段，DynamicForm 重新渲染
- **模板选择区 + 优先级固定不滚动**，始终可见
- **仅动态表单区可纵向滚动**（drawer-scroll: flex:1, overflow-y:auto）
- **底部按钮固定**（el-drawer #footer slot 自动处理）
