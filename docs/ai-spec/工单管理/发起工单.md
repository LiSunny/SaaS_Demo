## 一、页面元信息

| 项目 | 内容 |
| --- | --- |
| 页面名称 | 发起流程抽屉 |
| 所属模块 | 工单管理 |

### 卡片样式规范

每张卡片统一使用以下样式：
- `border: 1px solid var(--border-default)`
- `border-radius: var(--radius-sm, 6px)`
- `padding: var(--spacing-lg, 12px)`
- 卡片间距：`var(--spacing-xl, 16px)`
- 卡片标题：18px Medium，`color: var(--text-secondary)`，底部间距 12px

## 六、业务逻辑

### 6.1 模板选择流程（不变）

```
1. onMounted → workflowStore.fetchList() → 获取已发布的模板列表
2. 用户从 el-select 选择模板
3. onChange(templateId) → getTemplateDetail(templateId)
4. 从 detail 提取:
   - formFields     = detail.formSchema[startNodeId].fields
   - permissions    = startNode.formFields（如有）
   - totalNodes     = detail.flowDefinition.nodes.length
   - ttrMinutes     = detail.baseInfo.defaultTtrMinutes
   - ttsMinutes     = detail.baseInfo.defaultTtsMinutes
5. 显示"表单信息"卡片，DynamicForm 渲染
```

### 6.2 提交流程

```
1. 校验静态必填字段：工单标题非空、优先级已选
2. 校验动态表单：dynamicFormRef.validate() → 必填字段检查
3. 收集数据：
   - 静态字段：title, priority, remark
   - 动态字段：dynamicFormRef.getFormData()
4. 拼装 CreateOrderParams → 调用 store.createOrder(params)
5. emit('created') → 父组件刷新列表
6. 关闭抽屉
```

### 6.3 特殊规则

- 模板列表应过滤只显示**已发布状态（status === 1）**的模板
- 默认 priority 为 `normal`
- `creatorName` 使用当前登录用户（当前为 mock：'张三'）
- 抽屉打开时重置所有状态（避免上次填写残留）
- **支持切换模板**：选中模板后 el-select 不禁用，切换后重新加载表单字段
- **基本信息字段为静态字段**：不依赖模板选择，始终显示
- **表单信息卡片**：模板未选时隐藏，选中后出现
- **底部按钮固定**（el-drawer #footer slot 自动处理）
