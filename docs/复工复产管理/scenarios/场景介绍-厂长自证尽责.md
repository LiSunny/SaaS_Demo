# 节后复工，出了事怎么证明"我尽责了"？

> 阅读时长：约 8 分钟
> 目标读者：企业法人、厂长/总经理、安全副总

📊 图示：厂长视角复工管理全链路图 — 建组→签责→培训→交底→排查→体检→整改→验收→复工令→值班→归档，每步标注"谁执行""自动记录什么"

---

## 涉及角色

| 角色 | 一句话职责 | 使用端 |
|------|-----------|:---:|
| 厂长/总经理 | 主持安全专题会，签发复工令，承担最终审批责任 | Web 端 |
| 车间主任 | 创建复工计划，组建团队，组织联合验收 | Web 端 |

## 为什么厂长最需要这个

节后复工事故中，**厂长/法人是第一责任人**。2024 年山西吕梁焦化厂事故，厂长被判刑；2025 年山东青岛粉尘爆炸，22 人被追责。厂长签复工令的那一刻，就是把法律责任扛在了自己肩上。

但传统方式下，厂长是被动的——车间说"准备好了"，你只能相信；出了事故，你说"我以为他们查了"，法庭上毫无用处。

> 完整行业背景、事故案例与法规依据见 [复工复产管理总体介绍](./场景介绍.md)。

这个场景聚焦于厂长怎么用系统摆脱"盲签"——**让每一步留痕成为法律上自证尽责的证据**。

---

## 典型一天

### 08:00 ｜ 打开复工看板，全厂进度一屏了然

今天是节后复工第三天。张厂长打开电脑，进入「复工复产管理」→「可视化大屏」。

全屏暗色主题下，4 个阶段 KPI 卡片一字排开：复工准备中 3 个车间、复工审核中 1 个车间、试产观察 0 个、正式复产 0 个。下面一张**阶段分布流图**——冲压车间已经推进到"复工审核"，涂装车间还在"复工准备"，装配车间刚完成建组。

📷 截图：复工复产可视化大屏 — 4 阶段 KPI 卡片 + 阶段分布流 + 车间×步骤热力图

热力图中，装配车间的"隐患排查"和"设备体检"两格还是灰色（待执行）。张厂长不需要打电话问车间主任——打开大屏的一瞬间，哪个车间卡在哪一步，清清楚楚。

---

### 10:30 ｜ 联合验收通过，复工令推到你面前

冲压车间的流程走到了关键时刻。车间主任已完成联合验收——车间主任、安全员、班组长三方在现场确认了培训记录、设备体检结果、隐患整改闭环，在系统中签字确认。

系统状态从"复工准备"自动流转到"复工审核"。张厂长收到通知：冲压车间等待签发复工令。

他打开冲压车间的详情页，看到前 8 步的汇总：安全培训 42 人参训、技术交底已确认 12 个岗位、隐患排查 5 条已全部整改销号、设备体检 23 台已逐台打钩。每一步都有照片、签名、时间戳。

📷 截图：复工计划详情页 — 4 阶段进度条 + 步骤摘要卡片 + 验收通过后系统提示"等待签发复工令"

张厂长在"签发复工令"步骤中输入结论——"已完成全部复工准备，准予复工"——然后手写电子签名，提交。系统记录签发时间、签发人、签名图像。

**这一步不是走过场。** 厂长签名意味着承担最终责任。在此之前的 8 步全部留痕，在此之后的试产和归档同样可追溯。从法律角度看，这条签名是整个证据链最关键的节点。

---

### 14:00 ｜ 归档完成，一键导出全套迎检材料

一周后，冲压和涂装车间都完成了试产观察，进入"正式复产"。安全员执行最后一步——归档组卷，确认所有材料齐全。

张厂长再次打开系统。冲压车间的计划状态已经是"正式复产"。他点击右上角"导出档案包"——系统生成一份涵盖 11 个步骤的完整档案：建组名单、责任状签署记录、培训签到表、技术交底确认单、隐患排查与整改闭环记录、设备体检报告、联合验收签字表、厂长复工令、试产值班记录。

📷 截图：复工计划详情页 — 归档完成状态 + "导出档案包"按钮

全部是 PDF 格式，带时间戳和电子签名。可以打印、可以存档、可以直接提交给应急管理部门。

下个月安全监察科来检查。张厂长不用再去翻文件柜——打开系统，调出冲压车间的档案包，从头到尾、从人到设备、从培训到复工令——每一页都有签字，每一步都有时间。

**这就是"自证尽责"——不是靠嘴说，是靠系统里的每一条记录。**

## 核心价值

| 角色 | 价值 |
|------|------|
| **厂长/总经理** | 不靠"听说"做决策——打开看板就知道全厂各车间推进到哪一步。签发复工令时有 8 步记录做背书，不是盲签。出了事故能自证尽责 |
| **车间主任** | 4 阶段 11 步骤系统内嵌 SOP 引导，新上任的主任也能按指引跑通全流程，不依赖老员工口头带教 |
| **车间安全员** | 培训、交底、排查、归档——每步有模板、有留痕。检查时不再翻纸盒子，一键导出完整档案包 |
| **班组长/班组成员** | 操作不复杂——系统录入、电子签名、拍照上传，跟微信差不多。但每一步的记录都不可篡改，出问题时保护的是自己 |
| **全链条** | 从"建组"到"归档"，11 步闭环，每步自动记录完成人+时间。不是人管人，是流程管人——每一步都是法律上"我已尽责"的证据 |
