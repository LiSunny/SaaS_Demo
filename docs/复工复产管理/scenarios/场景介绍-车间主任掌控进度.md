# 三个车间同时复工，怎么做到心里有数？

> 阅读时长：约 7 分钟
> 目标读者：车间主任、生产主管、工段长

📊 图示：车间主任复工管理流程图 — 创建计划→建组→各班组并行执行步骤 1-7→联合验收→移交厂长签发

---

## 涉及角色

| 角色 | 一句话职责 | 使用端 |
|------|-----------|:---:|
| 车间主任 | 创建复工计划，组建复工团队，统筹全流程，组织联合验收 | Web 端 |
| 车间安全员 | 执行安全培训、技术交底，审核隐患整改，最终归档 | Web 端 |
| 班组长 | 牵头设备逐台检查、隐患整改闭环、签署责任状 | Web 端 |
| 班组成员 | 参与培训签到、签署责任状、随手拍上报隐患 | Web 端 |
| 厂长/总经理 | 签发复工令，完成最终审批 | Web 端 |

---

## 为什么车间主任最需要这个

节后复工，冲压、焊接、涂装、总装——几个车间同时推进。每个车间 11 个步骤、几十台设备、若干条隐患。车间主任是厂长签字前的**最后一道防线**——在验收之前，必须确保每一步都落实了、每一关都有人签字。

但传统方式靠打电话、微信群、Excel 三件套，"快了快了""差不多了"——信息滞后、缺项难发现、换人得从头教。

> 完整行业背景、事故案例与法规依据见 [复工复产管理总体介绍](./场景介绍.md)。

这个场景聚焦于车间主任怎么用系统**一屏掌控多车间进度，验收不再凭感觉**。

## 典型一天

### 08:30 ｜ 节后第一天，创建复工计划

年后开工第一天。冲压车间主任刘工打开系统，进入「复工复产管理」页面。

他点击"新建复工计划"。弹出一个简洁的表单——输入复工场所名称：冲压车间。关联到管理单元树中对应的车间节点。提交。

📷 截图：新建复工计划弹窗 — 复工场所名称输入框 + 管理单元树选择器

计划创建后，第一步"建组"自动弹出。刘工录入复工组织小组——自己是组长，加上副组长（安全员老张、两个班组长），再拉进各班的班组成员。每个人的姓名、岗位一键选择。

📷 截图：步骤 1 建组 — 成员列表编辑 + 角色选择 + 岗位关联

以前他得拉一个微信群，手动@所有人。现在系统里建完组，每个人的角色和职责在后续步骤中自动关联——签责时该谁签、培训时该谁参加、设备检查时该谁负责——系统全都知道。

---

### 09:00 ｜ 各班组开工，步骤在系统里推进

冲压车间共 11 步。复工准备阶段（步骤 1-7）不限顺序——各班组可以根据现场条件并行执行。

安全员老张已经开始"安全培训"——42 人参训，主题"节后复工复产安全须知"，培训地点在车间会议室，线下授课。老张在系统里录入培训信息、上传签到照片。步骤状态变成"已完成"，系统自动记录完成人和时间。

📷 截图：步骤 3 安全培训 — 培训主题/地点/日期/形式/参与人员录入 + 照片上传区

同时，一班组长带着班组在做"设备体检"——系统里弹出设备检查清单，逐台逐项打钩：冲压机 01 外观完好、急停按钮正常、润滑到位。异常的设备拍照标记。23 台设备，花了 40 分钟，全部检查完成。步骤状态变蓝——完成。

📷 截图：步骤 6 设备体检 — 设备列表（名称/位置/检查人/结果状态）+ 设备详情弹窗（检查项逐条打钩 + 异常照片标记）

---

### 11:00 ｜ 一屏看进度，不用打电话

三个车间正在同时复工：冲压车间（刘工自己）、涂装车间、装配车间。

刘工回到复工计划列表页。页面顶部是 4 阶段统计卡片：复工准备 3 个、复工审核 0 个、试产观察 0 个、正式复产 0 个。下面可以切换**卡片视图**或**列表视图**。

📷 截图：复工计划列表页（卡片视图）— 4 阶段统计卡片 + 各车间卡片（车间名 + 当前阶段进度条 + 已完成/总步骤数）

刘工切到列表视图看细节——冲压车间 11 步已完成 5 步，涂装车间 11 步已完成 3 步，装配车间 11 步已完成 2 步。装配车间的"隐患排查"步骤仍是灰色——还没开始。

以前刘工要打三个电话问进度，现在一屏看完。装配车间卡在隐患——他直接过去了解情况，协调资源。

---

### 14:00 ｜ 组织联合验收，缺一样都拦下

冲压车间 7 个准备步骤全部完成。系统状态自动推进到"复工审核"。

刘工作为车间主任，与安全员老张、一班班长三人一起做联合验收。系统将前序 7 步的汇总展示在验收界面——培训记录是否齐全、设备体检是否有漏项、隐患整改是否全部销号、责任人是否都签了字。

📷 截图：步骤 8 联合验收 — 前序步骤汇总卡片 + 验收结论录入 + 三方签名板

全部确认通过，三方在系统中签名。验收完成。前序步骤自动锁定——不能再修改。

---

### 16:00 ｜ 归档组卷，闭环完成

最后一步——归档组卷——由安全员老张执行。系统提示"全部步骤已完成，请确认归档"。

老张确认后，11 个步骤、4 个阶段的全部记录自动打包。从建组名单到复工令，形成一份完整的复工档案。刘工再看一眼列表——冲压车间状态：正式复产，绿色标签。

📷 截图：复工计划列表页（列表视图）— 冲压车间状态列：正式复产（绿色标签）+ 已完成步骤数 11/11

## 核心价值

| 角色 | 价值 |
|------|------|
| **车间主任** | 不再打电话问进度——一屏看全局。多车间同时复工互不干扰，哪个卡在哪个步骤一眼定位。系统内嵌 11 步 SOP，新主任也能跟着走通 |
| **安全员** | 培训、交底、排查——每步有结构化表单引导，不再自己设计表格。所有记录自动归入统一档案，跨班组的数据能横向对比 |
| **班组长** | 设备检查清单化——不用自己记要查什么，系统逐项引导。查完拍照打钩就是证据，比微信随手拍更标准、更能追溯 |
| **班组成员** | 培训签到电子化、责任状电子签署——不填纸质表。隐患随手拍上报，推送到整改人，有人跟、有人催、有人验收 |
| **全链条** | 从"建组"到"归档"，一人一条操作轨迹。不缺、不漏、不靠口头交接——系统替你盯、替你记、替你催 |
