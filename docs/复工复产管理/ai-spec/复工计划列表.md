# ai-spec：复工计划列表

> 页面路由：`/resumption` | 页面类型：列表管理（列表/卡片双视图） | 深度：🔵 light | 最后更新：2026-07-21

## 1. 组件树

```
PlanList (list-page)
└── content-card
    ├── metric-row（4 阶段统计卡片）
    │   ├── metric-card.prepare（复工准备 × N）
    │   ├── metric-card.review（复工审核 × N）
    │   ├── metric-card.trial（试产观察 × N）
    │   └── metric-card.production（正式复产 × N）
    ├── filter-bar
    │   ├── filter-left
    │   │   ├── search-input-wrap > fi-input + fi-icon
    │   │   ├── fi-select-wrap > el-select（状态筛选）
    │   │   ├── btn-primary [查询]
    │   │   └── btn-default [重置]
    │   └── filter-right
    │       ├── view-toggle（▦ 卡片 / ☰ 列表）
    │       └── btn-outline-primary > AppIcon(plus) [新建计划]
    ├── [列表视图 v-if="viewMode==='list'"] table-wrap > table.fi-table
    │   ├── thead > fi-thead-tr
    │   │   ├── col-name（复工场所）
    │   │   ├── col-status（状态）
    │   │   ├── col-date（开始时间 + TableSortIcon）
    │   │   ├── col-date2（完成时间）
    │   │   └── col-actions（操作）
    │   └── tbody > fi-tbody-tr × N
    │       └── action-cell > act-btn(act-preview) > AppIcon(preview)
    ├── [卡片视图 v-if="viewMode==='card'"] card-grid
    │   └── plan-card × N
    │       ├── card-header > card-name + StatusTag
    │       ├── card-progress > progress-bar > progress-fill + progress-text（X/11 步）
    │       └── card-meta（开始时间 / 完成时间）
    └── pagination-wrap > pagi-total + el-pagination
```

## 2. 数据流

```
useResumptionStore
├── fetchList() → store.list
│   ├── metric-row 统计：stats = { prepare, review, trial, production }
│   ├── 列表视图：table > tbody v-for
│   └── 卡片视图：card-grid > plan-card v-for
├── query: { keyword, status, page, size }
├── createResumptionPlan(name, enterpriseId, locationId) → 新建
└── dateSortDir（开始时间列排序）
```

## 3. 交互状态

| 状态 | 触发条件 | UI |
|------|---------|-----|
| 加载中 | store.loading | v-loading |
| 视图切换 | 点击 ▦ / ☰ 按钮 | viewMode = 'card' / 'list' |
| 排序 | 点击开始时间列头 | toggleDateSort() |
| 筛选 | 输入关键词 / 选状态 | store.search() |
| 新建 | 点击"新建计划" | el-dialog：选择管理单元 |
