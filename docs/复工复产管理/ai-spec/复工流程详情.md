| 阶段 | 标签 | 子步骤 | 关键节点 | 编辑规则 |
|------|------|--------|:---:|------|
| 复工准备 | 复工准备 | ①-⑦（建组→整改） | — | 自由编辑，不限顺序 |
| 复工审核 | 复工审核 | ⑧联合验收 + ⑨签发复工令 | 🔑 金色 | 验收后前序锁定，只编辑当前步骤 |
| 试产观察 | 试产观察 | ⑩试产值班 | 🔑 金色 | 审核后锁定，只编辑步骤 10 |
| 正式复产 | 正式复产 | ⑪归档组卷 | — | 全部只读 |

## 4. 数据流

```
useResumptionStore.fetchDetail(planId)
    │
    ├── detail → summary-card
    ├── selectedStage → currentStageSteps = filter by stage.stepOrders
    │   └── sub-steps-panel 渲染子步骤
    ├── selectedStepId → selectedStep
    │   ├── 通用详情（角色/法规/完成人/时间/备注）
    │   ├── stepType=joint-acceptance → signers-section
    │   └── stepType=issue-order → order-section (detail.order)
    ├── stageState(stage) → done/active/pending
    │   ├── done = 该阶段所有子步骤完成 → 绿色 ✓
    │   ├── active = 部分完成 → 蓝色填充
    │   └── pending = 全部待执行 → 灰色
    └── canEdit(step)
        ├── preparing → stepOrder ≤ 8 可编辑
        ├── trial → 仅第一个未完成步骤可编辑
        └── archived → 不可编辑
```

## 5. 交互状态

| 状态 | 触发条件 | UI |
|------|---------|-----|
| 加载中 | detailLoading | loading-wrap |
| 不存在 | detail === null | empty-wrap |
| 阶段切换 | 点击 stage-node | 子步骤面板展开 + 自动选中首个未完成步骤 |
| 子步骤选中 | 点击 sub-step-item | 详情卡片更新、标题栏操作按钮刷新 |
| 标记完成 | 点击「标记完成」可编辑 + 步骤未完成 | 弹窗（完成人 + 备注）|
| 修改 | 点击「修改」可编辑 + 步骤已完成 | 弹窗（完成人 + 备注 + 状态开关）|
| 不可编辑 | 步骤锁定或计划已归档 | 标题栏无操作按钮 |

## 6. 边界条件

| 场景 | 处理 |
|------|------|
| 阶段无子步骤 | sub-steps-panel 不渲染（v-if="currentStageSteps.length"） |
| 所有步骤完成 | 选中最后一个阶段 + 最后一个步骤 |
| 验收未完成 | 签字人员区域不渲染 |
| 复工令未签发 | order-section 不渲染（v-if="detail.order"） |
| localStorage 残留旧数据 | 数据模型兼容，stage 字段从 STEP_META 静态读取 |
