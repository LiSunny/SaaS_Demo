## 1. 组件树

```
AcceptancePage (detail-page)
├── page-top
│   ├── button.btn-link [← 返回流程详情]
│   └── el-breadcrumb > 复工复产管理 > 复工流程详情 > 验收与签发
├── page-header
│   ├── h2.page-title {{ locationName }} · 验收与签发
│   └── StatusTag(plan_xxx)
├── content-grid（左右两栏）
│   ├── info-card [联合验收]
│   │   ├── card-header > card-title + StatusTag(step_xxx)
│   │   └── card-body
│   │       ├── [已完成] info-row ×3（结论/验收人/时间）+ signers-section
│   │       │   └── signer-list > .signer-item ×3（角色·姓名 ✓）
│   │       └── [未完成] .empty-hint
│   └── info-card [复工令]
│       ├── card-header > card-title + StatusTag
│       └── card-body

    └── card-body > .step-checklist > .check-item ×7（✓/○ + 步骤名）
```

| 面包屑 | el-breadcrumb | — |

## 3. 数据流

```
useResumptionStore.fetchDetail(planId)
    │
    ├── detail.steps → acceptanceStep = find(stepType === 'joint-acceptance')
    ├── detail.steps → preAcceptanceSteps = filter(stepOrder 1-7)
    ├── detail.team  → acceptanceSigners = filter(车间主任/安全员/班组长)
    └── detail.order → 复工令签发状态
```

## 4. 交互状态

| 状态 | 条件 | UI |
|------|------|-----|
| 加载中 | detailLoading | loading-wrap |
| 不存在 | detail === null | empty-wrap |
| 验收未完成 | acceptanceStep.status !== 'done' | .empty-hint |
| 验收已完成 | acceptanceStep.status === 'done' | 验收结论 + 签字人列表 |
| 复工令未签发 | detail.order === null | .empty-hint |
| 复工令已签发 | detail.order !== null | 签发人/时间/结论 |
