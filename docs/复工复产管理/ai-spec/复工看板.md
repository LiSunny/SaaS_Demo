# ai-spec：复工看板

> 页面路由：`/resumption/dashboard` | 页面类型：统计看板 | 深度：🔵 light | 最后更新：2026-07-20

## 1. 组件树

```
Dashboard (dashboard-page)
├── page-top
│   ├── button.btn-link [← 返回列表]
│   └── el-breadcrumb > 复工复产管理 > 复工看板
├── metric-row（3 列统计卡片）
│   ├── metric-card.metric-preparing > metric-value + metric-label [筹备中]
│   ├── metric-card.metric-trial > metric-value + metric-label [试产中]
│   └── metric-card.metric-archived > metric-value + metric-label [已归档]
├── workshop-grid（自适应网格，minmax(300px, 1fr)）
│   └── workshop-card ×N（clickable → /resumption/:id）
│       ├── ws-header > ws-name + StatusTag
│       ├── ws-progress
│       │   ├── progress-bar > .progress-fill（width = stepPercent%）
│       │   └── progress-text [X/11 步已完成]
│       ├── ws-current > current-label + current-value（当前步骤名）
│       └── ws-meta > ws-meta-item ×2（开始时间 / 完成时间）
│
│   └── [空状态] .empty-card > p + btn-outline-primary [去创建计划]
└── [加载] .loading-wrap（v-loading）
```

## 2. 组件映射

| 设计元素 | 组件 | 来源 |
|---------|------|------|
| 状态标签 | StatusTag | 注册表复用 |
| 统计卡片 | 自定义 `.metric-card` | 页面 scoped（无适合的注册表组件） |
| 车间卡片 | 自定义 `.workshop-card` | 页面 scoped |
| 进度条 | 自定义 `.progress-bar` + `.progress-fill` | 页面 scoped |
| 面包屑 | el-breadcrumb | Element Plus |
| 返回按钮 | .btn-link | style.css 全局类 |

## 3. 数据流

```
useResumptionStore.fetchList()（size=100，拉全量）
    │
    ├── store.list → filter by status → stats { preparing, trial, archived }
    ├── store.list → .workshop-card ×N
    │   ├── completedSteps(plan) → 1-11 数字 + stepPercent(%)
    │   └── getStepLabel(plan) → 当前步骤名称
    └── store.loading → loading-wrap
```

## 4. 交互状态

| 状态 | UI |
|------|-----|
| 加载中 + 空列表 | v-loading 遮罩 |
| 加载完 + 有数据 | 统计卡片 + 车间卡片网格 |
| 加载完 + 无数据 | "暂无复工计划" + 去创建按钮 |
| 点击车间卡片 | 跳转 `/resumption/:id` |

## 5. 边界条件

| 场景 | 处理 |
|------|------|
| 看板全量拉取超过 100 条 | 当前 seed data 仅 3 条，无需分页；生产环境需后端聚合接口 |
| 开始时间为空 | 显示 `—` |
| 完成时间为空（未完成状态） | 该 ws-meta-item 不渲染 |
| 进度条 0% | progress-fill width=0%，视觉不可见 |
| 响应式 < 700px | 统计卡片从 3 列变为 1 列 |
