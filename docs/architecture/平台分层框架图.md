## 二、"7 项配置 → 9 引擎"映射（图上信息密度大，下面用表格再展开一遍）

| 7 项配置 | → | 对应引擎 | 引擎一句话 |
|---|---|---|---|
| 台账对象 | → | 数字台账 | 管"有什么"：对象、关系、生命周期、指标 |
| 表单字段 | → | 动态表单 | 管"填什么"：业务自己画，字段权限三态 |
| 流程节点 | ┐ | 流程编排 | 管"怎么走"：模板/节点/流转/指派/时限 |
| 流转规则 | ┘ | ↑ | ↑ |
| 校验规则 | → | 规则引擎 | 管"怎么判断"：条件、判定、结论 |
| 处置策略 | → | 策略执行 | 管"自动做什么"：触发、动作、留痕 |
| 消息模板 | → | 消息中心 | 管"怎么通知"：模板、通道、送达回执 |

**任务调度 / 统计服务 / 报表引擎** 是"通用件"——每个场景都用，但不是 7 项中的某一项。

## 四、两个支持方向（迭代飞轮）

> **新场景怎么落地、老的能力怎么沉淀，两条路都走得通。**

| 方向 | 什么时候走 | 怎么走 | 工作量 |
|---|---|---|---|
| **A · 消耗引擎** | 来了一个新场景需求 | 挑 L3 已有引擎 + L4 模板 + 本域模型 | L1 配权限 + L3 配参数 + L4 配字段；**引擎和视图不用重写** |
| **B · 分层沉淀** | 定期复盘各场景的共用部分 | 按**复用范围**分流，各归其位 | 见下表 |

### B 的分流标准：按复用范围，不按"是否可复用"

**不是所有业务都该变成引擎。** 判断依据是这段逻辑的复用范围有多宽：

| 复用范围 | 落点 | 收益 | 例子 |
|---|---|---|---|
| **跨业务域复用** | L3 业务引擎层 | 所有场景现成用 | 流程编排、动态表单、消息中心 |
| **域内复用**（本域多个场景共用） | **L5 · 域级模型与规则** | 本域场景现成用 | 隐患分级与闭环、维保周期算法、合同履约模型 |
| **只用一次** | **L5 · 场景专属** | 做完就不必管 | 某个监管报告的取数口径 |

> **域级模型按域各有不同**：② 风险防控是隐患分级标准 ＋ 闭环状态机；④ 运营服务是合同履约模型 ＋ 派工规则 ＋ 值守班次。

> 三个概念（业务域 / 场景 / 域级模型）的定义与判据 → [业务域与场景层介绍.md §三](应用场景层介绍.md)

**落错层的代价**
- 塞进 L3 → 引擎池膨胀，配置界面出现一堆只有一个选项的下拉，用户没法用
- 全留在场景层 → 同域多个场景各写一遍，改一次要改三处
- 该沉淀的没沉淀 → 飞轮转不起来，退化成"每次都重新开发"

**最危险的还是那条**：相似能力已经出现 3 次以上，却还是各写一份——这是真实的"该抽没抽"。

## 四之二、关于"零行代码"的准确说法

**骨架零代码 ≠ 零行代码。**

| | 是不是 0 行代码 | 说明 |
|---|:--:|---|
| 场景骨架（对象 / 字段 / 流程 / 规则 / 消息） | ✅ 是 | 七项全部配置得出来 |
| 本域的模型与规则 | ❌ 不是 | 隐患分级、维保周期…… 随域演进要写 |
| 场景专属逻辑 | ❌ 不是 | 取数口径、清单格式…… 用例级要写 |

**准确的说法**：平台省掉的是**重复造轮子**——引擎、视图、通用流程不用为新场景重写；不是省掉全部工作量。

而且"零行代码"在 L4 维度还更远一层：列表页与详情页目前**每域各写一份**（`HazardList.vue` `DeviceList.vue` …），只有表单 / 大屏 / 工作台是通用的。要让场景真正做到只配不写，得先补通用列表页 + 通用详情页，**估计 2-4 周**。

## 五、L4 现状（如实标注）

L4 在图上标了**"建设中"**，因为：

| 通用化组件 | 现状 | 说明 |
|---|:--:|---|
| 表单（DynamicForm + FormDesigner） | ✅ 已通用 | 每个域都跑同一套 |
| 工作台 widget（widget-registry） | ✅ 已通用 | 18 个组件，排列组合即可 |
| 大屏（bigscreen-templates） | ✅ 已通用 | 7 类模板，主题/数据按场景配 |
| **列表页** | ❌ 待通用化 | 当前每域各写一份（`HazardList.vue` `DeviceList.vue` …） |
| **详情页** | ❌ 待通用化 | 同上 |
| **看板** | ◐ 部分 | 复用 widget-registry，但拖拽/配置流程未建 |

> **不夸大承诺**。图上 L4 不写"80% 复用"——写"建设中"和"6 种形状"。**"零行代码"在表单/大屏/工作台场景成立，在列表/详情场景还不成立**。
> 要让所有场景都"零行代码"，需要立项做"通用列表页"+"通用详情页"—— 估计 2-4 周。

## 六、读图顺序（给新人）

```
① 地基（L1）→ ② 数据（L2）→ ③ 核心（L3）→ ④ 页面（L4）→ ⑤ 场景（L5）
```

- **③ 最重要，必读**。L3 是支点，其他层都从这出发。
- ①/②/④/⑤ 跑通流程后再补读——先有手感，再读理论。
