## 一、参考法规/标准 总览

### 1.1 法规强制力等级体系(本表的核心维度)

法规按**法律效力**从高到低分 4 级,**强制力等级越高,产品越必须遵守**:

| 等级 | 含义 | 法律效力 | 必须满足? | 本产品动作 |
|---|---|---|---|---|
| **★★★ L1** | 国家法律 / 行政法规 | 全国强制 | 是 | **必须实现,任何租户、任何地区、任何行业都生效,不可关闭** |
| **★★  L2** | 部门规章、强制性国家标准(GB) | 全国强制 | 是 | **必须实现,所有租户都生效** |
| **★   L3** | 推荐性国家标准(GB/T)、地方性法规/地方政府规章、地方标准(DB) | 区域内/行业内强制 | 是(在适用区域内) | **必须实现,按租户所在地区/行业加载;若租户跨地区,全部加载,取较严项** |
| **☆   L4** | 行业标准、团体标准(T/)、企业标准 | 自愿采用 | 否(参考) | **可参考,按租户行业类型开关启用,默认关闭** |

### 1.2 跨地区/跨行业处理原则

当租户**跨地区**或**跨行业**经营时,法规加载规则:

| 情况 | 处理方式 | 示例 |
|---|---|---|
| 同地区多店 | 加载该地区全部 L1+L2+L3 法规 | 北京某连锁物业 = R-01+R-02+R-03+R-04 |
| 跨地区经营 | **全部加载 + 取较严项**(方案 A) | 北京+河南租户 = 同时启用 R-04 和 R-05,字段取两者并集 |
| 多行业经营 | 按行业开关叠加 L4 行业标准 | 商业街 + 化工小作坊 = 通用法规 + 化工行业插件 |
| 不确定行业 | 仅启用 L1+L2 通用部分 | 默认安全配置 |

## 二、适用范围判定说明

### 2.1 通用适用法规(L1 + L2,任何租户必须遵守)

- **R-01 安全生产法** ★★★ — 主体责任、双报告、信息系统强制使用
- **R-02 消防法** ★★★ — 火灾隐患监督检查、临时查封
- **R-03 暂行规定** ★★ — 隐患定义、分级、督办、台账
- **R-07 消防安全责任制实施办法** ★★ — 四方责任
- **R-09 安全生产法司法解释** ★★ — 刑事追责
- **R-10 公安部 61 号令** ★★ — 单位消防安全管理、巡查频次

> 上述法规对本域「隐患排查 + 隐患整改」具有**全国统一约束力**。任何租户任何场景都必须实现对应功能,不可关闭。

### 2.2 推荐性国家标准(L3,全国适用但非强制)

- **R-08 GB/T 33000-2025** ★ — PDCA、标准化、内部报告奖励机制
- 推荐性国家标准本身不强制,但**被 L1/L2 法规引用时即获强制力**(如安全生产法 §41 引用的标准化建设要求 → GB/T 33000 实质成为强制参考)
- 本产品**默认全部租户启用**

### 2.3 地方性法规(L3,按地区加载)

- **R-04 北京办法**(北京)、**R-05 河南办法**(河南)、**R-06 福建条例**(福建)等
- 按租户主体注册地加载,**跨地区租户全部加载,取较严项**(方案 A)
- 字段差异:台账保存年限(河南 2 年)、信息系统强制使用(北京)等取并集

### 2.4 行业专属规定(L2/L3,按行业开关加载)

| 法规 | 适用行业 | 行业插件启用条件 |
|---|---|---|
| R-11 高校消防安全管理规定 | 教育行业 | 租户类型=学校/培训机构 |
| R-12/R-13 危化品重大危险源 | 危化品行业 | 租户涉及危化品存储/使用 |
| R-14 电力重大隐患判定标准 | 电力行业 | 租户类型=电力企业 |

> 行业插件是**通用隐患台账的字段增强**,不是另起一套系统。详见 [法规-功能映射.md](./法规-功能映射.md) §15「行业插件扩展指引」。

## 三、版本维护规则

1. 法规版本以**现行有效**为准。每季度由隐患管理域负责人复核一次。
2. 任何 R-01 ~ R-14 中的法规条款**被废止/修订/新增地方性法规**时,需:
   - 更新本文件
   - 同步更新 [法规-功能映射.md](./法规-功能映射.md) 中受影响的功能映射项
   - 在 [biz-design.md](./biz-design.md) 文档头部的「版本历史」中记录
3. 任何**业务设计 / 功能设计 / 流程模板**变更,需在本文件中标注所引用的法规编号(如「依据 R-03 §3、§8」)。

## 四、引用格式约定

在业务设计文档中引用法规时,使用以下统一格式:

```markdown
**法规依据**:R-03 §3 ★★(事故隐患定义)、R-08 §8.3 ★(重大隐患管理)
```

> 法规编号后**标注强制力等级**(★★★/★★/★),便于阅读者一眼判断约束强度。

便于跨文档追溯与合规审计。

## 六、岗位术语口径备忘(评审时一并确认)

> **结论日期**:2026-10-08 | **来源**:法规口径核对

| 业务口语 | 法规原文(本域) | 是否新增独立岗位 |
|---|---|---|
| "企业安全员" | R-10 §32 写作"**消防工作归口管理职能部门或者专兼职消防管理人员**",法规中无"企业安全员"称谓 | ❌ **不新增**——和现有"消防安全管理人 + 消控值班员 + 巡查员"职责边界重叠,强加会让责任链混乱 |
| "安全员" | R-01/R-08 体系称"**安全生产管理人员 / 班组安全员**",属综合安全线 | ⚠️ **仅当租户是生产经营单位时**(如带仓储的商场),需双线责任(消防 + 综合安全),届时按租户行业插件加载,不进核心用户表 |
| "消控室值班员" | R-10 §38 明确列项 + 持证上岗 + §31 第 6 项追责(脱岗) | ✅ **必须保留**,本就是 §2.1 五种角色之一,不能去掉 |
| "消防安全管理人" | R-10 §7 | ✅ 同上 |

> **给后续评审的话**:"企业安全员"如再次被提,先用本表核对法规口径,不要凭直觉新增。

> **评审动作**:请评审人确认 R-01 ~ R-14 是否覆盖了你所在场景的全部硬约束,并指出是否需要补充地方性/行业专属法规。
