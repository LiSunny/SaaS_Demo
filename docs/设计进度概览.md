# 维保平台 — 设计进度概览

> 最后更新：2026-06-02

---

## 一、业务设计 ✅

**产品定位**：消防维保双边协作平台，连接维保公司（服务商）与业主单位。底层由**流程编排引擎（M0）**驱动，支撑工单、督办、审批等流程场景。

| | 服务商端（执行方） | 业主端（监督方） |
|---|---|---|
| **角色** | 服务提供方 | 服务接收方 |
| **核心职责** | 执行消防维保、巡查、检测、维修 | 监督服务质量、管理内部消防事务 |
| **操作模式** | 以读写为主（创建/编辑/提交） | 以读为主（查看/确认/督促） |
| **数据范围** | 管理多家业主单位的维保数据 | 仅管理本单位数据 |
| **使用者** | 维保公司管理员、业务负责人、维保人员 | 业主单位管理员、安全负责人 |

**12 条核心业务规则已定义**：维保三层架构、计划启用即生成任务、故障双向流转、数据权限隔离、台账双轨制、合同"待确认"可编辑、签到配置跟随计划、台账设备级管理、双端角色体系、默认正常+只标记异常、合同履约按计划执行计算、故障闭环确认。
