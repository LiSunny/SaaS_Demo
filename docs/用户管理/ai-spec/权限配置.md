# 权限配置 — 设计文档

---

## 一、页面元信息

| 项目 | 内容 |
|------|------|
| 页面名称 | `权限配置` |
| 所属模块 | `用户管理` |
| 页面类型 | `表单提交` |
| 路由路径 | — （抽屉模式，依附于 `/admin/positions` 列表页） |

### 功能描述

平台管理员为内置岗位配置权限的抽屉页面。左侧为岗位信息摘要，右侧为三类权限的配置区：模块访问权限（控制能否进入各业务模块）、数据操作权限（控制进入模块后的增删改查导出）、管理操作权限（控制系统管理功能）。三类权限按模块分组展示，支持全选/取消全选。保存后即时生效。

## 二、页面结构

### 表单提交页布局（抽屉模式）

| # | 区域名称 | 位置 | 注册表组件 | 包含元素 |
|---|---------|------|-----------|---------|
| 1 | 抽屉标题 | 顶部 | `el-drawer` header | "权限配置 — {岗位名称}"，下方副标题显示岗位说明和数据范围 |
| 2 | 模块访问权限区 | 内容区 | `el-form` §1 | 分区标题"模块访问权限" + 说明文字"勾选后，该岗位用户可进入对应业务模块"。下方为模块网格（2列），每项为 `<el-checkbox>`：模块中文名 |
| 3 | 数据操作权限区 | 内容区 | `el-form` §2 | 分区标题"数据操作权限" + 说明文字"勾选后，该岗位用户可在对应模块中执行该操作"。表格形式：行=模块（仅展示已开启模块访问的模块），列=查看列表/查看详情/新增/编辑/删除/导出。每单元格为 `<el-checkbox>` |
| 4 | 管理操作权限区 | 内容区 | `el-form` §3 | 分区标题"管理操作权限" + 说明文字"勾选后，该岗位用户可执行对应系统管理功能"。下方为管理操作列表，每项为 `<el-checkbox>`：管理功能中文名 + 说明 |
| 5 | 提交按钮栏 | 底部(fixed) | `el-button` group | 保存(primary, loading) + 取消。底部固定，不随内容滚动 |

## 三、数据模型

### 3.1 岗位详情（PositionDetail）

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | `number` | 岗位 ID |
| `name` | `string` | 岗位名称 |
| `key` | `string` | 岗位唯一标识 |
| `description` | `string` | 岗位说明 |
| `dataScope` | `string` | 数据范围类型 |
| `dataScopeLabel` | `string` | 数据范围中文标签 |
| `permissions` | `PermissionConfig` | 权限配置，见 §3.2 |
| `userCount` | `number` | 使用该岗位的用户数 |

### 3.2 权限配置（PermissionConfig）

| 字段 | 类型 | 说明 |
|------|------|------|
| `moduleAccess` | `string[]` | 可访问的模块 Key 列表，如 `["order-mgmt", "device", "patrol-inspect"]` |
| `dataOperations` | `Record<string, string[]>` | 每个模块的数据操作权限。Key=模块Key，Value=操作Key列表，如 `{"order-mgmt": ["list","detail","create","edit"]}` |
| `managementOperations` | `string[]` | 管理操作 Key 列表，如 `["user-mgmt", "enterprise-config"]` |

## 五、接口定义

| 操作 | 方法 | 路径 | 请求类型 | 响应类型 |
|------|------|------|---------|---------|
| 获取岗位详情（含权限） | `GET` | `/api/admin/positions/:id` | — | `PositionDetail` |
| 保存权限配置 | `PUT` | `/api/admin/positions/:id/permissions` | `PermissionConfig` | `PositionDetail` |

## 六、业务逻辑

### 6.1 交互行为

| 操作 | 触发条件 | 行为描述 |
|------|---------|---------|
| 打开抽屉 | 点击列表页 [配置权限] | 调用 GET 获取岗位详情（含当前权限配置）→ 打开右侧抽屉 → 回填所有权限勾选状态 |
| 勾选/取消模块访问 | 点击模块 checkbox | 勾选：该模块出现在 §3 数据操作区。取消勾选：该模块从 §3 数据操作区移除，同时清空该模块下所有数据操作勾选 |
| 勾选/取消数据操作 | 点击操作 checkbox | 独立勾选/取消。勾选"查看详情"自动勾选"查看列表"（查看详情依赖查看列表） |
| 勾选/取消管理操作 | 点击管理操作 checkbox | 独立勾选/取消 |
| 全选模块访问 | 点击"全选"链接 | 勾选所有模块。如果已全选，变为"取消全选" |
| 模块级"全选操作" | 点击模块行"全选" | 勾选该模块下所有 6 个数据操作 |
| 保存 | 点击底部 [保存] | 收集三个区域勾选状态 → 组装 PermissionConfig → 调用 PUT → 成功后 ElMessage 提示"权限配置已保存" → 关闭抽屉 |
| 取消 | 点击 [取消] / 抽屉外区域 / Esc | 关闭抽屉，不保存。如有未保存修改，弹出 ElMessageBox.confirm("权限配置尚未保存，确定关闭吗？") |

### 6.2 特殊规则

- **模块访问是前置条件**：只有开启了模块访问的模块，数据操作权限才有意义。数据操作区仅展示已开启模块访问的模块
- **查看详情依赖查看列表**：勾选"查看详情"时自动勾选"查看列表"；取消"查看列表"时自动取消"查看详情""新增""编辑""删除""导出"
- **权限保存即时生效**：保存后，该岗位下所有用户的权限立即更新（下次请求时生效，不影响已登录 session 的当前页面）
- **新岗位默认无权限**：新增岗位后，所有模块访问/数据操作/管理操作默认关闭，需管理员手动配置
- **权限配置不跨岗位影响**：修改某岗位的权限配置不影响其他岗位

## 七、UI 组件分配

| 页面区域 | 注册表组件 | 关键 Props / 自定义说明 |
|---------|-----------|----------------------|
| 抽屉容器 | `FormDrawer` | title="权限配置 — {岗位名称}"，size=640px，destroy-on-close，:close-on-click-modal="false" |
| 岗位摘要 | 自定义 | 抽屉顶部展示岗位名称（h3）、数据范围（StatusTag）、岗位说明（text-secondary） |
| 模块访问区 | `el-checkbox-group` | 2 列网格布局。每个 `<el-checkbox>` 的 label 为模块中文名。顶部有"全选/取消全选"链接按钮。分区标题加左侧色条 |
| 数据操作区 | `el-checkbox` 矩阵 | 表格布局。仅展示已开启模块访问的模块行。每行：模块名 + 6 个 `<el-checkbox>`（列表/详情/新增/编辑/删除/导出）。列头可点击全选该列 |
| 管理操作区 | `el-checkbox-group` | 列表布局。每个 `<el-checkbox>` 含中文名 + 灰色说明小字。分区标题加左侧色条 |
| 底部按钮栏 | `el-button` group | 固定在抽屉底部。保存(primary, loading) + 取消。背景白色，上方有分割线 |
| 未保存确认 | `ElMessageBox` | before-close 钩子中检查 dirty 状态 |
