# 新增用户 — 设计文档

---

## 一、页面元信息

| 项目 | 内容 |
|------|------|
| 页面名称 | `新增用户` |
| 所属模块 | `用户管理` |
| 页面类型 | `表单提交` |
| 路由路径 | — （弹窗模式，依附于 `/admin/users` 列表页） |

### 功能描述

平台管理员新增用户账号的表单提交弹窗，填写手机号（即账号）、真实姓名和初始密码后创建平台级用户。用户创建后不自动关联任何企业，需由企业管理员在 M1 中将其加入企业。

---

## 二、页面结构

### 表单提交页布局（弹窗模式）

| # | 区域名称 | 位置 | 注册表组件 | 包含元素 |
|---|---------|------|-----------|---------|
| 1 | 弹窗标题 | 顶部 | `el-dialog` header | "新增用户" |
| 2 | 表单区 | 全宽 | `el-form` | 3 个字段：手机号(input) + 真实姓名(input) + 初始密码(input type=password, show-password) |
| 3 | 提交按钮栏 | 底部 | `el-button` group | 保存(primary) + 取消 |

---

## 三、数据模型

### 3.1 表单字段（CreateUserForm）

| 字段名 | 中文名 | 类型 | 必填 | 控件类型 | 校验规则 | 说明 |
|--------|--------|------|------|---------|---------|------|
| `phone` | 手机号 | `string` | 是 | `input` | `required`, `pattern: /^1[3-9]\d{9}$/` | 即登录账号，全局唯一，后端校验重复 |
| `realName` | 真实姓名 | `string` | 是 | `input` | `required`, `max: 20` | 列表展示用 |
| `password` | 初始密码 | `string` | 是 | `input` (type=password, show-password) | `required`, `min: 6`, `max: 20` | 首次登录强制修改 |

## 六、业务逻辑

### 6.1 交互行为

| 操作 | 触发条件 | 行为描述 |
|------|---------|---------|
| 打开弹窗 | 点击列表页 [新增用户] 按钮 | 弹窗打开，表单清空，手机号输入框自动聚焦 |
| 提交 | 点击 [保存] | 前端校验表单 → 调用 POST → 成功后 ElMessage 提示"创建成功" → 关闭弹窗 → 刷新列表 |
| 手机号重复 | 后端返回 409 | ElMessage.error("该手机号已被注册")，不关闭弹窗 |
| 取消 | 点击 [取消] / 弹窗外区域 / Esc | 关闭弹窗，不保存 |

### 6.2 特殊规则

- 手机号全局唯一，前端防抖 500ms 后可不做预检，由后端唯一约束兜底
- 创建成功后用户状态默认为"启用"
- 新用户不关联任何企业，`enterpriseCount` 为 0
