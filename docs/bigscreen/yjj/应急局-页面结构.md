## AutoLayout 布局模式

- **194 个** Frame 启用了 AutoLayout
- 方向: 主要使用 `VERTICAL`（卡片纵向堆叠）和 `HORIZONTAL`（表格行、标签横向排列）
- 间距范围: `3px ~ 49px`，常用值: `8px, 10px, 12px, 16px`
- 内边距: `8px ~ 16px`
- 整体为 **左侧-HORIZONTAL三列布局**

## 响应式布局方案

> **核心目标**: 页面始终填充满浏览器窗口（`100vw × 100vh`），零滚动条，所有模块按比例自适应。

### 整体策略

| 层级 | 方案 | 关键约束 |
|------|------|----------|
| 根容器 | `width: 100vw; height: 100vh; overflow: hidden` | 禁止滚动条 |
| 主布局 | CSS Grid — `grid-template-rows: auto 1fr` | 导航栏 + 内容区 |
| 内容区 | CSS Grid — 三列 `448fr 960fr 448fr` + `column-gap: 16px` + `padding: 0 16px` | 保持 7:15:7 原始比例 |
| 列内部 | Flex 纵向排列，`gap: 16px` | 卡片间间距固定 |
| 卡片内容 | `flex: 1` + 内部 `overflow-y: auto` | 内容溢出时卡片内部滚动 |

### 卡片内部自适应规则

```
┌──────────────────────────────┐
│  小标题栏 (固定 46px)          │  ← flex-shrink: 0
├──────────────────────────────┤
│                              │
│  内容区                       │  ← flex: 1; overflow-y: auto
│  - 图表/环形图: SVG viewBox   │
│  - 表格: 内部滚动             │
│  - 数据指标: flex wrap       │
│                              │
└──────────────────────────────┘
```

| 卡片区域 | 自适应策略 |
|----------|-----------|
| **标题栏** | 固定高度 `46px`，`flex-shrink: 0`，背景渐变 + 底部分割线 |
| **环形图 / 统计图** | 使用 SVG `viewBox` 保持比例，`max-width: 100%; max-height: 100%` |
| **数据表格** | `overflow-y: auto`，表头 `position: sticky; top: 0`，行高等比缩放 |
| **六边形图标** | `aspect-ratio: 1` + `width: %` 或 `clamp()` 控制尺寸范围 |
| **Segment 标签页** | `flex-shrink: 0`，固定高度，不参与内容区滚动 |
| **四象限指标** | CSS Grid `2×2`，每格 `1fr`，内部数据居中对齐 |

### 字体与间距缩放

以设计稿 1920×1080 为基准，使用 `clamp()` 实现平滑缩放：

```css
/* 基准换算: 1px = 100vw / 1920 = 0.052083vw */

/* 标题字体: 设计稿 18px → 最小 14px, 基准 18px, 最大 22px */
--text-title: clamp(14px, 0.9375vw, 22px);

/* 数据大数字: 设计稿 40px → 最小 28px, 基准 40px, 最大 56px */
--text-number-xl: clamp(28px, 2.083vw, 56px);

/* 正文: 设计稿 14px → 最小 12px, 基准 14px, 最大 16px */
--text-body: clamp(12px, 0.729vw, 16px);

/* 间距: 设计稿 16px → 最小 8px, 基准 0.833vw, 最大 20px */
--space-md: clamp(8px, 0.833vw, 20px);
```

| 设计稿 Token | 设计稿值 | 响应式 CSS | 说明 |
|-------------|---------|------------|------|
| `--text-h1` | 18px | `clamp(14px, 0.9375vw, 22px)` | 卡片标题 |
| `--text-number-xl` | 40px | `clamp(28px, 2.083vw, 56px)` | 大数字（999） |
| `--text-number-lg` | 24px | `clamp(18px, 1.25vw, 32px)` | 中数字（18家） |
| `--text-body-md` | 14px | `clamp(12px, 0.729vw, 16px)` | 表格正文 |
| `--text-caption` | 12px | `clamp(10px, 0.625vw, 14px)` | 辅助文字 |
| `--space-md` | 8px | `clamp(4px, 0.417vw, 12px)` | 小间距 |
| `--space-lg` | 16px | `clamp(8px, 0.833vw, 20px)` | 卡片间距 |
| `--space-xl` | 24px | `clamp(12px, 1.25vw, 32px)` | 大间距 |
| `--card-title-height` | 46px | `clamp(36px, 2.396vw, 52px)` | 标题栏高度 |

### 断点与降级策略

| 分辨率区间 | 策略 | 说明 |
|-----------|------|------|
| **≥ 1920×1080** | 标准大屏模式 | 按 `fr` 比例等比放大，字体/间距触及 `clamp()` 上限 |
| **1600×900 ~ 1920×1080** | 等比缩放 | `fr` 自适应，字体/间距在 `clamp()` 范围内平滑缩小 |
| **1366×768 ~ 1600×900** | 紧凑模式 | 字体/间距触及 `clamp()` 下限，卡片内部 `overflow-y: auto` 启用滚动 |
| **< 1366×768** | 降级模式 | 左右侧列折叠为 overlay 抽屉（点击展开/收起），中间列独占全部宽度 |

#### 降级模式详细行为

```
┌─────────────────────────────────────────┐
│  导航栏 (100vw)                          │
├─────────────────────────────────────────┤
│  ☰ 左侧  │         中间列 (1fr)          │  右侧 ☰ │
│  (浮层)  │                               │  (浮层) │
│          │  ┌─────────────────────────┐  │         │
│          │  │ 地图区 (flex: 1)         │  │         │
│          │  ├─────────────────────────┤  │         │
│          │  │ 卡片6    │  卡片7       │  │         │
│          │  └─────────────────────────┘  │         │
└─────────────────────────────────────────┘
```

- 左侧/右侧列各由一个 toggle 按钮触发，以 `position: fixed` 浮层形式覆盖在中间列上方
- 浮层宽度 `min(448px, 85vw)`，高度 `100%`，内部保持原始卡片排列
- 点击浮层外部区域或关闭按钮收起
- 中间列 `grid-column: 1 / -1` 占据全部宽度

### 关键技术点总结

| 关注点 | 方案 |
|--------|------|
| **填满窗口** | `100vw × 100vh` + `overflow: hidden` |
| **三列比例** | CSS Grid `448fr 960fr 448fr` + 固定 `gap` |
| **卡片等高** | 各列内 Flex 纵向 + `fr` 高度分配 |
| **内容溢出** | 卡片内容区 `overflow-y: auto`，标题栏 sticky |
| **字体缩放** | `clamp()` 平滑缩放，1920px 基准 |
| **小屏降级** | 侧栏折叠为浮层，中间列全宽 |
| **图片/图表** | SVG `viewBox` + `max-width: 100%` |
