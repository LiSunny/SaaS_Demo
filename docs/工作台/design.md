# 工作台 — 设计文档

> 状态：🟢 full | 最后更新：2026-07-08

## 1. 业务定位

工作台是平台的**总入口页面**（用户登录后的默认落地页），跨业务域聚合关键信息与快捷操作。

**核心目标**：
- **聚合**：在一个页面呈现跨模块（工单、维保、隐患、设备…）的关键指标
- **角色化**：物业管理员/安全监管员/消防服务工程师看到不同的内容
- **提效**：物业管理员从登录到发起工单 ≤ 2 次点击，监管员发现超时工单 ≤ 5 秒

**工作台不是**：各模块的替代品（不替代深度操作页）、监管大屏（不做实时动画）、数据仓库（只读摘要，不存储数据）。

## 2. 核心场景

- 作为**物业管理员**，我希望登录后第一时间看到本企业的工单状态和维保进度，以便快速了解"我的企业发生了什么"。
- 作为**物业管理员**，我希望在工作台上直接发起工单（选模板→填表单→提交），不需要进入工单监控页。
- 作为**安全监管员**，我希望登录后看到 SLA 概况（超时/预警/正常统计），以便快速定位需要督办的超时工单。
- 作为**消防服务工程师**，我希望在工作台看到待接单和处置中的工单数量。
- 作为**所有用户**，我希望根据自己的工作习惯调整工作台布局（增删组件、拖拽排序），下次登录保持。

## 3. 页面清单

| 页面 | 类型 | 路由 | 核心功能 | 深度 |
|------|------|------|---------|------|
| 工作台主页 | 统计看板 | `/workbench` | 可编辑 Widget 网格，角色预设布局，异步加载各业务 Widget | 🟢 full |

> 工作台只有一个页面，内容全部通过 Widget 组件呈现。底层依赖仪表盘框架（DashboardShell + WidgetGrid + WidgetCard + WidgetRenderer）。

## 4. 数据模型

工作台**无独立数据模型**。所有数据来自各业务模块的已有 API（工单管理、维保管理、隐患管理等）。

### 4.1 仪表盘配置（前端概念，非持久化实体）

| 字段 | 类型 | 说明 |
|------|------|------|
| WidgetSlot.id | string | Widget 实例 ID |
| WidgetSlot.type | string | 注册表中的 Widget 类型 key |
| WidgetSlot.size | number | 列跨度（1/2/3） |
| WidgetSlot.order | number | 排序序号 |
| WidgetSlot.config | object | Widget 专属配置（如 actions、moduleName） |

### 4.2 Widget 注册表（前端代码定义）

| Widget Key | 类型 | 面向角色 | 说明 |
|-----------|------|---------|------|
| app-shortcuts | 导航 | 所有角色 | 各业务模块快捷入口（3×2 网格） |
| quick-actions | 动作 | 所有角色 | 快捷操作按钮组（发起工单等） |
| my-tasks | 任务 | 所有角色 | 跨模块待办聚合 |
| notifications | 通知 | 所有角色 | 最近 5 条系统消息 |
| order-overview | 概览 | 所有角色 | 工单状态分布 + 最近列表 |
| sla-overview | 概览 | 监管员 | SLA 超时/预警/正常统计 |
| plan-status | 概览 | 物业/工程师 | 维保计划执行率（占位中） |
| hazard-overview | 概览 | 物业/监管员 | 隐患整改率（占位中） |

## 5. 业务规则

- **数据按角色隔离**：物业管理员只看本企业数据，监管员看全量，工程师只看分配给自己的
- **布局按角色预设**：每个角色有独立的默认布局，用户调整不跨角色共享
- **异常隔离**：一个 Widget 加载失败不影响其他 Widget，各自独立处理 error 状态
- **编辑模式不影响数据**：编辑布局时 Widget 不加载数据，退出编辑后统一刷新
- **单实例限制**：同一 Widget 在工作台中只可添加一次
- **模块未就绪时**：对应 Widget 显示占位卡片（模块名 + "即将上线"）或隐藏

## 6. 接口概要

工作台**无独立后端接口**。布局配置完全前端管理（localStorage）。各 Widget 复用已有模块 API：

| Widget | 依赖 API | 方法 |
|--------|---------|------|
| 工单概览 | `/api/work-order/list`, `/api/work-order/stats` | GET |
| SLA 概览 | `/api/work-order/list`（全量，按 slaStatus 分组） | GET |
| 我的待办 | `/api/work-order/list`（按 assigneeId/orgId 过滤） | GET |
| 消息通知 | 阶段 1 Mock，阶段 2 消息中心 API | — |
| 维保/隐患/设备概览 | 对应模块 API（待实现），当前为占位 | — |
