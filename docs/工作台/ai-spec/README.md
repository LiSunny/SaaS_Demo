## 页面结构概览

工作台主页为单页统计看板，包含 13 个区域：

```
┌─────────────────────────────────────────────────┐
│ 看板标题操作栏（查看: [编辑布局] / 编辑: [保存] [恢复]）│
├─────────────────────────────────────────────────┤
│ 各应用快捷入口  │ 快捷操作入口  │ 我的待办      │
│ (3×2 模块按钮) │ (发起工单…)   │ (待办/完成/剩余)│
│ ✅ 所有角色    │ ✅ 物业管理员  │ ✅ 所有角色    │
├─────────────────────────────────────────────────┤
│ 消息通知       │ 工单概览      │ SLA 概览      │
│ (最近5条Mock)  │ (4统计+5工单) │ (三色+超时列表) │
│ ✅ 物业+监管   │ ✅ 所有角色   │ ✅ 监管员      │
├─────────────────────────────────────────────────┤
│ 维保概览(占位) │ 隐患概览(占位)│ 设备概览(占位) │
│ ⏳ 阶段2       │ ⏳ 阶段2      │ ⏳ 阶段3       │
├─────────────────────────────────────────────────┤
│ 巡查概览(占位) │               │               │
│ ⏳ 阶段3       │               │               │
└─────────────────────────────────────────────────┘

浮层: 组件池选择面板(width=320) + 发起工单弹窗(width=560)
```

## Widget 分工

| 类别 | Widget | 职责 | 目标角色 |
|------|--------|------|---------|
| 导航 | app-shortcuts | 跳转到各业务模块 | 所有 |
| 动作 | quick-actions | 触发 Dialog/流程 | 物业管理员 |
| 任务 | my-tasks | 聚合待办事项 | 所有 |
| 通知 | notifications | 展示系统消息 | 物业+监管 |
| 概览 | order-overview | 工单统计+列表 | 所有 |
| 概览 | sla-overview | SLA 三色统计 | 监管员 |
| 占位 | plan-status | 维保(阶段2) | 物业+工程师 |
| 占位 | placeholder×3 | 隐患/设备/巡查(阶段2-3) | 物业+监管 |
