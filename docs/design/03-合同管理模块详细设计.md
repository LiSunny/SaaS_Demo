# 合同管理模块 — 详细设计
**版本：v2.5**（2026-05-20：履约计算方式从时间维度改为执行维度）

## 1. 概述

合同管理模块服务于维保服务协作平台中服务商与业主之间的合同全生命周期管理，覆盖合同创建、状态流转、数据联动、多端同步等核心业务场景。

**涉及角色：** 服务商端（操作方）、业主端（监督方）

---

## 2. 合同包含的信息

| 字段 | 说明 |
|---|---|
| 合同编号 | 系统按规则自动生成，无需手动录入 |
| 业主单位 | 从服务企业列表中已关联的企业中选择 |
| 项目类别 | 消防维保 / 消防检测 |
| 维保系统 | 多选，数据来源于维保标准库（M10）的系统类别列表，至少选择一个 |
| 合同开始日期 | 合同生效日期，创建时选择 |
| 服务期限 | 合同服务年限（年），手动输入或选择，系统自动计算结束日期 |
| 服务面积 | 服务覆盖面积（平方米），手动输入 |
| 负责人 | 从人员管理中选择，仅限"项目负责人"岗位人员（非该岗位灰显不可选） |
| 合同状态 | 见下方状态机定义 |
| 附件（可选） | PDF 等格式文件 |

## 3. 合同编号规则

**格式：** `HT-YYYYMMDD-NNNN`

| 段 | 含义 | 示例 |
|---|---|---|
| `HT` | 固定前缀 | HT |
| `YYYYMMDD` | 创建日期（年/月/日） | 20260518 |
| `NNNN` | 当日按创建顺序自增，从 0001 起 | 0001 |

**规则：**

- 取合同创建的当天日期作为编号的日期段
- 当天创建的第 1 份合同序号为 0001，后续每新增一份 +1
- 次日创建时日期段更新，序号从 0001 重新计数（跨天归零）

**示例：**

```
HT-20260518-0001  ← 5月18日第1份
HT-20260518-0002  ← 5月18日第2份
HT-20260519-0001  ← 次日第1份（归零）
```

## 4. 状态机

### 4.1 状态定义

| 状态 | 含义 | 是否终态 |
|---|---|---|
| 待确认 | 服务商已创建，等待业主确认 | 否 |
| 执行中 | 业主已确认签订，维保进行中 | 否 |
| 已结束 | 合同终止（到期/提前终止） | 是 |

### 4.2 状态流转图

```
待确认 → 执行中（业主确认）→ 已结束（到期/手动终止）
```

### 4.3 各状态下可执行的操作

| 当前状态 | 服务商可操作 | 业主可操作 | 说明 |
|---|---|---|---|
| 待确认 | 编辑合同 | 确认签订 | 服务商创建后等待业主回应；业主确认前可编辑合同内容 |
| 执行中 | 结束合同 | — | 维保进行中，业主确认后自动进入 |
| 已结束 | — | — | 终态，不可变更 |

### 4.4 状态转移规则

每次状态转移需满足以下条件：

1. **当前状态必须存在** — 必须是已定义的 3 种状态之一
2. **目标状态必须可达** — 只能沿流转图的方向前进（如"待确认"不能跳到"已结束"）
3. **操作角色必须有权限** — 见 4.3 表格，每种转移指定了由哪一方执行
4. **操作需二次确认** — 执行前弹出确认提示，防止误操作：

| 前往状态 | 确认提示 |
|---|---|
| 执行中 | "确认业主已同意合同条款？" |
| 已结束 | "确认结束此合同？此操作不可撤销" |

## 5. 页面说明

### 5.1 服务商端 — 合同列表

- 操作区：「+ 创建合同」按钮，点击弹出创建表单
- 列表以表格形式展示所有合同，每行包含：合同编号、业主单位、项目类别、覆盖系统、期限（含服务年限）、负责人、状态、操作
- 操作列内容根据合同当前状态动态变化（按 4.3 表格显示可用按钮）
- 点击「查看」进入合同详情页

### 5.2 服务商端 — 合同详情（二级页面）

四张卡片布局：

- **合同信息**：编号、业主单位、项目类别、维保系统（标签列表）、合同开始日期、服务期限（含起止日期和年限）、服务面积、负责人、状态
- **合同履约进度**：按计划实际执行次数计算履约率。合同覆盖系统 → 各系统按地标/国标要求有对应检查频次 → 合同期内应执行 X 次计划 → 实际已完成 Y 次 → 履约率 = Y/X。进度条显示"已完成 X 次 / 应执行 Y 次"，缺漏月份红色标记
- **关联任务记录**：通过合同编号 → 维保计划 → 维保任务的链路，展示该合同下所有任务，含任务名称、执行日期、状态、结果（合格/异常）、是否按时完成、关联故障及解决状态
- **关联企业信息**：企业名称、备注标签、项目负责人
- 提供「返回合同列表」导航

### 5.3 业主端 — 合同列表

- 只读视角，不可创建合同
- 展示内容与服务商端一致，操作列仅含「查看」和「下载」
- 当合同状态为"待确认"时，额外显示「确认签订」按钮
- 数据与服务商端实时同步

### 5.4 业主端 — 合同详情（二级页面）

- 展示合同信息、合同时效进度、关联任务记录（与服务商端一致，无关联企业信息卡片）
- 提供「返回合同列表」导航

## 6. 创建合同业务流程

### 6.1 表单内容

| 字段 | 填入方式 | 默认值 |
|---|---|---|
| 合同编号 | 系统自动生成 | 按规则自动填充 |
| 业主单位 | 从下拉列表选择（数据来源：已关联的企业列表） | 列表中第一个企业 |
| 项目类别 | 从下拉列表选择 | 消防维保 |
| 维保系统 | 多选框组（数据来源：维保标准库 M10 的系统类别） | 全部勾选 |
| 负责人 | 从下拉列表选择（数据来源：人员名单，仅项目负责人岗位可选，非该岗位灰显） | 第一个项目负责人 |
| 合同开始日期 | 日期选择 | 当天 |
| 服务期限 | 数字输入（年），手动输入或选择，范围 1~20 | 1 年 |
| 服务面积 | 数字输入（平方米），支持小数 | 无（手动输入） |
| 合同附件 | 上传文件 | 无 |

### 6.2 校验规则

- 业主单位必选，无已关联企业时无法创建合同
- 维保系统必选至少一项
- 合同开始日期必填
- 服务期限必填，范围 1~20 年
- 服务面积可选，输入时自动保留两位小数
- 负责人仅限"项目负责人"岗位，下拉列表中非该岗位人员灰显不可选
- 合同编号由系统生成，禁止手动修改

### 6.3 创建完成后的效果

- 新合同以"待确认"状态保存，出现在服务商端和业主端的合同列表中
- 业主端可见该合同并操作「确认签订」

## 7. 数据联动关系

### 7.1 与其它模块的联动

```
服务企业列表 ──关联新企业────→ 合同创建时可选的业主单位同步增加
              解除关联企业──→ 合同创建时可选的业主单位同步减少
              编辑备注标签──→ 合同详情页中关联企业信息同步更新

人员管理列表 ──增删人员──────→ 合同负责人下拉选项同步变化

维保标准库   ──系统类别变更──→ 合同创建时维保系统可选项同步变化
(M10)        系统停用/启用──→ 仅启用的系统类别可被勾选
```

### 7.2 服务商端与业主端数据同步

合同数据在两端共用同一数据源：
- 服务商端创建合同 → 业主端列表即时展示
- 业主端确认签订 → 服务商端状态即时更新
- 服务商端执行/完成任务 → 业主端看到状态变化

## 8. 业务边界场景

| 场景 | 处理方式 |
|---|---|
| 无已关联企业时创建合同 | 业主单位下拉为空，提示"请先关联业主单位" |
| 跨天创建合同 | 合同编号日期段随系统日期更新，序号从 0001 重新开始 |
| 对已结束的合同误操作 | 终态下所有操作按钮不可见，无法进行任何状态转移 |
| 业主端尝试创建合同 | 业主端无创建入口，仅可查看和确认签订 |
| 合同列表为空 | 表格显示无数据，引导用户创建第一份合同 |
| 页面刷新 | 所有合同数据保留，列表自动重建 |
