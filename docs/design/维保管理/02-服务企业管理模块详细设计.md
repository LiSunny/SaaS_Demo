# 服务企业管理模块 — 详细设计

## 1. 概述

服务企业管理模块是维保服务协作平台的**基础前置模块**，管理服务商与业主单位之间的"关联关系"。该模块确立了两端的合作关系——只有完成企业关联后，合同签订、维保台账、维保计划等后续业务才能推进。

**涉及角色：** 服务商端（发起关联方）、业主端（被关联方）

**模块定位：**

```
┌──────────────────────────────────────────────────────────────┐
│  服务企业管理 — 上下游依赖关系                                   │
│                                                              │
│  前提条件                         依赖于本模块                    │
│  ┌──────────────┐               ┌──────────────────────┐     │
│  │ 企业信息已录入 │               │ 合同管理              │     │
│  │ (系统初始化)   │───→  服务    │ 维保台账              │     │
│  └──────────────┘    企业关联    │ 维保计划              │     │
│                                  │ 故障指派              │     │
│                                  │ 报告归档              │     │
│                                  └──────────────────────┘     │
│                                                              │
│  没有企业关联，后续所有模块均无法选择"业主单位"                      │
└──────────────────────────────────────────────────────────────┘
```

---

## 2. 核心概念

### 2.1 什么是"服务企业"

- **服务商端视角**：指与该服务商建立了合作关系的**业主单位**。服务商为这些业主提供消防维保、检测等服务。
- **业主端视角**：指为该业主提供消防服务的**维保公司**。业主通过"相关方企业"列表查看已关联的服务商。

### 2.2 关联关系规则

```
┌────────────┐         关联关系          ┌────────────┐
│  服务商     │ ──────────────────────→  │  业主单位   │
│  (维保公司) │   谁为谁提供服务          │  (被服务方)  │
│            │                          │            │
│  主动发起    │                          │  被动确认   │
│  关联 + 解除 │                          │  可查看/监督 │
└────────────┘                          └────────────┘
```

**关系规则：**
- 一个服务商可关联**多家**业主单位
- 一个业主单位可被**多家**服务商关联
- 同一服务商不能重复关联同一业主单位
- 关联关系解除后，历史合同和维保记录保留只读，不影响已归档数据

### 2.3 两端视图对比

| 维度 | 服务商端 | 业主端 |
|------|---------|--------|
| 菜单名称 | 服务企业 | 相关方企业 |
| 数据内容 | 本服务商关联的所有业主单位 | 关联到本企业的所有服务商 |
| 操作权限 | 关联、解除关联、内联编辑备注/负责人、查看详情 | 查看详情 |
| 新建入口 | 「+ 关联业主单位」按钮 | 无（被动关联） |

## 3. 关联业务规则

### 3.1 关联业主单位流程（服务商端发起）

```
┌────────────┐    ┌──────────────────┐    ┌──────────────┐    ┌──────────────┐
│  点击       │    │  搜索业主单位      │    │  补充信息     │    │  关联完成     │
│  「关联     │──→│  ┌─── 有结果 → 选中 │──→│  备注标签     │──→│  企业出现在   │
│  业主单位」 │    │  └─── 无结果 → 新建 │   │  项目负责人   │    │  服务企业列表  │
└────────────┘    └──────────────────┘    └──────────────┘    └──────────────┘
```

**步骤 1 — 打开关联弹窗**

点击「+ 关联业主单位」按钮，弹出关联表单。

**步骤 2 — 搜索并选择业主单位**

在搜索框中输入企业名称关键词，系统从已存在的业主单位中匹配：

| 搜索结果 | 操作 |
|---------|------|
| **有匹配结果** | 展示可关联的企业列表 → 点击选中一条 → 底部展开该企业的详情摘要（名称、信用代码、地址、联系人） |
| **无匹配结果** | 自动展开新建表单，提示"未找到匹配的业主单位，请填写以下信息新建" |
| **已关联的企业** | 在结果中以灰色展示，标记"已关联"，不可选中 |

**新建表单字段：**

| 字段 | 必填 | 说明 |
|------|------|------|
| 企业名称 | 是 | 业主单位全称 |
| 统一社会信用代码 | 否 | — |
| 联系人 | 否 | 消防安全负责人姓名 |
| 联系电话 | 是 | 手机号码 |
| 单位地址 | 否 | 详细地址 |
| 建筑楼层 | 否 | — |
| 建筑高度 | 否 | 单位：米 |

**步骤 3 — 补充关联信息**

无论选择已有还是新建，底部的通用区域可补充：

| 字段 | 填入方式 | 必填 |
|------|---------|------|
| 备注标签 | 文本输入（如"重点客户""A 级项目"） | 否 |
| 项目负责人 | 从本服务商人员列表中选择 | 否 |

**步骤 4 — 提交关联**

- 校验：检查该业主单位是否已被本服务商关联 → 防止重复
- 校验通过 → 关联关系建立，状态为"关联中"
- 业主端相关方列表即时出现该服务商

### 3.2 关联关系状态

| 状态 | 含义 | 可执行操作 |
|------|------|-----------|
| 关联中 | 正常使用状态，可以创建合同等业务 | 解除关联、编辑备注/负责人 |
| 已解除 | 关系终止，关联数据保留但不再参与业务 | 无 |

### 3.3 解除关联规则

**前置条件：** 检查该业主是否存在**进行中的合同**（待确认 / 已签订 / 执行中）：
- 存在 → 阻止解除，提示"该企业还有进行中的合同，请先终止合同后再解除关联"
- 不存在 → 允许解除，弹出二次确认

**二次确认提示内容：**

> 确认解除与「{企业名称}」的关联关系？
>
> 解除后：
> - 关联数据保留，历史合同/维保记录仍可查阅
> - 无法为该企业创建新的合同和维保计划
> - 该企业将从业主端相关方列表中移除

**解除后效果：**
- 该企业从服务商端"关联中"列表消失（可切换到"已解除"列表查看历史）
- 业主端该服务商从"相关方企业"列表中移除
- 历史合同、维保记录等数据保留，只读可查
- 无法为该企业创建新的合同和维保计划

## 6. 数据联动关系

### 6.1 与其它模块的联动

```
服务企业管理 → 关联新业主    → 合同创建时可选业主单位增加
               → 解除关联    → 合同创建时可选业主单位移除
                            → 已有合同不受影响
                            → 维保台账/计划的可选业主同步移除

合同管理     → 进行中合同    → 解除企业关联时校验，阻止解除
```

### 6.2 联动规则矩阵

| 触发动作 | 影响范围 | 效果 |
|---------|---------|------|
| 关联新业主 | 合同创建"业主单位"下拉 | 即时新增可选企业 |
|  | 维保台账"所属企业"下拉 | 即时新增可选企业 |
|  | 维保计划"所属企业"下拉 | 即时新增可选企业 |
|  | 业主端相关方列表 | 即时出现该服务商 |
| 解除关联 | 合同创建"业主单位"下拉 | 移除，不可为该企业新签合同 |
|  | 维保台账/计划"所属企业"下拉 | 移除，不可为该企业新建 |
|  | 已有合同/台账/计划 | 保留不受影响，历史可查 |
| 编辑备注标签 | 服务商端企业列表、详情页 | 即时更新 |
| 编辑项目负责人 | 服务商端企业列表、详情页、合同详情页 | 即时更新 |

## 7. 业务边界场景

| 场景 | 处理方式 |
|------|---------|
| **重复关联** | 提示"该企业已被关联，不可重复关联"。弹窗中已关联企业灰色展示标记"已关联"，不可选中 |
| **解除关联时存在进行中合同** | 阻止解除，提示"该企业还有进行中的合同，请先终止合同后再解除关联" |
| **搜索有结果但仍需新建（企业未录入系统）** | 清空搜索框，重新搜索无结果即可触发新建表单 |
| **系统尚无任何业主单位** | 搜索任何内容均无结果 → 自动展开新建表单 |
| **服务商企业基础信息变更** | 由系统管理维护，本模块不提供编辑入口 |
| **业主端列表为空** | 展示「暂无关联的维保服务公司，如有疑问请联系相关服务商」 |
| **一家业主被多家服务商关联** | 业主端相关方列表展示所有关联服务商，互不冲突。各服务商独立为该业主创建合同和维保计划，数据隔离 |
