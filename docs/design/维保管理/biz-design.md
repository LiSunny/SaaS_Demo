# 消防维保平台 — 业务设计

> AI 安全管理平台。最后更新：2026-06-02。
> 面向物业、消防服务商、安全监管三方，提供消防安全全场景数字化管理。

---

## 一、产品定位

消防维保全链路数字化平台。围绕"设备 → 计划 → 任务 → 工单 → 报告"核心链路，串联物业、消防服务商、安全监管三方协作。

---

## 二、核心用户与价值

| 角色 | 核心诉求 | Web/移动端 |
|------|---------|-----------|
| 物业管理员 | 维保计划制定、工单发起、验收确认、报告查看 | Web |
| 消防服务工程师 | 接收任务、现场处置、拍照留痕 | 微信小程序 |
| 安全监管员 | 督办监管、统计分析、合规审查 | Web |
| 企业管理员 | 企业/人员/合同管理 | Web |

## 三、模块全景

| 编号 | 模块 | 定位 | 状态 |
|------|------|------|------|
| M0 | 流程编排 | 基础设施，提供流程引擎 | ✅ 已实现 |
| — | 工单管理 | M0 的子模块，任务流转与处置闭环 | ✅ 部分实现 |

| M7 | 故障与隐患 | 故障报修+隐患排查整改 | 待实现 |
