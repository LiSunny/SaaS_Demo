# 导航结构设计

> 侧栏主导航 — 取代顶部一级菜单 + 侧栏按分组过滤模式。
> 基于 14 域 × 123 模块全量功能分析，为角色化导航预留架构。
> 设计日期：2026-06-05

---

## 一、改造动机

### 1.1 现状问题

| # | 问题 | 表现 |
|---|------|------|
| 1 | **顶部菜单横向空间不足** | 9 个菜单已微挤，扩展到 10+ 后超出 |
| 2 | **7 个顶部菜单共享同一侧栏** | 顶部 7 项点击后看到的侧栏完全一样，无实际导航意义 |
| 3 | **多人共用同一套菜单** | 值班员、安全经理、系统管理员看到的内容一样，各自抱怨"不是我想要的" |
| 4 | **系统管理与平台配置职责模糊** | 两域模块数 39 个，管理单元/组织树等入口出现在多个地方 |

### 1.2 改造目标

1. **去除横向限制**：侧栏纵向可无限扩展
2. **分组折叠减噪**：用户只看到自己关注的分组
3. **支持 14 域全量**：从 demo 9 域扩展到真实平台 14 域
4. **为角色化过滤预留架构**：数据结构支持按角色条件渲染

## 三、展开模式 vs 跳转模式

### 3.1 决策规则

```
模块数 ≤ 8 → 展开模式：侧栏内嵌 2 级子菜单
              示例：巡查检查 → 巡查计划/巡查任务/巡查报表
              
模块数 > 10 → 跳转模式：点击进入域首页概览页
              示例：设备管理 → /device （18 模块在域内页 Tab 中承载）
```

### 3.2 展开模式结构

```
🔍 巡查与隐患 ▾
  ├─ 巡查检查 ▸                  ← 有 children，无 route → 点击展开
  │   ├ 巡查计划                 ← 无 children，有 route → 点击导航
  │   ├ 巡查任务
  │   └ 巡查报表 ▸               ← 二级展开
  ├─ 隐患管理 ▸
  │   ├ 隐患台账
  │   └ 自查上报
  └─ 危险作业                    ← 2 个模块时直接平铺，无需包装
      ├ 作业备案
      └ 特殊作业审批
```

### 3.3 跳转模式结构

```
🔧 设备与物联 ▸
  ├─ 设备管理 →                  ← 有 route → 点击导航到 /device
  ├─ IOT →                      ← 有 route → 点击导航到 /iot
  └─ 维保应用 ▸                  ← 有 children → 点击展开
      ├ 合同管理
      └ 维保记录
```

## 四、数据结构定义

```typescript
interface NavNode {
  key: string          // 唯一标识
  label: string        // 展示文本
  icon?: string        // 图标名称（收起模式用）
  route?: string       // 有 route = 点击跳转
  children?: NavNode[] // 有 children = 点击展开
}

interface NavGroup {
  key: string
  label: string
  icon?: string
  defaultOpen: boolean
  children: NavNode[]
}

// 核心规则：route 和 children 不能同时存在
// route + 无 children = 跳转叶子 or 跳转域首页入口
// children + 无 route = 展开节点（点击 toggle）
// 两者都无 = 纯占位标签
```

## 五、交互规格

### 5.1 搜索

| 动作 | 行为 |
|------|------|
| 输入文字 | 递归匹配所有 NavNode.label，包含关系即匹配 |
| 有匹配项 | 匹配的分组展开，无匹配的分组隐藏 |
| 匹配项高亮 | 匹配文字加粗或变色 |
| 无匹配 | 显示"无匹配结果" |
| 清空输入 | 恢复默认展开/折叠状态 |

### 5.2 钉选

| 动作 | 行为 |
|------|------|
| hover 菜单项 | 显示 ☆ 图钉图标 |
| 点击 ☆ | 加入 `pinnedKeys`，图标变 ⭐（金色），写入 localStorage |
| 再次点击 ⭐ | 移除钉选 |
| 有钉选项 | 搜索框下方渲染「📌 常用」区，可折叠 |
| 无钉选项 | 常用区不渲染 |

### 5.3 折叠

| 动作 | 行为 |
|------|------|
| 点击分组标题 | 切换 children 显隐，chevron 旋转 |
| 路由切换 | 当前路由所在的父级分组和父级节点自动展开 |

### 5.4 收起模式（≤1280px）

侧栏宽度：272px → 72px。隐藏：
- 搜索框
- 分组标题文字（只保留图标）
- 所有文字标签和子项
- 工作台文字（只保留星标）
- 常用区
